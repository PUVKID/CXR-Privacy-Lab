# 1차 전체 변경 범위

이전 저장소·차수가 없는 최초 구현이므로 빈 기준과 비교합니다. 공개한 모든 파일은 추가이며 수정·삭제 파일은 없습니다.

대시보드의 HTML·CSS·JavaScript·폰트와 라이선스, Node 서버·동작 검사, Python 실행 관리자·실패 경로 검사, 실행 CMD, README·차수 목차·변경 기록을 포함합니다. 원문 전체 차이는 저장소의 최초 커밋에서 파일별로 확인할 수 있으며, `git show --format=fuller --stat --patch HEAD`는 주석·공백을 포함한 전체 추가 내용을 보여 줍니다. 폰트 바이너리는 Git의 바이너리 표시와 함께 로컬 공개 분류 기록에서 바이트 수와 SHA-256을 확인했습니다.

제공받은 원본 실험 패키지는 로컬에 보존하고 공개를 보류했습니다. 환자 영상·가중치·결과·실행 로그·개인 기록·라우팅 영수증은 이 비교의 공개 대상이 아닙니다. 원본 평가 엔진의 계산식과 시험 분할은 이번 작업에서 변경하지 않았습니다.

처음 생성한 시안의 초록 계열은 구현 과정에서 흰색·저채도 회청색으로 변경했습니다. 최종 화면은 코드로 구현하며 시안 이미지를 기능 화면으로 사용하지 않습니다.
