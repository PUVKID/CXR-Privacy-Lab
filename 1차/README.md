## LEVEL 1 - Beginner · 배경과 용어부터 읽기

[11/13시점 원격 설명(보존) · 같은 LEVEL 1](https://github.com/PUVKID/CXR-Privacy-Lab/blob/2434a1e29533a74b7acc60a6799c8da550c91ac7/1%EC%B0%A8/README.md#reading-level-1) — 당시 6차까지의 설명이며 현재 7·8차 관측과 구분합니다.

| 구분 | 이 차수에서 하는 일 | 처음 읽을 때 확인할 뜻 |
| --- | --- | --- |
| 목적 | 이미 학습된 공개 CXR 최종 가중치로 평가하는 첫 구현입니다.<br>이 차수에서 새 CXR 모델을 학습했다는 뜻이 아닙니다. | 배우는 작업인지 평가인지 먼저 구분합니다. |
| 입력 | 로컬 평가 패키지, 준비된 NIH·COVID 영상, 공개 최종 가중치와 실행 설정을 입력합니다. | 사진·목록·모델·설정의 역할은 다릅니다. |
| 처리 | Python 관리자가 데이터 준비·평가 실행을 연결하고 Node 화면이 GPU·다운로드 크기·환경 및 실행 로그·CSV를 읽습니다. | 화면과 계산 프로그램을 혼동하지 않습니다. |
| 설정·조건 | 원본·블러·모자이크는 평가 단계입니다.<br>흰색·회청색, 나눔고딕 Bold700, 양쪽 테마와 입체 영상의 모션 제어를 제공합니다. | 설정 숫자는 성능 숫자가 아닙니다. |
| 출력 | 실제 결과 CSV, 상태·로그와 변환 예시를 보여 줍니다.<br>파일이 없는 결과는 미측정이며 미리보기 사진은 성능 수치가 아닙니다. | 파일이 있어야 측정값을 읽을 수 있습니다. |
| 과거·현재 관측 | 화면과 실행 관리 기능을 구성했으나, 이어진 2차 감사에서 공식 분할·검색 정규화·결과 덮어쓰기 등의 문제가 드러났습니다. | 이 차수에서 확인한 범위까지만 말합니다. |
| 한계 | 화면이 열리거나 추론이 성공한 것만으로 원 논문 성능을 재현했다고 할 수 없습니다.<br>공개 사본에는 의료 데이터·평가 엔진 전체·가중치가 없습니다. | 후속 차수의 해결을 과거에 소급하지 않습니다. |
| 실행·검사 | 로컬 START_DASHBOARD.cmd 또는 node server.mjs로 화면을 엽니다.<br>Node tests/server.test.mjs, Python tests/test _runner.py와 원본 엔진 검사를 구분합니다. | 공개 설명만으로 의료 실험을 실행할 수 있는지 확인합니다. |

**읽는 예:** 이미 환자를 구별하도록 배운 모델에 사진을 넣어 시험 점수를 계산합니다. “가중치”는 모델이 배워 저장한 숫자입니다. 모델을 받아 시험하는 것과 사진을 보며 새로 배우는 것은 다른 작업입니다. 이 차수의 시작 버튼은 전자의 실행을 관리합니다.

화면에서 영상이 천천히 기울어지는 것은 처리 흐름을 이해하기 위한 표현입니다. 모션 정지는 그 움직임만 멈춥니다. 데이터를 내려받는 중, 환경을 설치하는 중, 평가를 계산하는 중, CSV가 생긴 뒤를 각각 읽어야합니다. 결과 칸이 비어 있는 것은 0점이 아니라 아직 점수를 얻지 못했다는 뜻입니다.

**신뢰할 수 있는 범위:** localhost는 이 컴퓨터 안에서 화면을 여는 주소이고 GPU는 계산 장치입니다. Host·Origin 검사는 다른 주소에서 임의 실행 요청을 보내는 것을 제한합니다. 이 보안 기능이 평가 알고리즘의 정확성까지 증명하지는 않습니다. 뒤의 2차 감사가 바로 그 계산 조건을 따로 확인합니다.

**결과 보고:** 저장된 측정값과 논문 기준을 구분합니다. 손실은 시험 정확도가 아니며 PrivacyScore @1은 고정 공격의 1 순위 실패율입니다. 이 값만으로 익명성·임상 효용을 보장하지 않습니다. 의료 영상·개인별 목록·모델 가중치·운영 원문은 공개하지 않습니다.

## LEVEL 2 - Explorer · 구성과 조건의 관계

[11/13시점 원격 설명(보존) · 같은 LEVEL 2](https://github.com/PUVKID/CXR-Privacy-Lab/blob/2434a1e29533a74b7acc60a6799c8da550c91ac7/1%EC%B0%A8/README.md#reading-level-2) — 당시 6차까지의 설명이며 현재 7·8차 관측과 구분합니다.

| 출력 | 실제 결과 CSV, 상태·로그와 변환 예시를 보여 줍니다.<br>파일이 없는 결과는 미측정이며 미리보기 사진은 성능 수치가 아닙니다. | 상태·미리보기·지표는 다른 출력입니다. |

| 한계 | 화면이 열리거나 추론이 성공한 것만으로 원 논문 성능을 재현했다고 할 수 없습니다.<br>공개 사본에는 의료 데이터·평가 엔진 전체·가중치가 없습니다. | 같지 않은 조건은 비교에 명시합니다. |

이 차수의 연결은 **화면→관리자→평가 패키지→CSV→화면**입니다.

Node 서버가 연구 결과를 계산하는 것이 아니라 평가 프로그램이 저장한 값을 읽습니다.

Python 관리자에 데이터 준비가 있어도 그 다음이 반드시 새 학습이라는 규칙은 없습니다. 1차는 제공된 최종 모델로 평가합니다.

설치 로그와 평가 로그를 분리해 원인을 좁히고, 로컬 요청 검사와 실행 중복 차단은 제어 경계를 지킵니다. 2차 감사의 계산 결함은 이 제어 경계가 정상이어도 별도로 남을 수 있습니다.

**결과 보고:** 저장된 측정값과 논문 기준을 구분합니다. 손실은 시험 정확도가 아니며 PrivacyScore @1은 고정 공격의 1 순위 실패율입니다. 이 값만으로 익명성·임상 효용을 보장하지 않습니다. 의료 영상·개인별 목록·모델 가중치·운영 원문은 공개하지 않습니다.

**구현 경계:**server.mjs의 HTTP 제어와 Python 관리자의 평가 실행을 분리합니다.

CSV·상태·부분 다운로드 크기는 관측 입력이며 대표 미리 보기는 UI 자료입니다.

원본 엔진이 별도 비공개인 공개 사본에서는 서버 fixture와 관리자 제어 검증만으로 전체 추론·분할·논문 성능을 검증할 수 없습니다.

후속 2차의 결함 목록을 1차 구현에 소급해 해결됐다고 쓰지 않습니다.

**결과 보고:** 저장된 측정값과 논문 기준을 구분합니다. 손실은 시험 정확도가 아니며 PrivacyScore @1은 고정 공격의 1 순위 실패율입니다. 이 값만으로 익명성·임상 효용을 보장하지 않습니다. 의료 영상·개인별 목록·모델 가중치·운영 원문은 공개하지 않습니다.

## 🩻 1차 — 로컬 실험 제어와 대시보드

첫 구현 차수입니다. 앞선 차수나 최종본은 없습니다. 원본·블러·모자이크는 실험의 세 단계이며 파일 저장 차수와 다릅니다.

## 화면과 동작

- 흰색·저채도 회청색, 나눔고딕 Bold 700, 좌측 탐색과 넓은 현재 작업 영역을 사용합니다.
- 실제 영상의 원본·블러·모자이크 변환을 입체 패널로 보여 줍니다. 로컬 미리보기는 평가 결과와 구분합니다. 모션을 멈춰도 실험은 계속됩니다.
- 다크·라이트 전환은 표·로그·입체 재질까지 함께 바꿉니다.
- GPU 정보와 데이터 다운로드 파일 크기, 환경 설치·실험 로그, 실제 CSV 결과를 표시합니다.
- 결과가 없으면 빈 상태를 표시합니다. 표시된 데이터셋 수량은 목표와 관측값을 구분합니다.
- 서버는 로컬 주소에만 바인딩하고 Host·Origin을 검사합니다. 경로 탐색과 임의 명령 입력을 허용하지 않습니다.

## 실행과 검증

`START_DASHBOARD.cmd` 또는 `node server.mjs`로 화면 서버를 실행합니다.

실험 시작은 `run_experiment.py`를 사용합니다.

원본 평가 코드는 로컬 `experiment/`, Python은 상위 `runtime/`, 데이터와 결과는 상위 `research/`에 필요합니다. [전체 안내](../README.md)를 확인하세요.

검사는 `node --test tests/server.test.mjs`, `python tests/test_runner.py -v`와 원본 엔진의 unittest를 사용합니다. 현재 공개 소스는 대시보드와 관리자에 한하며, 원본 패키지·실 데이터는 별도입니다.
