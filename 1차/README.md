# 1차 — 로컬 실험 제어와 대시보드

첫 구현 차수입니다. 앞선 차수나 최종본은 없습니다. 원본·블러·모자이크는 실험의 세 단계이며 파일 저장 차수와 다릅니다.

## 화면과 동작

- 흰색·저채도 회청색, 나눔고딕 Bold 700, 좌측 탐색과 넓은 현재 작업 영역을 사용합니다.
- 실제 영상의 원본·블러·모자이크 변환을 입체 패널로 보여 줍니다. 로컬 미리보기는 평가 결과와 구분합니다. 모션을 멈춰도 실험은 계속됩니다.
- 다크·라이트 전환은 표·로그·입체 재질까지 함께 바꿉니다.
- GPU 정보와 데이터 다운로드 파일 크기, 환경 설치·실험 로그, 실제 CSV 결과를 표시합니다.
- 결과가 없으면 빈 상태를 표시합니다. 표시된 데이터셋 수량은 목표와 관측값을 구분합니다.
- 서버는 로컬 주소에만 바인딩하고 Host·Origin을 검사합니다. 경로 탐색과 임의 명령 입력을 허용하지 않습니다.

## 실행과 검증

`START_DASHBOARD.cmd` 또는 `node server.mjs`로 화면 서버를 실행합니다. 실험 시작은 `run_experiment.py`를 사용합니다. 원본 평가 코드는 로컬 `experiment/`, Python은 상위 `runtime/`, 데이터와 결과는 상위 `research/`에 필요합니다. [전체 안내](../README.md)를 확인하세요.

검사는 `node --test tests/server.test.mjs`, `python tests/test_runner.py -v`와 원본 엔진의 unittest를 사용합니다. 현재 공개 소스는 대시보드와 관리자에 한하며, 원본 패키지·실데이터는 별도입니다.
