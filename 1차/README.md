### LEVEL 1 · 목적과 대상

**이 차수의 목적과 실제 구성**

첫 구현 차수입니다. 앞선 차수나 최종본은 없습니다. 원본·블러·모자이크는 실험의 세 단계이며 파일 저장 차수와 다릅니다.

흉부 엑스레이를 흐리게 하거나 모자이크로 바꿔도 같은 환자의 다른 사진을 찾아낼 수 있는지 살피는 실험입니다. 검증은 두 사진이 같은 사람인지 비교하고, 검색은 여러 사진 중 같은 사람을 찾는 작업입니다. **화면의 변환 미리보기는 평가 결과가 아닙니다.**

### LEVEL 1 · 달라진 내용과 차수 관계

로컬 실험 제어와 대시보드의 첫 구현입니다. 앞선 차수·최종본은 없으며 원본·블러·모자이크는 파일 차수가 아닌 실험의 세 단계입니다.

어떤 사진이 누구의 것인지 다시 찾는 것이 재식별입니다. 흐리게 한 사진을 모델에 넣고 같은 환자의 다른 촬영 사진이 검색되는지 봅니다. 자기 사진을 그대로 정답 후보에 두면 쉬운 비교가 되므로 제외합니다.

### LEVEL 1 · 입력과 실행 조건

`START_DASHBOARD.cmd` 또는 `node server.mjs`로 화면 서버를 실행합니다. 실험 시작은 `run_experiment.py`를 사용합니다. 원본 평가 코드는 로컬 `experiment/`, Python은 상위 `runtime/`, 데이터와 결과는 상위 `research/`에 필요합니다. [전체 안내](../README.md)를 확인하세요.

검사는 `node --test tests/server.test.mjs`, `python tests/test_runner.py -v`와 원본 엔진의 unittest를 사용합니다. 현재 공개 소스는 대시보드와 관리자에 한하며, 원본 패키지·실데이터는 별도입니다.

[직전 비교와 전체 변경 범위](COMPARISON.md) · [차수 목차](../docs/REVISION_INDEX.md)

원영상 확보와 손상·중복 검사를 먼저 하고, 문제가 없을 때 모델을 학습합니다. 이후 원본과 변형 사진을 같은 모델로 비교합니다. 결과가 없거나 다른 실행의 파일이면 화면에 이전 숫자를 가져오지 않습니다.

### LEVEL 1 · 처리 절차

- 흰색·저채도 회청색, 나눔고딕 Bold 700, 좌측 탐색과 넓은 현재 작업 영역을 사용합니다.
- 실제 영상의 원본·블러·모자이크 변환을 입체 패널로 보여 줍니다. 로컬 미리보기는 평가 결과와 구분합니다. 모션을 멈춰도 실험은 계속됩니다.
- 다크·라이트 전환은 표·로그·입체 재질까지 함께 바꿉니다.
- GPU 정보와 데이터 다운로드 파일 크기, 환경 설치·실험 로그, 실제 CSV 결과를 표시합니다.
- 결과가 없으면 빈 상태를 표시합니다. 표시된 데이터셋 수량은 목표와 관측값을 구분합니다.
- 서버는 로컬 주소에만 바인딩하고 Host·Origin을 검사합니다. 경로 탐색과 임의 명령 입력을 허용하지 않습니다.

대시보드를 여는 것과 학습을 시작하는 것은 다릅니다. 해당 차수의 시작 파일과 준비·실행 안내를 따릅니다. 움직이는 그림을 멈춰도 실제 실험은 계속되며, 대기 화면을 학습 완료로 보지 않습니다.

### LEVEL 1 · 결과를 확인하는 방법

실제 CSV를 표시하고 결과가 없으면 빈 상태를 보입니다. 미리보기와 평가, 목표 수량과 실제 관측 수량을 구분합니다.

수치는 실제 결과 파일에서 읽습니다. 2026-11-13 확인한 연결 실험은 CUDA 오류로 중단된 상태였습니다. 화면을 새로 꾸몄다고 학습이 다시 시작되거나 높은 성능이 나온 것은 아닙니다.

### LEVEL 1 · 주의할 범위

공개 소스는 대시보드와 관리자에 한합니다. 로컬 experiment·runtime·research의 필수 자료와 원본 엔진은 별도로 필요하며 모션 정지가 실험 정지를 뜻하지 않습니다.

의료 원영상·환자 식별자·가중치는 공개하지 않습니다. 중복 영상 때문에 준비가 중단된 과거 기록도 남아 있습니다. **좋은 프라이버시 점수가 법적 익명화나 진단 가능성을 보장하지 않습니다.**

### LEVEL 4 · 입력과 실행 조건
