# 2차 — 평가 재현 정밀 감사

1차를 수정하지 않고 원 논문과 공식 코드를 대조했습니다. 당시 경로는 공개 최종 CXR 가중치 평가였으며 재학습은 아니었습니다.

공식 Verification·Retrieval의 서로 다른 목록 범위, 검색 출력 정규화 누락, 고정 결과 덮어쓰기, 캐시 출처 부족과 동률·파일 검증·Windows 실행 경로 문제를 확인했습니다.

합성 계산과 공개 모델 추론 검사는 실제 환자 데이터의 논문 성능 재현과 구분했습니다. 프라이버시 수식은 고정 공격에서의 Rank-1 실패율로 한정해야 하며, 자기 원본 제외와 환자 분할 검사 외에 전체 영상 검증이 필요하다고 판정했습니다. 공개판은 식별자·영상 목록이 없는 감사 요약입니다.
