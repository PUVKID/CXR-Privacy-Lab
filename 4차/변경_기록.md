# 4차 변경 기록

사용자 요청에 따라 한글 프로젝트 폴더로 통합하고 3차의 소스에서 4차를 구성했습니다. 기존 차수·원본·대용량 결과·캐시를 보존합니다.

- 화면·실험 코드·검사·문서 폴더와 시작 CMD·노트북·사용자 안내 파일을 한글 이름으로 정리했습니다.
- 서버·실행 관리자·설정·검사·그래프 폰트·노트북 경로를 상대 경로와 새 공통 폴더에 맞췄습니다. 서버 8787·보안 allowlist·실행 잠금·중단 계약을 유지했습니다.
- 현재 RAM 여유를 고려해 학습 입력 작업자를 0으로 명시했습니다. 학습 배치·손실·시드·에폭·검사 제한시간을 유지하고, 원래 환자의 분할 소속을 바꾸지 않습니다. 중복 제외로 달라진 영상·쌍 수는 별도로 기록합니다.
- 모션 버튼에 투명 상태 배경·44px 클릭 영역·스위치 축소 방지·테마별 트랙/손잡이 경계를 적용했습니다. 작은 화면 제목 행은 공간이 부족하면 줄바꿈합니다.
- CMD 검사는 한글 경로를 위해 UTF-8 무BOM·CRLF·코드페이지 65001을 확인하며, Python 진입점·실행 환경·실패 중단 검사는 유지합니다. 한글 정적 폴더 allowlist와 모션 상태 계약 검사도 추가했습니다.
- 과거 프로토콜·계획·검증 보고서는 문서에 보존 표시와 함께 남겼습니다. 과거 관측을 4차 결과로 바꾸지 않았습니다.
- NIH112,120장 디코딩 오류 0과 픽셀 중복 25그룹을 실제 확인했습니다. 환자 충돌 8그룹 17장 전체 제외 및 같은 환자 17그룹에서 17장 제외로 112,086장의 파생 허용 집합을 정합니다. 원본·기존 14그룹 차단 보고서는 보존하고, 학습·검증·시험 및 검색이 같은 파생 목록을 사용하게 합니다.
- 새 실험은 검증 영상의 CBM 혼입 차단과 정확 중복 제외가 추가된 재학습입니다. 원 논문과 동일한 전체 데이터·환경의 성능 재현으로 표현하지 않습니다.

- 전체 차수 목차를 번호 목록에서 폴더·설명·직전 비교 링크를 함께 놓은 표로 보완했습니다.

검사 결과·독립 검토·공개 반영 영수증은 실제 실행 뒤 별도로 보존합니다. 원본 평가 엔진의 재배포 권한 불명확 상태와 의료 원본 비공개는 유지합니다.
