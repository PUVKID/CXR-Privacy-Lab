## LEVEL 1 - Beginner · 배경과 용어부터 읽기

[11/13시점 원격 설명(보존) · 같은 LEVEL 1](https://github.com/PUVKID/CXR-Privacy-Lab/blob/2434a1e29533a74b7acc60a6799c8da550c91ac7/4%EC%B0%A8/README.md#reading-level-1) — 당시 6차까지의 설명이며 현재 7·8차 관측과 구분합니다.

| 구분 | 이 차수에서 하는 일 | 처음 읽을 때 확인할 뜻 |
| --- | --- | --- |
| 목적 | 한글 폴더로 프로젝트를 통합하고 NIH의 정확 픽셀 중복을 제외하는 파생 학습 집합을 추가했습니다. | 배우는 작업인지 평가인지 먼저 구분합니다. |
| 입력 | 원본 NIH112,120장을 그대로 보존하고 전수 디코드·원본 SHA256·픽셀 내용·환자 및 분할 관계를 확인한 명세를 사용합니다. | 사진·목록·모델·설정의 역할은 다릅니다. |
| 처리 | 환자가 서로 다른 동일 영상은 모두 제외하고 같은 환자의 동일 영상은 파일명 순 한 장을 남깁니다.<br>원본 삭제가 아닌 허용 목록의 파생입니다. | 화면과 계산 프로그램을 혼동하지 않습니다. |
| 설정·조건 | NIH34장을 제외한 허용 112,086장입니다.<br>검증 모델은 학습 75,690·검증 10,811·시험 25,585장, 검색 학습 61,735장으로 구분합니다.<br>시드 3·배치 32, 입력 작업자 0을 명시합니다. | 설정 숫자는 성능 숫자가 아닙니다. |
| 출력 | 한글 화면·실험 코드·검사·문서 폴더와 실행별 학습 기록을 만듭니다.<br>모션 버튼의 전역 호버 충돌·44px 조작 영역·포커스·양쪽 테마를 보완했습니다. | 파일이 있어야 측정값을 읽을 수 있습니다. |
| 과거·현재 관측 | NIH 디코드 손상 0, 픽셀 중복 25 그룹 51장 중 14 그룹 차단을 관측했습니다.<br>이후 COVID 충돌 영상 발견으로 4차 준비가 중단됐고 그 준비에서 학습은 시작하지 않았습니다. | 이 차수에서 확인한 범위까지만 말합니다. |
| 한계 | 정확 픽셀 중복 제거는 근사 중복 전체 해결을 뜻하지 않습니다.<br>파생 분모는 저자 공식 목록과 다르며 4차 준비 실패를 학습 성공으로 쓰지 않습니다. | 후속 차수의 해결을 과거에 소급하지 않습니다. |
| 실행·검사 | 대시보드 _시작.cmd, 실험 코드/데이터 _준비.cmd·데이터 _검사.cmd·전체 _실험 _시작.cmd를 목적별로 구분합니다.<br>한글 경로·복사 무결성·중복/손상·실행 및 화면 조작 검사를 따로 확인합니다. | 공개 설명만으로 의료 실험을 실행할 수 있는지 확인합니다. |

**읽는 예:** 이름이 다른 파일 두 개라도 실제 사진 내용이 같으면 “다른 촬영”을 찾는 시험에서 정답을 너무 쉽게 찾을 수 있습니다. 4차는 파일 이름뿐 아니라 실제 픽셀, 즉 사진을 구성하는 색 숫자까지 비교해 이런 정확 중복을 찾았습니다. 조금 비슷한 사진까지 모두 해결했다는 뜻은 아닙니다.

같은 영상에 서로 다른 환자 이름표가 붙어 있으면 어느 쪽이 맞는지 임의 결정하지 않고 그 그룹을 실험 대상에서 뺍니다. 같은 환자의 같은 영상 여러 파일은 한 장만 남깁니다. 원본을 지우는 것이 아니라 사용할 목록을 따로 만드는 방법이므로 원래 수량과 실제 실험 수량이 함께 남습니다.

한글 폴더와 모션 버튼 수리는 사용 편의를 바꾼 부분입니다. 데이터 수량이 달라진 변경과 구별해서 읽어야합니다. NIH 정리를 마쳤어도 COVID에서 충돌이 발견돼 준비가 멈췄으므로, 폴더가 완성되고 화면이 정상이라고 학습까지 끝났다고 판단하면 안 됩니다.

**결과 보고:** 저장된 측정값과 논문 기준을 구분합니다. 손실은 시험 정확도가 아니며 PrivacyScore @1은 고정 공격의 1 순위 실패율입니다. 이 값만으로 익명성·임상 효용을 보장하지 않습니다. 의료 영상·개인별 목록·모델 가중치·운영 원문은 공개하지 않습니다.

### LEVEL 1 · 이 차수의 용어 풀이

| 용어 | 쉬운 뜻 |
| --- | --- |
| 디코드·픽셀·SHA256 | 디코드는 파일을 실제 사진으로 읽는 일, 픽셀은 사진의 색 숫자, SHA256은 파일 내용의 지문입니다.<br>각각 다른 종류의 손상·변경을 확인합니다. |
| 원본·파생 허용 집합 | 원본은 보관한 자료 전체이고 파생 허용 집합은 규칙을 통과해 이번 실험에 실제로 쓸 목록입니다.<br>수량이 달라도 원본을 지운 뜻이 아닙니다. |
| 시드·작업자 0 | 시드는 무작위 선택의 시작 설정입니다.<br>입력 작업자 0은 추가 자료 읽기 프로세스를 만들지 않는 설정이며 학습 배치가 0이라는 뜻이 아닙니다. |
| 호버·포커스 | 호버는 마우스를 올린 상태, 포커스는 키보드로 조작할 대상이 선택된 상태입니다.<br>화면이 멀쩡해 보여도 이 상태를 따로 확인합니다. |

## LEVEL 2 - Explorer · 구성과 조건의 관계

[11/13시점 원격 설명(보존) · 같은 LEVEL 2](https://github.com/PUVKID/CXR-Privacy-Lab/blob/2434a1e29533a74b7acc60a6799c8da550c91ac7/4%EC%B0%A8/README.md#reading-level-2) — 당시 6차까지의 설명이며 현재 7·8차 관측과 구분합니다.

| 구성 요소 | 연결되는 자료·조건 | 해석 경계 |

| 목적 | 한글 폴더로 프로젝트를 통합하고 NIH의 정확 픽셀 중복을 제외하는 파생 학습 집합을 추가했습니다. | 경로의 목적을 정하는 계약입니다. |

| 과거·현재 관측 | NIH 디코드 손상 0, 픽셀 중복 25 그룹 51장 중 14 그룹 차단을 관측했습니다.<br>이후 COVID 충돌 영상 발견으로 4차 준비가 중단됐고 그 준비에서 학습은 시작하지 않았습니다. | 관측과 기능 구현은 다른 증거입니다. |

정제의 연결은 원본 바이트 확인→픽셀 내용 비교→환자·분할 관계 판단→허용 목록→학습 입력입니다.

파일명만 비교하면 서로 다른 이름의 같은 영상을 놓칩니다.

같은 환자 내 중복과 환자 표기 충돌에 서로 다른 제외 규칙을 적용해 보존 원칙과 실험 입력을 분리했습니다.

한글 경로는 이 명세·실행 진입점이 같은 자료를 가리키게 만드는 운영 계약입니다.

NIH 정제 완료는 COVID 검사까지 통과했다는 뜻이 아니므로 뒤의 준비 실패도 흐름에 남습니다.

**결과 보고:** 저장된 측정값과 논문 기준을 구분합니다. 손실은 시험 정확도가 아니며 PrivacyScore @1은 고정 공격의 1 순위 실패율입니다. 이 값만으로 익명성·임상 효용을 보장하지 않습니다. 의료 영상·개인별 목록·모델 가중치·운영 원문은 공개하지 않습니다.

**자료 준비 순서:**데이터 _준비와 데이터 _검사 CMD를 전체 _실험 _시작과 구분합니다.

NIH 원본 112,120장 보존을 확인하고 허용 112,086장 및 환자별·분할별 명세를 읽습니다.

## 4차 — 중복 영상을 제외하고 다시 학습하는 흉부 엑스레이 재식별 실험

<a id="-실행"></a>
## 실행

프로젝트 상위의 `실행 환경/Scripts/python.exe`로 `run_experiment.py`를 실행합니다.

대시보드는 Node.js로 `server.mjs`를 실행하고 로컬 포트 8787에서 확인합니다.

데이터는 기존 프로젝트의 `연구 자료/`를 사용하고 실행별 학습·체크포인트·기록은 `4차/work/runs/<실행 UUID>/`에 새로 저장합니다.

과거 실행에서 자동 재개하지 않습니다.

학습 전 데이터의 실제 확보·손상·환자 분리 검증과 GPU 연산 확인이 필요합니다. 화면의 준비 중은 학습 중을 뜻하지 않습니다. 모델 학습 실패나 현재 실행이 생성하지 않은 가중치에서는 평가를 시작하지 않습니다. 기존 1차와 감사 보고서 2차는 보존합니다.

학습은 원 논문 시드 3 과 배치 32를 사용합니다.

현재 GPU에서는 검색 네트워크의 활성 값 재계산을 켜고, 재계산 중 BatchNorm 통계와 난수 상태를 보존합니다.

혼합 정밀도 초기 배율의 overflow는 가중치 갱신 없이 상태를 복원하고 배율을 낮춘 뒤 같은 배치를 재시도합니다.

유한 손실·기울기를 확인한 뒤 optimizer와 스케줄러를 한 번 갱신합니다.

이 포팅 조건을 원 논문 실행 환경과 구분해 기록합니다.

원 공식 검색 코드의 validation CBM 메모리 갱신은 이번 구현에서 차단합니다. 검증 영상이 다음 학습 큐에 섞이지 않도록 한 의도된 변경이며, 원 논문 주요 학습 조건에 누수 방어를 보완한 재학습으로 구분합니다. 모든 코드 동작과 환경이 원본과 동일한 재현이라고 표현하지 않습니다.

<a id="-지표-해석"></a>
## 지표 해석

프라이버시 점수 `100 × (1 − CMC@1)`는 고정된 공격 모델과 검색 집합에서의 1 순위 재식별 실패율입니다.

익명성 보장·차등 프라이버시·법적 적합성·진단 효용을 뜻하지 않습니다.

자기 원본은 검색에서 제외하며 같은 환자의 다른 촬영 영상으로 재식별을 평가합니다.

환자별 영상 수와 질의 분모를 함께 기록합니다.

- 확보된 데이터 검사만: `실험 코드/데이터_검사.cmd`

## 실제 데이터에서 확인한 중복

NIH 원본 112,120장을 모두 디코딩한 결과 손상은 0개, 정확히 같은 픽셀의 중복은 25 그룹 51장이었습니다. 이 중 14 그룹은 환자 기록 충돌·분할 중복 또는 평가의 동일 영상 비교 문제로 준비 단계에서 차단됐습니다. 원본과 이 실패 기록은 보존합니다.

서로 다른 환자로 기록된 동일 영상 8 그룹 17장은 모두 실험 목록에서 제외하고, 같은 환자의 동일 영상 17 그룹 34장은 파일명 순으로 한 장씩 남깁니다. 총 34장을 제외한 112,086장이 파생 허용 집합입니다. 원 논문과 달라진 데이터 조건이며, 공식 목록을 그대로 사용한 성능 재현으로 표현하지 않습니다.

검증 모델의 분할은 학습 75,690장·검증 10,811장·시험 25,585장입니다.

학습은 남은 양성 395,926 쌍과 에폭마다 생성하는 음성 395,926 쌍을 사용합니다.

검색 학습은 중복 제외 후 새로 생긴 단일 영상 환자도 학습 자격에서 구분해 61,735장입니다.

최종 준비 검증과 실제 실행 기록에서 이 수량과 동일 픽셀 잔여 중복 0을 다시 확인해야 합니다.
