# 3차 → 4차 비교

4차는 3차 소스를 복사한 뒤 사용자용 한글 이름과 경로를 적용합니다. 비교 시 파일 이름 변경과 실제 내용 변경을 구분합니다. 복사 기준의 개별 크기·SHA256은 비공개 작업 기록에 보존합니다. 과거 차수는 보존합니다.

| 3차 | 4차 | 내용 변경 |
|---|---|---|
| app/ | 화면/ | 모션 상태 배경·44px 영역·고정 스위치·4차 표시 |
| experiment/ | 실험 코드/ | 상대 공통 경로·한글 안내·CMD·노트북·폰트 경로 |
| tests/ | 검사/ | 한글 경로·모션·정적 파일 경계 회귀 |
| docs/ | 문서/ | 과거 문서 보존 표시, 한글 파일명 |
| START_DASHBOARD.cmd | 대시보드_시작.cmd | 서버 진입점 유지 |
| run_experiment.py | 동일 도구 이름 | 4차·새 경로·학습 입력 작업자0 |
| server.mjs | 동일 도구 이름 | 4차·새 공통 경로·한글 화면 폴더 |

`cxr_reid`·`training` 등 내부 패키지와 원저자 고유 파일명은 실행 계약 때문에 유지합니다. .codex의 과거 누적 상태는 사본이며 새 실행 증거나 누적 초기화가 아닙니다. 공통 폴더의 실제 이동과 전체 공개 비교 파일 생성·원격 반영은 부모 담당 절차입니다.

이 문서는 비교 안내입니다. 기능·주석·공백과 바이너리 크기·해시를 포함한 실제 전체 비교 자료는 검증된 공개 대상에 한해 별도로 연결합니다.

## 실제 데이터 검사에 따른 추가 변경

3차의 전수 검사는 원본112,120장 중 정확 픽셀 중복25그룹을 발견하고14개 문제 그룹을 차단했습니다. 4차에서는 공식 원본을 그대로 보존하면서 환자 정체성이 충돌한17장과 같은 환자의 반복 픽셀17장을 제외하는 파생 집합을 사용합니다. 정제 결과를 임의 수동 목록으로 신뢰하지 않고 고정 원근거·현재 모든 원영상 해시·정책 재계산과 대조합니다.

검증 학습은 양성395,926쌍과 새 음성395,926쌍, 검색 학습은61,735장으로 바뀝니다. 평가도 같은 허용 집합으로 투영하며 변경된 분모를 기록합니다. 공개 범위에 새로 작성한 정제 정책 코드와 합성 검사를 포함하고, 재배포 권한이 미확인인 기존 평가 엔진은 계속 보류합니다.
