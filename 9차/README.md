## LEVEL 1 - Beginner

**현재 계산은 7차, 새 진행 화면은 9차**입니다. 에 폭은 학습 자료를 한 바퀴 도는 단위이고, 배치는 한 번에 처리하는 묶음입니다. 같은 7차 학습을 보면서 현재 바퀴가 얼마나 진행됐는지와 세 학습 과정 중 어디에 있는지를 구분합니다.

| 보는 곳 | 읽는 방법 | 주의할 점 |
| --- | --- | --- |
| 에폭 막대 | 현재 배치를 이번 에폭의 전체 배치와 비교 | 100%는 이번 한 바퀴가 끝났다는 뜻 |
| 학습 단계 막대 | 지금까지의 에폭·배치를 그 단계의 최대 예정 에폭과 비교 | 전체 실험 시간이나 성능의 완성도가 아님 |
| 세 단계 흐름 | 검증 모델 → 검색 출력부 → 검색 전체 | 저장된 완료 증거와 현재 기록을 함께 확인 |
| 손실 그래프 | 실제로 저장된 학습·검증 오차의 최근 관측을 확인 | 낮아졌다고 시험 정확도나 익명성이 보장되지는 않음 |
| 빈 값·원값 | 기록이 없으면 미측정 안내, 있는 값은 원래 숫자로 확인 | 없는 오차를 0으로 채우지 않음 |

먼저 화면의 실험 차수와 학습 상태를 확인하고, 큰 막대 아래의 에폭·배치 숫자를 읽습니다.

그 다음 손실 그림의 범위와 마지막 기록 시각을 봅니다.

앞 부분을 생략한 최근 기록이라면 전체 학습 곡선으로 보고하지 않습니다.

조기 종료가 가능한 검증 모델은 최대 100에 폭을 다 채우지 않고 끝날 수 있으므로 막대가 100%가 아니어도 실제 완료 기록이 있는지 따로 확인합니다.

기존 표시용 PowerShell 창이나 브라우저를 닫는 일과 **숨김 학습 실행기를 종료하는 일은 다릅니다**.

별도 실행 중인 학습의 생존과 기록 증가를 확인해야하며, 모든 PowerShell·Python을 일괄 종료하거나 재부팅해도 계속된다는 뜻은 아닙니다.

화면의 모션 정지는 그림의 움직임만 멈춥니다.

의료 사진·가중치·개인별 목록·운영 로그는 공개하지 않습니다.

## LEVEL 2 - Explorer

9차는 7차 계산 결과를 새로 만드는 학습기가 아니라, **기존 기록을 진행률·단계·추세로 연결하는 읽기 전용 화면**입니다. 에폭, 학습 단계, 전체 평가 조건은 분모가 다른 세 축입니다.

| 연결 | 처리 | 화면에서의 뜻 |
| --- | --- | --- |
| 현재 진행 기록 → 에폭 | 현재 배치 / 해당 에폭 전체 배치 | 한 자료 순회의 진행 |
| 에폭 기록 → 학습 단계 | 완료에 폭과 현재 배치 비율/단계 최대 에폭 | 검증 100·출력부 30·전체 50 각각의 예정 량 기준 |
| 저장 완료 근거 → 단계 흐름 | 현재 기록과 완료 상태를 구분 | 다음 단계로 넘어간 근거를 표시 |
| 유한한 크기의 이력 → 손실 추이 | 실제 정상 학습·검증 관측만 분리 | 누락·범위·마지막 시각을 함께 해석 |
| 프로세스·최근 기록 → 현재 상태 | 파일 존재만으로 생존을 추정하지 않음 | 현재 실행과 과거 정상 관측을 분리 |

세 단계 비율을 단순 평균해 전체 실험 시간 완료율로 부르지 않습니다. 검증 모델은 조기 종료할 수 있고 각 단계의 한 배치 비용도 다릅니다. 손실 그림은 관측한 오차의 변화이며 최종 검증 AUC나 검색 P @1과 다른 출력입니다. 조회할 기록이 부족하면 계산할 수 없다는 상태를 유지합니다.

표시 창·화면 서버·학습 실행기가 분리돼 있으면 표시만 닫는 조작은 학습 종료 명령이 아닙니다. 다만 실제 실행기 종료·운영 체제 종료·저장 실패까지 막는 보장은 아닙니다. 8차의 연결·입력 검증과 강도별 원값 조회는 보존하며 9차는 학습 설정이나 변환별 재학습 구조를 추가하지 않습니다.

## LEVEL 3 - Practitioner

**7차 계산을 유지한 채 9차 화면을 여는 절차**입니다. 공개 사본에는 의료 자료·가중치·운영 원문이 없으며 로컬 연구 환경과 연결된 경우에만 실제 관측을 읽을 수 있습니다.

| 순서 | 확인할 내용 | 보고할 근거 |
| --- | --- | --- |
| 1 |9차 서버·화면과 7차 실험 연결 표시 | 다른 차수의 예전 화면과 구분 |
| 2 | 현재 학습 단계·프로세스·기록 시각 | 살아 있는 실행과 과거 로그를 구분 |
| 3 | 에폭·배치 원수와 에폭 막대 | 배치 분모를 확인한 해당 에폭의 진행률 |
| 4 | 단계 최대 에폭과 완료 근거 | 최대 예정량과 실제 조기 종료·완료를 분리 |
| 5 | 손실의 학습/검증 구분·표시 범위 | 최근 일부 이력인지와 마지막 관측 시각 |
| 6 | 두 테마·모션 정지·키보드·작은 화면 | 실제 조작 상태와 값의 출처를 함께 점검 |

9차 폴더에서 `node server.mjs`로 조회 서버를 실행하고 로컬 8787 화면을 확인합니다. 이미 같은 포트에 서버가 있으면 중복 실행하거나 학습 프로세스를 종료해 해결하지 않습니다. 현재 서버의 차수와 주소는 실제 실행 환경에서 대조합니다.

숫자가 비어 있거나 이력이 오래됐으면 미측정·확인 불가로 기록합니다.

손실을 정확도로 바꾸거나 이전 단계 곡선을 현재 단계 곡선으로 이어 붙이지 않습니다.

백분율 요약은 소수 첫째 자리 반올림이며 원수·원비율을 확인합니다.

표시용 창을 닫은 뒤에도 실제 학습 생존과 기록 증가가 이어지는지 따로 확인하고, 학습 실행기 전체 종료와 혼동하지 않습니다.

## LEVEL 4 - Advanced

9차는 기존 읽기 경계와 상태 판정 위에 **진행 계산·이력 전달·시각화 경계**를 추가합니다. 학습 소스·분할·손실·optimizer·scheduler는 이 화면 변경의 대상이 아닙니다.

| 구현 경계 | 검토할 계약 | 변경 영향 |
| --- | --- | --- |
| 진행 계산 | 에폭의 배치 비율과 단계 최대 에폭 비율을 구분 | 전체 시간 추정과 별개 |
| 완료 상태 | 현재 기록·저장 완료 근거·오래된 상태를 구분 | 실제 완료를 단순 최대 에폭 도달로 대체하지 않음 |
| 이력 전달 | 유한한 읽기 범위·정상 기록·단계·검증 구분 | 무제한 파일 전달과 누락을 0으로 메우는 처리를 금지 |
| 손실 표시 | 관측 구간·축·마지막 시각과 원값 유지 | 부분 이력을 전체 학습으로 오표시하지 않음 |
| 화면 동작 | 테마·모션·포커스·작은 폭과 선택 상태 | 조회 동작이 학습 제어로 번지지 않음 |

분모가 없는 기록은 unknown으로 유지해야 합니다. 단계 전환·재개·실패행의 0·중복 또는 불완전 기록은 현재 상태와 마지막 정상 관측을 구분하는 기존 어댑터 계약과 함께 검토합니다. 진행 막대의 값이 유한하다는 검사만으로 과학적 해석이 맞다고 판단하지 않습니다.

동일 실행의 표시 창과 숨김 학습 실행기는 별개 생명 주기를 가질 수 있습니다. 서버 재시작·브라우저 종료가 학습 종료 API가 되어서는 안 되며, 기존 프로세스 정체 확인·읽기 경로 제한은 유지합니다. 구체적 읽기 상한·계산 함수·회귀 결과는 9차 상세와 8 →9 전체 파일 비교에서 대조합니다.

## LEVEL 5 - Expert · 동결 구현의 전체 설명

다음은 9차 구현자가 동결한 안내의 전체 본문입니다. 수준별 해설을 추가하며 실제 코드·관측 값을 바꾸지 않았습니다.


현재 계산은 **7차 학습**, 화면은 **9차 읽기 전용 대시보드**입니다. 7차 학습 코드·설정·가중치와 8차 화면을 보존합니다. 이 화면은 학습을 시작하거나 중단하지 않습니다.

| 영역 | 실제 근거 | 해석 |
| --- | --- | --- |
| 현재 에폭 | 현재 처리 배치 / 전체 배치 | 현재 자료 순회 진행; 남은 배치도 같은 분모에서 계산 |
| 현재 학습 단계 | ((에폭−1)+배치/전체 배치)/예정 최대 에폭 | 최대 예정량의 비율이며 전체 실험 시간 완료율이 아님 |
| 세 단계 흐름 | 현재 실행의 기록·후속 학습 단계·선택 가중치 | 검증 최대 100 → 검색 출력 부 30 → 검색 전체 50; 조기 종료와 최대 량 도 달 구분 |
| 학습 손실 | 최근 정상 training 이벤트 | 가로축은 단계 내 누적 처리 배치; 손실 감소가 시험 성능을 뜻하지 않음 |
| 검증 손실 | 실제 epoch_complete의 validation_loss | 가로 축은 에폭; 학습 배치 손실과 별도 그래프 |
| 결과 | 현재 실행의 평가 JSON/CSV | 2 데이터 셋 ×2 과제 ×21 조건 =84개 상태; 미측정은 0으로 대체하지 않음 |

## 진행과 그래프를 읽는 방법

백분율은 소수 첫째 자리 반올림이며 원 분자·분모·계산 원 비율을 학습 수치 원값에서 확인합니다.

에 폭·전체에 폭·배치·전체 배치가 정수 범위를 벗어나거나 분모가 0/누락이면 막대는 미측정입니다.

조기 종료로 다음 학습 단계에 진입하면 최대 예정 비율이 100%가 아니어도 이전 단계가 끝난 것입니다.

세 단계의 단순 평균을 전체 시간 진행률로 제시하지 않습니다.

최근 256 KiB의 완성된 LF 행만 엄격 UTF-8/JSON/실행 경계로 검증합니다.

중간 손상이 있으면 손실 시 계열을 채택하지 않습니다.

원본은 보존되며 잘린 앞부분과 작성 중 마지막 행은 따로 안내합니다.

**이 그래프는 전체 학습 이력이 아닙니다.** 학습 곡선은 단계·에폭·시간 역전·누적 처리 배치 되 감기에서 선을 끊습니다.

원값이 0 인 손실은 유효하고, 미측정 손실은 점을 만들지 않습니다.

축 눈금만 4 유효 숫자로 줄여 쓰며 그래프 점 설명과 전체 학습 원값에는 저장 정밀도를 유지합니다.

현재 기록과 오류 전 마지막 정상 기록, 오래된 관측과 실제 프로세스 확인을 구분합니다.

선택 가중치 파일만으로 단계 완료를 단정하지 않습니다.

두 과제 순차 학습 설정에서 후속 단계 관측 또는 실제 전체 학습 종료와 가중치 존재를 결합합니다.

현재에 폭 남은 배치는 표시하지만 재개·검증·자료 읽기가 섞인 로그에서 속도나 남은 시간을 만들지 않습니다.

처리 배치는 AMP에서 생략되는 가중치 적용 횟수와 다릅니다.

## PowerShell 창과 학습 실행

표시 창과 실제 학습 프로세스는 별개일 수 있습니다.

이번 확인에서 기존 표시 창에는 학습 자식이 없었고 실제 숨김 실행기 아래의 학습 프로세스는 별도로 관측됐습니다.

이 사실을 모든 PowerShell 창을 닫아도 안전하다는 일반 보장으로 확대하지 않습니다.

실행기나 실제 학습 프로세스 트리를 종료하면 학습이 중단될 수 있습니다.

이 화면의 모션 정지는 화면 움직임만 멈춥니다.

## 실행과 검사

Node.js로 `server.mjs`를 실행하면 기본 로컬 8787에서 화면을 제공합니다.

운영 서버 교체는 학습과 별개로 담당자가 수행하며 기존 학습 프로세스를 종료하지 않습니다.

시험 서버는 `createDashboard()`를 import하여 8788 같은 별도 포트로 열 수 있습니다.

기본 실험 경계는 같은 프로젝트의 `7차`이며 UUID 포인터의 임의 경로를 따르지 않습니다.

```text
node --check server.mjs
node --test 검사/server.test.mjs
```

이 차수 구현자 검사는 29개입니다. 실제 PC·모바일 화면, 밝은/어두운 테마, 포커스·선택·모션 조작 검증과 독립 검토는 별도 단계이며 합성 검사 성공을 실험 성능 재현으로 표현하지 않습니다. 의료 자료·가중치·실행 로그는 공개하지 않습니다. 공개 소스만으로 전체 실험을 실행할 수 있다는 뜻이 아닙니다.

진행 막대의 요약 백분율은 원 정수 분자·분모에서 0.1% 단위로 직접 반올림합니다. 나눗셈 후 이진 부동 소수 오차 때문에 경계 값이 낮아지는 문제를 막고, 원 비율과 저장 값은 그대로 보존합니다. 2,100개 경계 조합과 별도 재현 사례를 검사합니다.


## 공개 사본의 검증 범위

| 근거 | 실제 확인 | 한계 |
| --- | --- | --- |
| 고정 구현 검사 | Node 회귀 29개 통과와 문법 검사 | 합성 계약 검사이며 7차 학습·평가 완주 증거가 아님 |
| 실제 화면 | PC 밝은/어두운 테마,390×844 작은 화면의 넘침,Enter 원값 펼침·모션 정지/재생, 콘솔 경고/오류 확인 | 사용한 도구에서 실제 hover를 지원하지 않아 마우스 오버 상태는 미검증 |
| 기록·수치 | 실제 관측 구간·원값·미측정과 최대 예정량을 구분 | 모든 미래 UI·저장·학습 오류가 방지된다는 뜻이 아님 |

설계와 작업계획의 미완료 체크 표시는 작성 시점의 계획을 보존한 것입니다. 이후 수행한 구현 검사와 위 화면 확인 범위는 따로 구분합니다. 논문·평가 해석의 한계는 [8차 재검토](../8차/논문과_실행_재검증.md)를 유지하며 새 원고·논문 PDF·성과를 만들지 않았습니다.
