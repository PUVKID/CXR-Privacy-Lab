## LEVEL 1 - Beginner · 배경과 용어부터 읽기

| 구분 | 이 차수에서 하는 일 | 처음 읽을 때 확인할 뜻 |
| --- | --- | --- |
| 목적 | 기존 5차 고정 연결 대신 현재 7차 실행을 읽는 독립 대시보드입니다.<br>학습 모델·분할·수치 계산은 이 차수에서 바꾸지 않습니다. | 배우는 작업인지 평가인지 먼저 구분합니다. |
| 입력 | `7차/work/current_run.json`의 검증된 실행 ID와 고정 `runs/<UUID>` 경계의 진행·이벤트·설정·결과·현재 대표 사진을 읽습니다.<br>포인터 path는 읽기 경로로 신뢰하지 않습니다. | 사진·목록·모델·설정의 역할은 다릅니다. |
| 처리 | 2 데이터 셋·2 과제·21 조건을 선택하고 실제 행만 연결합니다.<br>프로세스의 소스·출력 UUID·부모·생성 시각과 최근 진행 기록이 함께 맞을 때만 학습 중으로 표시합니다. | 화면과 계산 프로그램을 혼동하지 않습니다. |
| 설정·조건 | 블러·모자이크 모두 0,1,2,4,8,16,32,64,128,256입니다.<br>상태 3초 갱신·프로세스 10초 캐시·GPU15초 캐시, 읽기 전용이며 시작·중단 API가 없습니다. | 설정 숫자는 성능 숫자가 아닙니다. |
| 출력 | 84개 과제 상태·42개 CSV 행·전체 원값·최근 재개 stdout/stderr와 대표 사진을 보여 줍니다.<br>정상 이력 생략 안내와 손상 오류, 현재 오류와 마지막 정상 기록을 나눕니다. | 파일이 있어야 측정 값을 읽을 수 있습니다. |
| 과거·현재 관측 | 로컬 연결·보안·표시 검사를 수행하고 7차 실제 진행과 프로세스의 연결을 확인했습니다.<br>이는 7차의 전체 학습·평가·논문 성능 완료 증거가 아닙니다. | 이 차수에서 확인한 범위까지만 말합니다. |
| 한계 | global_step은 단계 내 처리 배치이며 혼합 정밀도의 가중치 적용 생략 때문에 실제 적용 횟수와 다를 수 있습니다.<br>마지막 관측과 저장 체크포인트도 다르며 운영 분리가 재부팅·저장 실패를 막지는 않습니다. | 후속 차수의 해결을 과거에 소급하지 않습니다. |
| 실행·검사 | node server.mjs 후127.0.0.1:8787에서 화면 8차·실험 7차를 확인합니다.<br>Node 검사와 실제 데이터 셋/과제/21 조건 선택·원값·양 쪽 테마·모션·포커스 검증을 구분합니다. | 공개 설명만으로 의료 실험을 실행할 수 있는지 확인합니다. |

**읽는 예:**7차가 일을 하는 작업장이라면 8차는 그 작업장을 보는 현황 판입니다. 화면을 새로 고침하거나 데이터 셋·강도를 바꿔도 7차 학습 설정은 바뀌지 않습니다. 시작·종료 버튼을 제거해 예전 5차를 잘못 제어하지 않게했습니다.

실행 ID는 여러 실험 결과가 섞이지 않도록 붙이는 고유 표지입니다. 기록에 적힌 임의 경로를 따라가지 않고 현재 ID의 정해진 폴더만 봅니다. 최근 글이 쓰였다는 사실과 실제 계산 프로그램이 남아 있다는 사실을 함께 확인해야 학습 중으로 보입니다. 조회가 실패하면 확인 불가라고 표시합니다.

**0을 읽는 방법:**오류를 남기는 과정에서 진행 칸이 0으로 초기화돼도 이전 작업 전체가 사라졌다는 뜻은 아닙니다.

마지막 정상 기록과 저장된 체크포인트를 따로 봅니다.

처리 배치 수는 입력 묶음을 몇 번 다뤘는지이며, 계산 값이 유효하지 않아 모델 수정이 생략된 배치까지 포함할 수 있어 실제 가중치 적용 횟수와 같지 않습니다.

긴 학습 이력의 앞부분을 생략하는 것은 정상적인 조회 방식입니다. 최근 256 KiB만 읽었다는 안내를 원값 옆에 남기고 손상된 기록만 오류로 알립니다. 밝고 어두운 테마, 모션 정지, 조건 선택과 숫자 펼침은 조회 기능이며 익명성 보장이나 학습 완료를 뜻하지 않습니다.

**결과 보고:** 저장된 측정값과 논문 기준을 구분합니다. 손실은 시험 정확도가 아니며 PrivacyScore @1은 고정 공격의 1 순위 실패율입니다. 이 값만으로 익명성·임상 효용을 보장하지 않습니다. 의료 영상·개인별 목록·모델 가중치·운영 원문은 공개하지 않습니다.

### LEVEL 1 · 이 차수의 용어 풀이

| 용어 | 쉬운 뜻 |
| --- | --- |
| UUID·어댑터 | UUID는 실행 고유 표지이고 어댑터는 7차 파일을 화면이 읽을 수 있는 상태로 바꾸는 연결 코드입니다. |
| JSON·CSV·stdout/stderr | JSON은 이름-값 기록, CSV는 표 파일입니다. stdout은 프로그램 출력, stderr는 경고·오류 출력이며 어느 실행에서 나온 것인지 함께 봅니다. |

| 256 KiB·캐시·신선도 | KiB는 파일 크기 단위입니다.<br>캐시는 잠시 조회 결과를 재사용하는 방식, 신선도는 기록이 최근인지 보는 기준이며 그 자체로 프로세스 생존 증명은 아닙니다. |

Windows 가상환경의 실행 전달 프로세스와 실제 Python 자식은 같은 계보이면 한 학습으로 묶습니다.

정상적인 이력 앞부분 생략은 오류가 아니지만 잘못된 JSON·UTF8·다른 실행 기록은 관측값으로 채택하지 않습니다.

NIH/COVID19와 검증/검색을 고르고 원본·블러·모자이크의 원하는 강도로 이동합니다.

현재 UUID·결과 원값·측정 출처·분모를 확인하고 미측정을 0점으로 기록하지 않습니다.

상단 학습 중 표시는 프로세스와 최근 기록 확인이 동반되어야합니다.

## LEVEL 5 - Expert · 전체 상세와 근거

## 8차 — 7차 실시간 연결과 실행 분리

기존 대시보드의 5차 고정 연결을 7차 실제 실행 기록으로 바꾸는 화면 차수입니다. 학습 모델·설정·데이터 분할은 이 화면 변경으로 바꾸지 않습니다.
