차수는 보존 이력이며 최종본이나 학습 완료를 뜻하지 않습니다. 3차의 실제 준비 검사는 데이터 중복을 차단했고 정식 학습은 시작하지 않았습니다. 4차의 실제 학습 결과와 구분합니다.

5차의 실제 학습 시작·종료는 원영상 검사와 새 모델의 실제 갱신 증거로 별도 확인합니다.
