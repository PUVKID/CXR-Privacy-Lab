# 4차와 5차의 전체 비교

4차에서 NIH 전수 파일 검사를 끝낸 뒤 COVID 외부 평가의 정확 중복 2그룹을 발견해 준비를 차단했습니다. 5차는 이 외부 집합의 환자 충돌 4장을 제외하는 결정적 파생 정책과 실행 연결을 추가합니다. 4차의 실패·검증 이력과 원본은 보존합니다.

**범위**

COVID 원본

**4차**

781장·1,548쌍, 중복 2그룹에서 차단

**5차**

원본과 차단 근거 보존, 허용 777장·1,534쌍으로 파생


**범위**

외부 평가 분모

**4차**

실제 평가 미실행

**5차**

검증 양성 772·음성 762, 검색 유효질의 508을 구분


**범위**

외부 목록 결합

**4차**

정제된 COVID 집합 미연결

**5차**

검증 쌍과 검색이 같은 허용 집합 사용


**범위**

검증 출처

**4차**

NIH 고정 원근거·파생 목록

**5차**

COVID도 별도 고정 원근거·정책 재계산·현재 원파일 SHA·보고서 결합


**범위**

실행·표시

**4차**

4차·준비 실패

**5차**

5차·새UUID·스냅샷 실패 중단, 실제 0회와 미기록 구분


**범위**

관측 수치

**4차**

소수 네 자리 반올림 요약

**5차**

백분율 소수 둘째 자리 버림, 단위 구분과 저장 원값 펼침


**범위**

유지 조건

**4차**

NIH 정제와 학습 조건·모션·양쪽 테마

**5차**

같은 조건 유지, 기존 차수 보존



공개 가능한 코드·문서의 주석·공백·이름을 포함한 실제 전체 차이는 [전체 변경](비교%20자료/4차_대비_전체_변경.diff)과 [파일별 크기·해시](비교%20자료/파일_비교.json)에서 확인합니다. 비교 문서 자체와 생성 비교 자료는 자기 참조를 피하려고 이 내용 비교에서 제외하며 전체 공개 묶음 해시에는 포함합니다.

제공 평가 엔진의 수정 파일은 재배포 권한이 확인되지 않아 공개 사본에서 보류합니다. 로컬 전체 소스 비교와 독립 검토에는 포함합니다. 새 정제 코드와 개인정보가 없는 합성 검사는 공개 범위에 포함합니다. 이 차이를 논문 전체의 동일 재현이나 실제 학습 완료로 표현하지 않습니다.
