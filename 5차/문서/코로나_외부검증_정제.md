**4차 준비 실행은 NIH 원파일 112,120개의 현재 SHA256 대조를 마친 뒤 COVID 전수 디코딩에서 다른 환자 ID에 연결된 동일 픽셀 2그룹·4장을 발견해 종료 코드 1로 중단했습니다.** 실제 학습 갱신은 0회였습니다. 5차는 이전 차수·원영상·공식 목록·실패 보고서를 보존하고, NIH와 같은 정제 정책을 외부검증에도 적용합니다.

## 적용 정책과 실제 분모

서로 다른 환자 ID가 같은 픽셀에 연결된 그룹은 신원을 확정할 수 없어 해당 영상을 모두 제외합니다. 같은 환자의 동일 픽셀은 파일명 정렬의 첫 영상만 남기는 정책을 유지합니다. 이번 COVID 근거에는 같은 환자 중복 그룹이 없습니다. 공식 목록을 직접 고치거나 쌍을 새로 균형 표집하지 않습니다.

영상 4장 제외로 검증 쌍 14개가 제외됩니다. 원래 두 클래스가 균형인 1,548쌍과 정제 후 불균형 1,534쌍을 구분합니다. 5차의 외부검증은 이 정제 집합에 대한 평가이며, 논문의 공식 1,548쌍 평가와 같은 실험이라고 주장하지 않습니다. 새 정확도·AUC·프라이버시 결과는 아직 측정하지 않았습니다.

검증 쌍과 검색 목록은 `project_external_evaluation`에서 동일한 허용 집합에 투영합니다. 제외 영상을 검색 갤러리에 남기지 않습니다. 갤러리 777장과 유효 질의 508장은 서로 다른 분모이며, 검색 지표의 자기 원본 제외·단일 영상 환자 질의 제외 조건을 유지합니다. NIH 정제 허용 112,086장, 학습 분할·손실·배치·시드·에폭·ImageNet 초기화는 이번 수리에서 바꾸지 않았습니다.

## 고정 전수 검사와 새 검증 스냅샷

원 COVID 전수 검사 JSON은 187,044바이트이며 SHA256은 `b5978c0baf9457b7fc20cd706d8b77d4df3e6160cdffac93d6c04b9e0fd88724`입니다. 원 검사 엔진은 `95fac8ac7657876ace6c8215366897784bb257a16dbc932d5ef5f06667fcdf6d`, 레코드 내용 지문은 `bd8709157ffa84c8660965b53667009f57e3bef3430b3a89b24e006b493299d3`입니다. 이 값은 관측된 고정 근거이며 현재 파일에 맞춰 갱신하는 기준이 아닙니다.

`validation_runs/원본_전수검사/covid_pixels.private.json`의 안정 사본을 자동 발견하면 다음 조건을 모두 확인한 뒤 새 UUID 스냅샷에 파생 결과를 작성합니다. 새 CLI 인자를 요구하지 않습니다.

1. JSON을 해석하기 전에 고정 파일 크기와 전체 SHA256을 확인합니다. 원 엔진·내용 지문·781개 디코딩 완료·오류 0 조건도 확인합니다.
2. 공식 CSV와 쌍 파일의 고정 SHA, 공식 영상 범위·환자 대응·외부 분할을 대조합니다.
3. 제외된 4장을 포함한 현재 원파일 781개 전체 SHA256을 다시 검사합니다. NIH 현재 원파일 전수 SHA 검사도 유지합니다.
4. 정책을 다시 계산해 허용·제외 목록과 이유를 생성합니다. NIH와 독립된 `covid_exact_pixel_cleaning_v1` 스키마·원근거 앵커를 사용하고 새 엔진 해시에 결합합니다.
5. 보고서에 파생 manifest 파일 SHA, 허용 목록 해시, 정책·집계와 실제 평가 분모를 결합합니다. 이후 스냅샷 재사용 시에도 현재 원파일 SHA와 정책·보고서 분모를 다시 계산해 검증합니다.

원 `blocking_duplicate_groups=2`와 원 레코드 781개는 파생 manifest에서도 그대로 보존합니다. 정제 후 `remaining_duplicate_groups=0`은 다른 필드에 실제 허용 픽셀의 유일성을 확인한 결과로 기록합니다. 허용 목록이나 보고서 해시만 함께 바꾸어도 고정 원근거에서 정책을 재계산하므로 받아들이지 않습니다. NIH 근거를 COVID 근거로 바꾸거나 다른 원 JSON·바뀐 파일·다른 엔진을 제출하면 차단합니다. 안정 사본이 없으면 기존 전수 디코딩 경로가 동작하며, 중복 차단을 생략하지 않습니다.

기존 고정 JSON과 공식 목록을 읽어 재계산했을 때 NIH/COVID의 원본 픽셀 교집합과 정제 후 픽셀 교집합은 모두 0개였습니다. 이 계산은 새 실행의 현재 영상 SHA 전수 검사를 대신하지 않습니다. 근사 중복·환자 ID 원기록의 정확성을 보장하는 검사도 아닙니다. 원영상·환자별 목록·비공개 manifest는 공개 대상에서 제외합니다.

## 구현 검사와 남은 확인

신규 합성 회귀 `검사/test_covid_cleaning.py`는 독립 원근거·스키마, 원 차단 근거 보존, 다른 원근거·변조 제외 목록·보고서 불일치 거부, 불균형 쌍의 투영, 빈 집합 차단, 제외 영상의 현재 바이트 검사와 준비 단계의 고정 근거 재사용을 확인합니다. 781개 작은 합성 파일의 준비 검사에서는 재디코딩을 호출하지 않고 현재 SHA를 전수 검사하며, 제외 파일을 바꾸면 새 manifest를 게시하기 전에 중단하는지 확인했습니다. 실제 의료 영상이나 환자 ID를 포함하지 않습니다.

- 신규 구현 전 검사 6개는 미지원 `dataset` 인자로 실패한 TDD 이력이며 원문을 보존했습니다. 실패를 성공으로 바꾸지 않았습니다.
- 구현 후 신규 COVID 8개가 통과했습니다. `Ran 8 tests in 34.549s`는 unittest 내부 검사 시간이며 전체 프로세스 경과 시간을 별도로 측정한 값이 아닙니다.
- 기존 NIH 정제 13개, 데이터셋 7개, 병렬 픽셀 5개, 두 데이터 계약 4개가 각각 통과했습니다. 합계는 37개입니다. 이 부분 검사를 전체 독립 검사 통과로 표현하지 않습니다.
- 새 전체 독립 검사, 현재 원영상의 새 전수 SHA 검증, 실제 학습 첫 갱신과 성능 평가는 부모 실행과 별도 verifier의 확인 범위입니다. 중앙 75초 계산 검사와 전체 120초 제한은 변경하지 않았습니다.
