## 학습과 선택

검증 모델은 입력 256·배치 32·BCEWithLogitsLoss·Adam lr0.0001·최대 100에폭·검증 BCE 기준 patience5를 사용합니다. 검색 모델은 입력 1024·배치 32·환자 블록 8·밝기/대비 0.4 증강, 정규화 L2 ContrastiveLoss와 CBM128을 사용합니다. SGD momentum0.9·weight_decay0.00001·OneCycle max_lr0.158489, 출력부 30에폭 후 전체 50에폭으로 이어집니다. 각 검색 단계의 optimizer·스케줄러·메모리는 새로 구성합니다.

검색 모델은 공식 경로의 마지막 에폭을 사용하고 시험·COVID 영상으로 학습이나 선택을 하지 않습니다. 원 공식 코드의 검증 중 CBM 메모리 갱신은 차단해 검증 영상이 다음 학습의 큐에 섞이지 않게 했습니다. 이 차이와 중복 제외는 의도된 누수 방어입니다.

## 실행과 기록

상위 실행기의 준비 전용 실행으로 검증을 완료한 뒤 그 실행의 `validation_snapshot`을 학습에 전달합니다. 새 학습 진입점은 `train_from_scratch.py --project <연구 자료> --output <새 실행 폴더> --seed 3 --tasks both --validated-snapshot <완료 검증 스냅샷> --activation-checkpointing --num-workers 0`입니다. 완료한 픽셀 검사 근거를 재사용하더라도 고정 해시·명세·내용과 현재 모든 원영상의 SHA256이 일치해야 합니다. 원본 차단 값을 정상으로 바꾸는 방식으로 재사용하지 않습니다.

`--preflight`는 입력 검사, `--smoke-gpu`는 합성 영상 역전파 검사입니다. 정식 NIH 학습과 구분합니다. 실행별 초기화·설정·가중치 해시·진행·선택 근거를 보존하며 자동으로 이전 실행을 재개하지 않습니다.

Windows·Python3.12·PyTorch2.7.1 포팅이며 논문 당시 환경과 같지 않습니다. 활성값 재계산은 난수·BatchNorm 통계를 보존하도록 검사합니다. 혼합정밀도 overflow에서는 가중치 갱신 없이 상태와 같은 배치를 복원해 배율을 낮추고, 유한 기울기에서 optimizer·스케줄러를 한 번 갱신합니다. 입력 작업자 0은 추가 프로세스 메모리를 줄이기 위한 실행 조건이며 배치 32와 연구 분할을 바꾸지 않습니다.

## 해석 범위

현재 범위는 NIH·COVID 재식별과 블러·모자이크 비교입니다. CheXpert 및 모든 부가 분석을 포함한 완전 재현으로 표현하지 않습니다. 프라이버시 점수는 고정 공격에서의 Rank-1 실패율이며 진단 효용·익명성을 보장하지 않습니다. 학습 종료와 논문 수치 재현은 실제 결과가 확보된 뒤 판정합니다.

## 5차 COVID 외부 평가의 파생 조건

COVID 원본 781장 전수 디코딩에서 서로 다른 환자 ID에 연결된 동일 픽셀 2그룹·4장을 확인해 원래 준비 실행을 차단했습니다. 이 4장을 모두 제외한 777장·445명의 허용 집합을 verification 쌍과 retrieval에 함께 적용합니다. 검증 쌍은 1,534개(양성 772·음성 762), 유효 검색 질의는 508장입니다. 원 공식 1,548쌍·781장과 파생 분모를 구분하며 음성 쌍을 새로 만들어 균형을 맞추지 않습니다.

원본·공식 목록·기존 2그룹 차단 근거를 보존합니다. 고정 원근거의 전체 SHA, 원래 781개 현재 파일의 SHA, 정책 재계산과 보고서 결합을 확인하며 NIH와의 교차 픽셀 중복도 차단합니다. 이 정제는 외부 평가에만 적용하며 NIH 학습·모델·손실 조건을 바꾸지 않습니다. 최종 수치는 실제 새 모델의 평가 후 기록합니다.

## 수치 표시와 원값 보존

백분율은 소수 둘째 자리까지 버려 표시하고, 같은 행에서 저장된 원비율과 전체 정밀도의 원값을 펼쳐 확인할 수 있게 합니다. 검색 성공률은 원비율을 백분율로 바꾸고 프라이버시 점수는 이미 0~100인 단위를 유지합니다. AUC·손실·학습률의 표시 자릿수와 원값도 구분합니다. 표시 과정에서 CSV·JSON 결과 원본을 바꾸거나 미측정 값을 0으로 대체하지 않습니다.
