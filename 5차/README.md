## LEVEL 1 - Beginner · 배경과 용어부터 읽기

[11/13시점 원격 설명(보존) · 같은 LEVEL 1](https://github.com/PUVKID/CXR-Privacy-Lab/blob/2434a1e29533a74b7acc60a6799c8da550c91ac7/5%EC%B0%A8/README.md#reading-level-1) — 당시 6차까지의 설명이며 현재 7·8차 관측과 구분합니다.

| 구분 | 이 차수에서 하는 일 | 처음 읽을 때 확인할 뜻 |
| --- | --- | --- |
| 목적 | 4차에서 멈춘 COVID의 환자 충돌 중복도 제외하고 NIH 정제 정책을 이어 가는 후속 파생 실험입니다. | 배우는 작업인지 평가인지 먼저 구분합니다. |
| 입력 | 보존한 NIH·COVID 원본과 검증 스냅샷을 사용합니다.<br>스냅샷은 앞서 확인한 영상 내용과 제외 규칙의 기록이며 현재 원본 바이트를 다시 검사합니다. | 사진·목록·모델·설정의 역할은 다릅니다. |
| 처리 | NIH34장 제외를 유지하고 COVID의 서로 다른 환자 충돌 4장을 평가 집합에서 제외합니다.<br>정제 명세를 통과한 뒤에만 새 모델 학습과 평가로 넘어갑니다. | 화면과 계산 프로그램을 혼동하지 않습니다. |
| 설정·조건 | COVID781장 중 허용 777장·검증 1,534 쌍(양성 772/음성 762)·유효 질의 508개로 분리합니다.<br>NIH 허용 112,086장, 시드 3·배치 32·입력 작업자 0을 유지합니다. | 설정 숫자는 성능 숫자가 아닙니다. |
| 출력 | `5차/work/runs/<UUID>`의 기록·가중치·평가를 사용합니다.<br>당시 백분율 표시는 둘째 자리 버림과 원값 펼침이며 6차부터 첫째 자리 반올림으로 바뀝니다. | 파일이 있어야 측정 값을 읽을 수 있습니다. |
| 과거·현재 관측 | 준비 완료와 첫 가중치 적용을 구분하는 새 경로를 구현했습니다.<br>이후 연결 실행에서 학습 기록이 남았으나 CUDA 오류 등 운영 실패를 최종 성능 재현으로 해석하지 않습니다. | 이 차수에서 확인한 범위까지만 말합니다. |
| 한계 | 정제한 시험 분모와 검증 메모리 차단은 저 자 원본 조건과 다릅니다.<br>미측정 수치를 0으로 채우지 않고 단순 손실 값을 정확도로 환산하지 않습니다. | 후속 차수의 해결을 과거에 소급하지 않습니다. |
| 실행·검사 | run_experiment.py --validated-snapshot <현재 연구 자료 안의 스냅샷>은 원영상 SHA256·정제 명세 재확인 후에만 진행합니다.<br>정제·체크포인트·새 실행 경계·표시 원값 검사를 확인합니다. | 공개 설명만으로 의료 실험을 실행할 수 있는지 확인합니다. |

**읽는 예:**4차가 NIH 사진의 중복을 정리한 뒤 COVID 외부 시험 자료에서 같은 사진에 다른 환자 표기가 있는 문제로 멈췄습니다. 5차는 그 문제 사진도 원본을 보관한 채 시험 목록에서 제외합니다. 외부 시험은 학습에 쓰지 않은 다른 자료에서 잘 작동하는지 보는 확인입니다.

스냅샷은 특정 시점의 검사 결과를 묶어 둔 기록입니다. 기록이 있다는 이유만으로 지금 사진도 같다고 믿지 않고, 원본 파일의 SHA256이라는 내용 지문을 다시 비교합니다. 지문이 다르거나 검사 명세가 맞지 않으면 모델 학습으로 넘어가지 않습니다.

**숫자 읽기:**777장은 정리한 COVID 사진 수이고 1,534는 두 사진을 묶은 검증 쌍 수 라 단위가 다릅니다. 같은 사진이 여러 쌍에 나올 수 있습니다. 5차의 옛 화면은 백분율 둘째 자리 아래를 버렸고 6차부터 반올림 방식으로 바뀌었습니다. 표시 변경 때문에 원래 측정값을 바꾸지 않습니다.

**결과 보고:** 저장된 측정값과 논문 기준을 구분합니다. 손실은 시험 정확도가 아니며 PrivacyScore @1은 고정 공격의 1 순위 실패율입니다. 이 값만으로 익명성·임상 효용을 보장하지 않습니다. 의료 영상·개인별 목록·모델 가중치·운영 원문은 공개하지 않습니다.

COVID는 777 영상·1,534 검증 쌍·508 유효 질의처럼 과제마다 분모가 달라한 수량으로 합치지 않습니다.

이전 스냅샷 재사용은 디코드 결과의 재활용이지 현재 파일 확인의 생략이 아닙니다.

원영상 SHA와 제외 명세가 다시 맞아야 모델 학습을 허용하고 실제 첫 적용 기록을 준비 완료와 구분합니다.

숫자 표시 방식도 저장 수치와 별도의 층입니다.

<a id="-실행"></a>
## 실행

프로젝트 상위의 `실행 환경/Scripts/python.exe`로 `run_experiment.py`를 실행합니다.

대시보드는 Node.js로 `server.mjs`를 실행하고 로컬 포트 8787에서 확인합니다.

데이터는 기존 프로젝트의 `연구 자료/`를 사용하고 실행별 학습·체크포인트·기록은 `5차/work/runs/<실행 UUID>/`에 새로 저장합니다.

과거 실행에서 자동 재개하지 않습니다.

학습 전 데이터의 실제 확보·손상·환자 분리 검증과 GPU 연산 확인이 필요합니다. 화면의 준비 중은 학습 중을 뜻하지 않습니다. 모델 학습 실패나 현재 실행이 생성하지 않은 가중치에서는 평가를 시작하지 않습니다. 기존 1차와 감사 보고서 2차는 보존합니다.

학습은 원 논문 시드 3 과 배치 32를 사용합니다.

현재 GPU에서는 검색 네트워크의 활성 값 재계산을 켜고, 재계산 중 BatchNorm 통계와 난수 상태를 보존합니다.

혼합 정밀도 초기 배율의 overflow는 가중치 갱신 없이 상태를 복원하고 배율을 낮춘 뒤 같은 배치를 재시도합니다.

유한 손실·기울기를 확인한 뒤 optimizer와 스케줄러를 한 번 갱신합니다.

이 포팅 조건을 원 논문 실행 환경과 구분해 기록합니다.

원 공식 검색 코드의 validation CBM 메모리 갱신은 이번 구현에서 차단합니다. 검증 영상이 다음 학습 큐에 섞이지 않도록 한 의도된 변경이며, 원 논문 주요 학습 조건에 누수 방어를 보완한 재학습으로 구분합니다. 모든 코드 동작과 환경이 원본과 동일한 재현이라고 표현하지 않습니다.

## 실제 데이터에서 확인한 중복

NIH 원본 112,120장을 모두 디코딩한 결과 손상은 0개, 정확히 같은 픽셀의 중복은 25 그룹 51장이었습니다. 이 중 14 그룹은 환자 기록 충돌·분할 중복 또는 평가의 동일 영상 비교 문제로 준비 단계에서 차단됐습니다. 원본과 이 실패 기록은 보존합니다.

서로 다른 환자로 기록된 동일 영상 8 그룹 17장은 모두 실험 목록에서 제외하고, 같은 환자의 동일 영상 17 그룹 34장은 파일명 순으로 한 장씩 남깁니다. 총 34장을 제외한 112,086장이 파생 허용 집합입니다. 원 논문과 달라진 데이터 조건이며, 공식 목록을 그대로 사용한 성능 재현으로 표현하지 않습니다.

검증 모델의 분할은 학습 75,690장·검증 10,811장·시험 25,585장입니다.

학습은 남은 양성 395,926 쌍과 에폭마다 생성하는 음성 395,926 쌍을 사용합니다.

검색 학습은 중복 제외 후 새로 생긴 단일 영상 환자도 학습 자격에서 구분해 61,735장입니다.

최종 준비 검증과 실제 실행 기록에서 이 수량과 동일 픽셀 잔여 중복 0을 다시 확인해야 합니다.

## 수치 표시와 원값 보존

백분율은 소수 둘째 자리까지 버려 표시하고, 같은 행에서 저장된 원비율과 전체 정밀도의 원값을 펼쳐 확인할 수 있게합니다.

검색 성공률은 원비율을 백분율로 바꾸고 프라이버시 점수는 이미 0~100 인 단위를 유지합니다.

AUC·손실·학습률의 표시 자릿수와 원값도 구분합니다.
