### LEVEL 1 · 목적과 대상

**이 차수의 목적과 실제 구성**

공개 CXR 최종 가중치를 평가하는 경로와 새로운 학습 경로를 분리했습니다.

데이터 준비·검증이 끝나면 검증 모델, 검색 모델 출력부, 검색 모델 전체를 순서대로 학습하고 이 실행에서 생성한 가중치로 원본·블러·모자이크를 평가합니다. ImageNet 초기화는 논문상 설정이며 CXR 최종 가중치 재사용과 구분합니다.

흉부 엑스레이를 흐리게 하거나 모자이크로 바꿔도 같은 환자의 다른 사진을 찾아낼 수 있는지 살피는 실험입니다. 검증은 두 사진이 같은 사람인지 비교하고, 검색은 여러 사진 중 같은 사람을 찾는 작업입니다. **화면의 변환 미리보기는 평가 결과가 아닙니다.**

### LEVEL 1 · 달라진 내용과 차수 관계

COVID 충돌 영상으로4차 준비가 차단된 뒤 원본을 보존하고 정제 평가 집합을 파생합니다. 준비·첫 갱신·학습 종료를 따로 확인합니다.

어떤 사진이 누구의 것인지 다시 찾는 것이 재식별입니다. 흐리게 한 사진을 모델에 넣고 같은 환자의 다른 촬영 사진이 검색되는지 봅니다. 자기 사진을 그대로 정답 후보에 두면 쉬운 비교가 되므로 제외합니다.

### LEVEL 1 · 입력과 실행 조건

NIH 원본 112,120장을 모두 디코딩한 결과 손상은 0개, 정확히 같은 픽셀의 중복은 25그룹 51장이었습니다. 이 중 14그룹은 환자 기록 충돌·분할 중복 또는 평가의 동일 영상 비교 문제로 준비 단계에서 차단됐습니다. 원본과 이 실패 기록은 보존합니다.

서로 다른 환자로 기록된 동일 영상 8그룹 17장은 모두 실험 목록에서 제외하고, 같은 환자의 동일 영상 17그룹 34장은 파일명 순으로 한 장씩 남깁니다. 총 34장을 제외한 112,086장이 파생 허용 집합입니다.

원 논문과 달라진 데이터 조건이며, 공식 목록을 그대로 사용한 성능 재현으로 표현하지 않습니다.

검증 모델의 분할은 학습 75,690장·검증 10,811장·시험 25,585장입니다. 학습은 남은 양성 395,926쌍과 에폭마다 생성하는 음성 395,926쌍을 사용합니다. 검색 학습은 중복 제외 후 새로 생긴 단일 영상 환자도 학습 자격에서 구분해 61,735장입니다.

최종 준비 검증과 실제 실행 기록에서 이 수량과 동일 픽셀 잔여 중복 0을 다시 확인해야 합니다.

4차 준비 실행은 COVID 시험 영상에서 서로 다른 환자 기록의 정확 픽셀 중복을 발견해 중단됐으며, 그 실행에서 실제 학습은 시작하지 않았습니다. 5차는 NIH의 파생 정제 정책을 유지하고 COVID의 충돌 영상도 원본을 보존한 채 평가용 파생 집합에서 제외합니다. 원본 공식 수량과 정제 후 평가 분모를 구분하며, 준비 완료·학습 첫 갱신·학습 종료는 각각 실제 기록으로 확인합니다.

이전 준비 결과를 사용할 때에도 `run_experiment.py --validated-snapshot <현재 연구 자료 안의 검증 스냅샷>`은 현재 원영상 전체 SHA256과 정제 명세 검증을 먼저 수행합니다. 검증이 실패하면 새 학습이나 평가를 시작하지 않습니다. 실제 가중치 갱신이 0회이면 화면에 첫 갱신 대기를 표시하며, 갱신 수가 기록되지 않았다면 확인 전으로 표시합니다.

원영상 확보와 손상·중복 검사를 먼저 하고, 문제가 없을 때 모델을 학습합니다. 이후 원본과 변형 사진을 같은 모델로 비교합니다. 결과가 없거나 다른 실행의 파일이면 화면에 이전 숫자를 가져오지 않습니다.

### LEVEL 1 · 처리 절차

프로젝트 상위의 `실행 환경/Scripts/python.exe`로 `run_experiment.py`를 실행합니다. 대시보드는 Node.js로 `server.mjs`를 실행하고 로컬 포트 8787에서 확인합니다. 데이터는 기존 프로젝트의 `연구 자료/`를 사용하고 실행별 학습·체크포인트·기록은 `5차/work/runs/<실행 UUID>/`에 새로 저장합니다. 과거 실행에서 자동 재개하지 않습니다.

학습 전 데이터의 실제 확보·손상·환자 분리 검증과 GPU 연산 확인이 필요합니다. 화면의 준비 중은 학습 중을 뜻하지 않습니다. 모델 학습 실패나 현재 실행이 생성하지 않은 가중치에서는 평가를 시작하지 않습니다. 기존 1차와 감사 보고서 2차는 보존합니다.

학습은 원 논문 시드 3과 배치 32를 사용합니다. 현재 GPU에서는 검색 네트워크의 활성값 재계산을 켜고, 재계산 중 BatchNorm 통계와 난수 상태를 보존합니다.

혼합정밀도 초기 배율의 overflow는 가중치 갱신 없이 상태를 복원하고 배율을 낮춘 뒤 같은 배치를 재시도합니다. 유한 손실·기울기를 확인한 뒤 optimizer와 스케줄러를 한 번 갱신합니다. 이 포팅 조건을 원 논문 실행환경과 구분해 기록합니다.

원 공식 검색 코드의 validation CBM 메모리 갱신은 이번 구현에서 차단합니다. 검증 영상이 다음 학습 큐에 섞이지 않도록 한 의도된 변경이며, 원 논문 주요 학습 조건에 누수 방어를 보완한 재학습으로 구분합니다. 모든 코드 동작과 환경이 원본과 동일한 재현이라고 표현하지 않습니다.

프로젝트 폴더는 `흉부 엑스레이 환자 재식별 실험`이며 기존 1~4차를 보존합니다. 5차의 화면은 `화면/`, 실험은 `실험 코드/`, 검사는 `검사/`, 문서는 `문서/`에 있습니다. 공통 폴더는 `연구 자료/`, `실행 환경/`, `공개 코드/`, `화면 검증/`, `작업 기록/`입니다. 내부 `work/`는 실행 중 변경되는 작업 기록 폴더로 유지합니다.

- 대시보드: `대시보드_시작.cmd` → `http://127.0.0.1:8787`
- 데이터 준비와 새 학습·평가: `실험 코드/전체_실험_시작.cmd`
- 다운로드·전수 검사만: `실험 코드/데이터_준비.cmd`
- 확보된 데이터 검사만: `실험 코드/데이터_검사.cmd`
- 단계별 수동 평가: `실험 코드/흉부_엑스레이_3단계_실험.ipynb`. 5차 또는 실험 코드 폴더에서 열고 새 학습 가중치 두 개를 지정합니다.

현재 RAM 여유가 낮게 관측되어 실행 관리자는 학습에 `--num-workers 0`을 지정합니다. 입력을 같은 프로세스에서 처리하며 배치 32·손실·분할·시드 3·에폭 기준은 변경하지 않습니다. 이는 검사 import 지연을 해결했다는 주장이 아닙니다. 5차의 학습 시작·첫 가중치 갱신·완료는 실제 실행 증거를 따로 확인합니다.

Python 모듈·패키지·의존성 및 도구 고정 이름(`cxr_reid`, `training`, `main.py`, `requirements.txt`, `settings.json`, `test_*.py`, `.codex`, `README.md` 등)은 실행 계약 때문에 유지합니다. 의료 원영상과 비공개 기록은 공개하지 않습니다.

모션 버튼의 전역 호버 배경 충돌을 분리하고 44px 클릭 영역, 고정 스위치 크기, 키보드 포커스와 양쪽 테마의 경계를 보완했습니다. 실제 화면 검증 결과와 소스 검사는 구분합니다.

대시보드를 여는 것과 학습을 시작하는 것은 다릅니다. 해당 차수의 시작 파일과 준비·실행 안내를 따릅니다. 움직이는 그림을 멈춰도 실제 실험은 계속되며, 대기 화면을 학습 완료로 보지 않습니다.

### LEVEL 1 · 결과를 확인하는 방법

프라이버시 점수 `100 × (1 − CMC@1)`는 고정된 공격 모델과 검색 집합에서의 1순위 재식별 실패율입니다. 익명성 보장·차등 프라이버시·법적 적합성·진단 효용을 뜻하지 않습니다.

자기 원본은 검색에서 제외하며 같은 환자의 다른 촬영 영상으로 재식별을 평가합니다. 환자별 영상 수와 질의 분모를 함께 기록합니다.

백분율은 소수 둘째 자리까지 버려 표시하고, 같은 행에서 저장된 원비율과 전체 정밀도의 원값을 펼쳐 확인할 수 있게 합니다. 검색 성공률은 원비율을 백분율로 바꾸고 프라이버시 점수는 이미 0~100인 단위를 유지합니다. AUC·손실·학습률의 표시 자릿수와 원값도 구분합니다. 표시 과정에서 CSV·JSON 결과 원본을 바꾸거나 미측정 값을 0으로 대체하지 않습니다.

수치는 실제 결과 파일에서 읽습니다. 2026-11-13 확인한 연결 실험은 CUDA 오류로 중단된 상태였습니다. 화면을 새로 꾸몄다고 학습이 다시 시작되거나 높은 성능이 나온 것은 아닙니다.

### LEVEL 1 · 주의할 범위

검사와 독립 검토 결과는 실제 실행 뒤 별도로 기록합니다. 합성 GPU 역전파 성공과 실제 NIH 학습, 학습 종료와 원 논문 수치 재현은 각각 구분합니다. Windows·Python3.12·PyTorch2.7.1 환경은 원 논문 환경과 동일하지 않습니다.

의료 원영상·영상별 목록·환자 식별자·학습 가중치·실행 로그·개인 지침은 공개하지 않습니다. 제공 패키지 자체의 재배포 권한이 확인되지 않은 평가 엔진은 로컬에서 보존하며 공개 대상에서 보류합니다.

의료 원영상·환자 식별자·가중치는 공개하지 않습니다. 중복 영상 때문에 준비가 중단된 과거 기록도 남아 있습니다. **좋은 프라이버시 점수가 법적 익명화나 진단 가능성을 보장하지 않습니다.**

### LEVEL 2 · 입력과 실행 조건

NIH 원본 112,120장을 모두 디코딩한 결과 손상은 0개, 정확히 같은 픽셀의 중복은 25그룹 51장이었습니다. 이 중 14그룹은 환자 기록 충돌·분할 중복 또는 평가의 동일 영상 비교 문제로 준비 단계에서 차단됐습니다. 원본과 이 실패 기록은 보존합니다.

원 논문과 달라진 데이터 조건이며, 공식 목록을 그대로 사용한 성능 재현으로 표현하지 않습니다.

4차 준비 실행은 COVID 시험 영상에서 서로 다른 환자 기록의 정확 픽셀 중복을 발견해 중단됐으며, 그 실행에서 실제 학습은 시작하지 않았습니다. 5차는 NIH의 파생 정제 정책을 유지하고 COVID의 충돌 영상도 원본을 보존한 채 평가용 파생 집합에서 제외합니다. 원본 공식 수량과 정제 후 평가 분모를 구분하며, 준비 완료·학습 첫 갱신·학습 종료는 각각 실제 기록으로 확인합니다.

### LEVEL 2 · 처리 절차

프로젝트 상위의 `실행 환경/Scripts/python.exe`로 `run_experiment.py`를 실행합니다. 대시보드는 Node.js로 `server.mjs`를 실행하고 로컬 포트 8787에서 확인합니다. 데이터는 기존 프로젝트의 `연구 자료/`를 사용하고 실행별 학습·체크포인트·기록은 `5차/work/runs/<실행 UUID>/`에 새로 저장합니다. 과거 실행에서 자동 재개하지 않습니다.

학습 전 데이터의 실제 확보·손상·환자 분리 검증과 GPU 연산 확인이 필요합니다. 화면의 준비 중은 학습 중을 뜻하지 않습니다. 모델 학습 실패나 현재 실행이 생성하지 않은 가중치에서는 평가를 시작하지 않습니다. 기존 1차와 감사 보고서 2차는 보존합니다.

혼합정밀도 초기 배율의 overflow는 가중치 갱신 없이 상태를 복원하고 배율을 낮춘 뒤 같은 배치를 재시도합니다. 유한 손실·기울기를 확인한 뒤 optimizer와 스케줄러를 한 번 갱신합니다. 이 포팅 조건을 원 논문 실행환경과 구분해 기록합니다.

### LEVEL 2 · 결과를 확인하는 방법

프라이버시 점수 `100 × (1 − CMC@1)`는 고정된 공격 모델과 검색 집합에서의 1순위 재식별 실패율입니다. 익명성 보장·차등 프라이버시·법적 적합성·진단 효용을 뜻하지 않습니다.

자기 원본은 검색에서 제외하며 같은 환자의 다른 촬영 영상으로 재식별을 평가합니다. 환자별 영상 수와 질의 분모를 함께 기록합니다.

백분율은 소수 둘째 자리까지 버려 표시하고, 같은 행에서 저장된 원비율과 전체 정밀도의 원값을 펼쳐 확인할 수 있게 합니다. 검색 성공률은 원비율을 백분율로 바꾸고 프라이버시 점수는 이미 0~100인 단위를 유지합니다. AUC·손실·학습률의 표시 자릿수와 원값도 구분합니다. 표시 과정에서 CSV·JSON 결과 원본을 바꾸거나 미측정 값을 0으로 대체하지 않습니다.

프라이버시 점수 100×(1−CMC@1)는 1순위 재식별 실패율입니다. 정확도·F1·AUC와 검색 순위 지표는 별도로 읽습니다. 백분율은 소수 첫째 자리 반올림이며 원값·전체 자릿수를 펼쳐 확인합니다.

### LEVEL 3 · 입력과 실행 조건

NIH 원본 112,120장을 모두 디코딩한 결과 손상은 0개, 정확히 같은 픽셀의 중복은 25그룹 51장이었습니다. 이 중 14그룹은 환자 기록 충돌·분할 중복 또는 평가의 동일 영상 비교 문제로 준비 단계에서 차단됐습니다. 원본과 이 실패 기록은 보존합니다.

서로 다른 환자로 기록된 동일 영상 8그룹 17장은 모두 실험 목록에서 제외하고, 같은 환자의 동일 영상 17그룹 34장은 파일명 순으로 한 장씩 남깁니다. 총 34장을 제외한 112,086장이 파생 허용 집합입니다.

원 논문과 달라진 데이터 조건이며, 공식 목록을 그대로 사용한 성능 재현으로 표현하지 않습니다.

검증 모델의 분할은 학습 75,690장·검증 10,811장·시험 25,585장입니다. 학습은 남은 양성 395,926쌍과 에폭마다 생성하는 음성 395,926쌍을 사용합니다. 검색 학습은 중복 제외 후 새로 생긴 단일 영상 환자도 학습 자격에서 구분해 61,735장입니다.

최종 준비 검증과 실제 실행 기록에서 이 수량과 동일 픽셀 잔여 중복 0을 다시 확인해야 합니다.

4차 준비 실행은 COVID 시험 영상에서 서로 다른 환자 기록의 정확 픽셀 중복을 발견해 중단됐으며, 그 실행에서 실제 학습은 시작하지 않았습니다. 5차는 NIH의 파생 정제 정책을 유지하고 COVID의 충돌 영상도 원본을 보존한 채 평가용 파생 집합에서 제외합니다. 원본 공식 수량과 정제 후 평가 분모를 구분하며, 준비 완료·학습 첫 갱신·학습 종료는 각각 실제 기록으로 확인합니다.

이전 준비 결과를 사용할 때에도 `run_experiment.py --validated-snapshot <현재 연구 자료 안의 검증 스냅샷>`은 현재 원영상 전체 SHA256과 정제 명세 검증을 먼저 수행합니다. 검증이 실패하면 새 학습이나 평가를 시작하지 않습니다. 실제 가중치 갱신이 0회이면 화면에 첫 갱신 대기를 표시하며, 갱신 수가 기록되지 않았다면 확인 전으로 표시합니다.

NIH는 112,120장 중 중복 정책으로 34장을 제외해 112,086장 파생 집합을 만듭니다. 검증 분할 75,690/10,811/25,585장, 학습 양성·음성 각 395,926쌍, 검색 학습 61,735장의 실제 조건을 확인합니다.

### LEVEL 3 · 처리 절차

프로젝트 상위의 `실행 환경/Scripts/python.exe`로 `run_experiment.py`를 실행합니다. 대시보드는 Node.js로 `server.mjs`를 실행하고 로컬 포트 8787에서 확인합니다. 데이터는 기존 프로젝트의 `연구 자료/`를 사용하고 실행별 학습·체크포인트·기록은 `5차/work/runs/<실행 UUID>/`에 새로 저장합니다. 과거 실행에서 자동 재개하지 않습니다.

### LEVEL 3 · 결과를 확인하는 방법

프라이버시 점수 `100 × (1 − CMC@1)`는 고정된 공격 모델과 검색 집합에서의 1순위 재식별 실패율입니다. 익명성 보장·차등 프라이버시·법적 적합성·진단 효용을 뜻하지 않습니다.

백분율은 소수 둘째 자리까지 버려 표시하고, 같은 행에서 저장된 원비율과 전체 정밀도의 원값을 펼쳐 확인할 수 있게 합니다. 검색 성공률은 원비율을 백분율로 바꾸고 프라이버시 점수는 이미 0~100인 단위를 유지합니다. AUC·손실·학습률의 표시 자릿수와 원값도 구분합니다. 표시 과정에서 CSV·JSON 결과 원본을 바꾸거나 미측정 값을 0으로 대체하지 않습니다.

환자별 영상 수와 유효 질의 분모, 검증 쌍의 수를 지표 옆에서 확인합니다. 반올림100.0%와 실제 원비율1을 구분하고 결과 CSV·JSON을 표시 목적으로 수정하지 않습니다. 미측정·대기·정의 불가를 남깁니다.

데이터 준비·검증이 끝나면 검증 모델, 검색 모델 출력부, 검색 모델 전체를 순서대로 학습하고 이 실행에서 생성한 가중치로 원본·블러·모자이크를 평가합니다. ImageNet 초기화는 논문상 설정이며 CXR 최종 가중치 재사용과 구분합니다.

검증 네트워크와 검색 네트워크의 학습·평가 경계를 분리합니다. 검색 출력부→검색 전체 학습은 같은 실행에서 이어지지만 검증 모델은 별도입니다. 누수 방어를 보완한 포팅이므로 원 논문 모든 동작과 동일한 재현은 아닙니다.

### LEVEL 4 · 달라진 내용과 차수 관계

COVID 충돌 영상으로4차 준비가 차단된 뒤 원본을 보존하고 정제 평가 집합을 파생합니다. 준비·첫 갱신·학습 종료를 따로 확인합니다.

변형 조건마다 공격자를 다시 학습하는 실험이 아니라 NIH 원영상으로 학습한 같은 최종 가중치를 고정해 비교합니다. 변형에 적응한 공격자 평가는 별도 설계입니다. 프라이버시와 식별 성능의 정의를 이 공격 범위에 묶습니다.

### LEVEL 4 · 입력과 실행 조건

NIH 원본 112,120장을 모두 디코딩한 결과 손상은 0개, 정확히 같은 픽셀의 중복은 25그룹 51장이었습니다. 이 중 14그룹은 환자 기록 충돌·분할 중복 또는 평가의 동일 영상 비교 문제로 준비 단계에서 차단됐습니다. 원본과 이 실패 기록은 보존합니다.

서로 다른 환자로 기록된 동일 영상 8그룹 17장은 모두 실험 목록에서 제외하고, 같은 환자의 동일 영상 17그룹 34장은 파일명 순으로 한 장씩 남깁니다. 총 34장을 제외한 112,086장이 파생 허용 집합입니다.

원 논문과 달라진 데이터 조건이며, 공식 목록을 그대로 사용한 성능 재현으로 표현하지 않습니다.

검증 모델의 분할은 학습 75,690장·검증 10,811장·시험 25,585장입니다. 학습은 남은 양성 395,926쌍과 에폭마다 생성하는 음성 395,926쌍을 사용합니다. 검색 학습은 중복 제외 후 새로 생긴 단일 영상 환자도 학습 자격에서 구분해 61,735장입니다.

최종 준비 검증과 실제 실행 기록에서 이 수량과 동일 픽셀 잔여 중복 0을 다시 확인해야 합니다.

4차 준비 실행은 COVID 시험 영상에서 서로 다른 환자 기록의 정확 픽셀 중복을 발견해 중단됐으며, 그 실행에서 실제 학습은 시작하지 않았습니다. 5차는 NIH의 파생 정제 정책을 유지하고 COVID의 충돌 영상도 원본을 보존한 채 평가용 파생 집합에서 제외합니다. 원본 공식 수량과 정제 후 평가 분모를 구분하며, 준비 완료·학습 첫 갱신·학습 종료는 각각 실제 기록으로 확인합니다.

이전 준비 결과를 사용할 때에도 `run_experiment.py --validated-snapshot <현재 연구 자료 안의 검증 스냅샷>`은 현재 원영상 전체 SHA256과 정제 명세 검증을 먼저 수행합니다. 검증이 실패하면 새 학습이나 평가를 시작하지 않습니다. 실제 가중치 갱신이 0회이면 화면에 첫 갱신 대기를 표시하며, 갱신 수가 기록되지 않았다면 확인 전으로 표시합니다.

ImageNet ResNet-50 초기화와 새 출력층을 사용하며 공개 CXR 최종 가중치를 초기값으로 재사용하지 않습니다. 시드3·배치32, 활성값 재계산 시 BN·난수 상태 보존과 overflow 복구를 구분합니다. validation CBM 갱신 차단은 의도된 누수 방어입니다.

### LEVEL 4 · 처리 절차

프로젝트 상위의 `실행 환경/Scripts/python.exe`로 `run_experiment.py`를 실행합니다. 대시보드는 Node.js로 `server.mjs`를 실행하고 로컬 포트 8787에서 확인합니다. 데이터는 기존 프로젝트의 `연구 자료/`를 사용하고 실행별 학습·체크포인트·기록은 `5차/work/runs/<실행 UUID>/`에 새로 저장합니다. 과거 실행에서 자동 재개하지 않습니다.

학습 전 데이터의 실제 확보·손상·환자 분리 검증과 GPU 연산 확인이 필요합니다. 화면의 준비 중은 학습 중을 뜻하지 않습니다. 모델 학습 실패나 현재 실행이 생성하지 않은 가중치에서는 평가를 시작하지 않습니다. 기존 1차와 감사 보고서 2차는 보존합니다.

학습은 원 논문 시드 3과 배치 32를 사용합니다. 현재 GPU에서는 검색 네트워크의 활성값 재계산을 켜고, 재계산 중 BatchNorm 통계와 난수 상태를 보존합니다.

혼합정밀도 초기 배율의 overflow는 가중치 갱신 없이 상태를 복원하고 배율을 낮춘 뒤 같은 배치를 재시도합니다. 유한 손실·기울기를 확인한 뒤 optimizer와 스케줄러를 한 번 갱신합니다. 이 포팅 조건을 원 논문 실행환경과 구분해 기록합니다.

원 공식 검색 코드의 validation CBM 메모리 갱신은 이번 구현에서 차단합니다. 검증 영상이 다음 학습 큐에 섞이지 않도록 한 의도된 변경이며, 원 논문 주요 학습 조건에 누수 방어를 보완한 재학습으로 구분합니다. 모든 코드 동작과 환경이 원본과 동일한 재현이라고 표현하지 않습니다.

### LEVEL 4 · 결과를 확인하는 방법

프라이버시 점수 `100 × (1 − CMC@1)`는 고정된 공격 모델과 검색 집합에서의 1순위 재식별 실패율입니다. 익명성 보장·차등 프라이버시·법적 적합성·진단 효용을 뜻하지 않습니다.

같은 최종 두 가중치를 원본·블러·모자이크에 고정하므로 관측 차이는 해당 고정 공격의 조건부 결과입니다. 변형 미리보기·합성 GPU 검사·실제 NIH 학습·전체 평가 종료를 분리합니다. CUDA 중단 이력을 화면 수정의 성공으로 덮지 않습니다.

프로젝트 상위의 `실행 환경/Scripts/python.exe`로 `run_experiment.py`를 실행합니다. 대시보드는 Node.js로 `server.mjs`를 실행하고 로컬 포트 8787에서 확인합니다. 데이터는 기존 프로젝트의 `연구 자료/`를 사용하고 실행별 학습·체크포인트·기록은 `5차/work/runs/<실행 UUID>/`에 새로 저장합니다. 과거 실행에서 자동 재개하지 않습니다.

학습 전 데이터의 실제 확보·손상·환자 분리 검증과 GPU 연산 확인이 필요합니다. 화면의 준비 중은 학습 중을 뜻하지 않습니다. 모델 학습 실패나 현재 실행이 생성하지 않은 가중치에서는 평가를 시작하지 않습니다. 기존 1차와 감사 보고서 2차는 보존합니다.

학습은 원 논문 시드 3과 배치 32를 사용합니다. 현재 GPU에서는 검색 네트워크의 활성값 재계산을 켜고, 재계산 중 BatchNorm 통계와 난수 상태를 보존합니다.

혼합정밀도 초기 배율의 overflow는 가중치 갱신 없이 상태를 복원하고 배율을 낮춘 뒤 같은 배치를 재시도합니다. 유한 손실·기울기를 확인한 뒤 optimizer와 스케줄러를 한 번 갱신합니다. 이 포팅 조건을 원 논문 실행환경과 구분해 기록합니다.

원 공식 검색 코드의 validation CBM 메모리 갱신은 이번 구현에서 차단합니다. 검증 영상이 다음 학습 큐에 섞이지 않도록 한 의도된 변경이며, 원 논문 주요 학습 조건에 누수 방어를 보완한 재학습으로 구분합니다. 모든 코드 동작과 환경이 원본과 동일한 재현이라고 표현하지 않습니다.

## 실제 데이터에서 확인한 중복

NIH 원본 112,120장을 모두 디코딩한 결과 손상은 0개, 정확히 같은 픽셀의 중복은 25그룹 51장이었습니다. 이 중 14그룹은 환자 기록 충돌·분할 중복 또는 평가의 동일 영상 비교 문제로 준비 단계에서 차단됐습니다. 원본과 이 실패 기록은 보존합니다.

서로 다른 환자로 기록된 동일 영상 8그룹 17장은 모두 실험 목록에서 제외하고, 같은 환자의 동일 영상 17그룹 34장은 파일명 순으로 한 장씩 남깁니다. 총 34장을 제외한 112,086장이 파생 허용 집합입니다.

원 논문과 달라진 데이터 조건이며, 공식 목록을 그대로 사용한 성능 재현으로 표현하지 않습니다.

검증 모델의 분할은 학습 75,690장·검증 10,811장·시험 25,585장입니다. 학습은 남은 양성 395,926쌍과 에폭마다 생성하는 음성 395,926쌍을 사용합니다. 검색 학습은 중복 제외 후 새로 생긴 단일 영상 환자도 학습 자격에서 구분해 61,735장입니다.

최종 준비 검증과 실제 실행 기록에서 이 수량과 동일 픽셀 잔여 중복 0을 다시 확인해야 합니다.
