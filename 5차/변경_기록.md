# 5차 변경 기록

4차의 데이터 준비 실행은 NIH 원파일 112,120개의 SHA를 확인한 뒤 COVID 외부검증 영상의 환자 충돌 중복 2그룹을 찾아 중단했습니다. 이 차수는 원본과 1~4차를 보존하고, 외부 평가도 같은 중복 제거 원칙을 적용합니다.

- COVID 원본 781장 중 서로 다른 환자로 기록된 동일 픽셀 4장을 모두 제외하는 파생 집합을 구성합니다. 허용777장·445명, 검증1,534쌍(양성772·음성762), 유효 검색 질의508장의 실제 분모를 기록합니다.
- 공식781장·1,548쌍과 원 blocking2 기록을 보존합니다. 별도 고정 원근거·파생 schema·현재781개 원파일 SHA·정책 재계산·보고서 결합으로 임의 목록 편집과 검사 우회를 차단합니다.
- 외부 verification과 retrieval이 같은 허용 집합을 사용합니다. NIH 학습·검증·시험의 기존34장 제외 정책과 모델·손실·배치·시드 조건은 유지합니다.
- 실행기와 화면의 차수를5차로 연결하고 실제0회 갱신과 아직 기록되지 않은 값을 구분합니다. 기존 snapshot 재사용도 검증 성공 전에는 학습으로 넘어가지 않습니다.
- 노트북의 현재 폴더 오류 안내를5차로 맞췄습니다. 기존 흰색·회청색, 양쪽 테마와 모션 조작부 수정은 유지합니다.

실제 학습 시작은 새 실행의 초기화 기록·첫 유한 기울기·출력층 변경·진행1회 이상을 확인한 뒤 판정합니다. 전체 학습과 성능 재현은 별도 결과입니다. 원영상·영상별 목록·가중치·비공개 운영 기록과 재배포 권한이 불명확한 평가 엔진은 공개하지 않습니다.

## 수치 표시와 원값 보존

백분율은 소수 둘째 자리까지 버려 표시하고, 같은 행에서 저장된 원비율과 전체 정밀도의 원값을 펼쳐 확인할 수 있게 합니다. 검색 성공률은 원비율을 백분율로 바꾸고 프라이버시 점수는 이미 0~100인 단위를 유지합니다. AUC·손실·학습률의 표시 자릿수와 원값도 구분합니다. 표시 과정에서 CSV·JSON 결과 원본을 바꾸거나 미측정 값을 0으로 대체하지 않습니다.

합성 COVID 검사에서 외장 HDD 임시 파일 생성이 주요 지연으로 측정돼 시스템 임시 폴더를 사용하도록 조정했습니다. 원영상 위치·검사 대상 781개·변조 차단 기준과 정식 제한시간은 유지합니다.
