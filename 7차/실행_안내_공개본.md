# CXR7 — 새 원본 기준 실험 + 블러·모자이크 대조 실험

로컬의 기존 NIH ChestX-ray14와 COVID-19 Image Data Collection **두 데이터셋만** 사용합니다.
새 원본 기준 모델을 먼저 학습·평가하고, 그 모델을 고정한 채 블러·모자이크 강도별로 평가합니다.
논문 성능을 실제 얻었는지는 평가 결과로 확인해야 하며, 코드만으로 같은 숫자를 보장하지 않습니다.

## 1. 가장 간단한 실행

1. `CXR7_AllInOne_Start.cmd` 하나를 다운로드합니다.
2. 더블클릭합니다. Python 코드를 붙여 넣거나 파일을 직접 편집할 필요가 없습니다.
3. 실행기가 아래 폴더를 만들고 내장 코드를 검증·설치한 뒤 진행합니다.

```text
E:\2026\흉부 엑스레이 환자 재식별 실험\7차
```

최초 실행 시 **공식 ImageNet ResNet-50 초기 가중치**를 받을 때 인터넷이 필요할 수 있습니다.
코드·원 저자 분할 목록·자동 테스트는 CMD 안에 포함되어 있습니다.
이미지 데이터와 CUDA/Python 환경은 포함하지 않으며, 기존 E: 경로를 사용합니다.
관리자 권한 승격이나 보안 설정 변경을 요구하지 않습니다. 권한 문제가 있으면 중단하고 표시합니다.

ZIP을 이용한다면 내용물이 `7차\src`, `7차\All-In-One.ps1`, `7차\Start-CXR7.cmd`가 되도록 풀고
`Start-CXR7.cmd`를 실행하세요. ZIP과 단일 CMD는 같은 코드입니다. 둘을 동시에 실행하지 마세요.

## 2. 자동 실행 순서와 기존 실험 보존

| 순서 | 동작 |
|---|---|
| 1 | 코드·라이브러리·자동 테스트·저자 분할·필요한 이미지 파일 존재 여부 검사 |
| 2 | 기존 UUID `비공개 실행 식별자`의 6차 관리자와 학습만 확인하여 중지 |
| 3 | GPU 메모리 및 정식 해상도·배치의 합성 입력 순전파·역전파 점검 |
| 4 | 새 UUID의 7차 폴더 생성, 고정 대표 원본 사진 저장 |
| 5 | Verification 학습 → Retrieval phase1 → Retrieval phase2 |
| 6 | 원본 NIH·COVID 평가, NIH 논문 기준 수치와 차이 저장 |
| 7 | 전체 블러 조건 → 전체 모자이크 조건, 대표사진·측정 결과 순차 저장 |

사전 검사가 실패하면 6차는 건드리지 않습니다. 과거 PID `운영 PID 비공개`만 보고 종료하지 않습니다.
Python 경로·학습 스크립트·UUID 출력 경로·생성 시각·명령행으로 해당 실행의 정체를 확인합니다.
확인된 재개 관리자를 먼저 중지하고 학습에는 `STOP_REQUESTED`를 보냅니다.
최대 60초 후에도 살아 있으면 정체를 재확인한 해당 프로세스만 종료합니다.

기존 5차·6차 데이터·체크포인트·결과는 삭제하지 않습니다.
강제 중지가 필요하면 마지막 저장 이후 미저장 연산은 보존되지 않을 수 있습니다.
정체가 불명확한 관리자나 권한 문제가 있으면 무리하게 종료하지 않고 중단합니다.
예전 대시보드의 `Active`는 남을 수 있으나 실행기는 실제 프로세스를 확인합니다.
드물게 종료 유예 중 새로 만들어진 CPU 작업자가 남을 수 있어 모든 자식 종료까지 보장하지는 않습니다.

기존 7차 코드가 있으면 `7차\backups\package-...`에 보존합니다. `7차\runs`의 결과는 교체하지 않습니다.
기존 7차 실행 중에는 코드 교체·중복 실행을 차단합니다.

6차의 중복 제거 후 목록 대신 **저자 원본 목록**으로 시작합니다.
누락된 이미지를 건너뛰거나 다른 데이터로 채우지 않습니다. 이미지를 복사·이동·재다운로드하지 않습니다.

분할 목록의 SHA-256·레코드 수와 이미지 존재 여부를 확인합니다. 원본 데이터 전체의 픽셀 해시 재검사는 아닙니다.
실험 중 원본 이미지·라벨·코드를 변경하지 마세요. 대표 사진 두 원본은 별도 SHA-256으로 고정합니다.

## 4. 원본 기준 실험

| 항목 | 설정 |
|---|---|
| 기준 | Packhäuser 등, Scientific Reports 2022; 저자 commit `880168f564afa07936a8d8fb3b868b140ab937d9` |
| 초기값 | 공식 ImageNet ResNet-50.<br>기존 6차 또는 공개 최종 CXR 모델을 이어받지 않음 |
| Verification | Siamese ResNet-50, 256×256, 배치 32, Adam, 학습률 0.0001 |
| Verification 데이터 | RNP: 양성 쌍 유지, 학습·검증 음성 쌍을 매 epoch 다시 구성 |
| Verification 종료 | 최대 100 epoch, 검증 손실 5회 연속 비개선 시 조기 종료, 최저 검증 손실 모델 선택 |
| Retrieval | ResNet-50 + 128차원 head, 1024×1024, 배치 32 |
| Retrieval 학습 | phase1 30 → phase2 50 epoch, SGD, 최대 LR0.158489, weight decay0.00001, OneCycle |
| Retrieval 손실 | 원본 PML0.9.94 ContrastiveLoss/CrossBatchMemory, 메모리 128, mining block8 |
| 정밀도 | 검증 모델 FP32; 검색 모델 학습 FP16 mixed precision |
| 작업자 | verification16, retrieval4; seed3 |

배치·해상도를 몰래 줄이지 않습니다. 메모리가 부족하면 이유를 남기고 중단합니다.
검색 학습에는 활성값 재계산으로 메모리를 절약하고, 재계산 때문에 BN 이동통계가 두 번 갱신되지 않도록 처리했습니다.
Retrieval은 각 phase의 마지막 epoch 모델을 사용합니다. GPU 점검 성공이 모든 장시간 실행의 성공을 보장하지는 않습니다.

NIH 논문 비교 기준은 **AUC0.9940, verification Accuracy0.9555, retrieval P@1=0.9963,
mAP@R=0.9748, R-Precision0.9763**입니다. 논문 수치이지 이 패키지가 이미 달성한 결과가 아닙니다.
Loss를 Accuracy로 환산하지 않습니다. 실제 값과 차이는 `evaluation_results.json`에 저장합니다.
논문 수치에 맞추기 위해 테스트셋을 보고 자동 재학습·설정 조정·수치 변경을 하지 않습니다.
블러·모자이크 단계에 진입했다는 것이 원본 성능의 동등성 합격을 뜻하지는 않습니다.

현대 PyTorch/CUDA·Windows·RTX4090으로 옮긴 구현이며 역사적 난수 흐름·연산 환경까지 같지는 않습니다.
같게 맞춘 점과 남은 차이는 `원본_설계_비교.md`를 참고하세요.
원 저자 검색 코드는 검증 임베딩도 같은 CrossBatchMemory에 넣습니다. 이 동작을 유지했으므로
새로 설계한 완전한 누수 방지 프로토콜이라고 설명해서는 안 됩니다.

## 5. 블러·모자이크 대조 실험

각각 `0, 1, 2, 4, 8, 16, 32, 64, 128, 256` 강도입니다.
원본 모델·시험 목록·원본 갤러리를 **고정**하고 질의 영상 변환만 바꿉니다. 강도마다 재학습하지 않습니다.

- 블러는 기존 `PIL.ImageFilter.GaussianBlur(radius=강도)` 유지.
- 모자이크는 기존 원본 좌표계 타일 크기, BOX 축소 → NEAREST 확대 유지.
- 모델 입력 크기로 줄이기 **전 원본 영상**에 변환합니다. 특징맵 블러를 사용한 별도 CT 실험과 다릅니다.
- Verification: 변환된 왼쪽 영상과 원본 오른쪽 영상 비교.
- Retrieval: 변환 질의와 원본 갤러리 비교. **같은 촬영 이미지 자체는 제외**하고 같은 환자의 다른 영상 검색.
- 원본·blur0·mosaic0·mosaic1은 픽셀상 동일하므로 측정된 원본 결과를 재사용했다고 표시합니다.
  나머지 17개 조건은 실제 변환 추론을 수행합니다.

21 조건 × 2 데이터 셋 × 2 과제여서 진행률의 `total_task_conditions`는 **84**입니다.
완성 CSV는 **42개 데이터 행**이며 각 행에 두 과제 결과가 들어갑니다.
블러·모자이크 결과가 원본과 비슷해야 한다는 합격 기준은 없습니다.

`PrivacyScore@1 = 100 × (1 − 실제 P@1)`은 이 실험의 설명용 점수입니다.
차등프라이버시·비식별화 인증·복원 불가능성·질병 진단 성능 보장이 아닙니다. 환자 매칭은 영상 복원과 다른 과제입니다.

## 6. 같은 원본을 사용한 단계별 대표사진

`7차\runs\실행UUID\대표사진` 한 폴더 아래에 모입니다.

| 하위 폴더/파일 | 내용 |
|---|---|
| `대표사진\NIH` | 고정 NIH 한 장의 원본 1 + 블러 10 + 모자이크 10 |
| `대표사진\COVID19` | 고정 COVID 한 장의 원본 1 + 블러 10 + 모자이크 10 |
| `대표사진\index.json` | 원본 파일명·해시, 조건, PNG 해시, 크기 |

총 **42 PNG**입니다. 파일명은 `00_original.png`, `01_blur_000.png`, …, `10_blur_256.png`,
`11_mosaic_000.png`, …, `20_mosaic_256.png`입니다.

모델 결과를 보기 전에 저자 시험 목록의 파일명 순서로 한 장을 정하고 모든 조건에 동일하게 씁니다.
원본 해상도 PNG로 저장하고 글자나 장식을 영상 위에 덧씌우지 않습니다.
원본은 본학습 전, 변환 사진은 해당 조건 평가에 진입할 때 저장합니다.
**사진 생성만으로 지표 평가 완료를 뜻하지 않습니다.** 한 과제가 미완료면 CSV 상태는 `pending`입니다.
누락된 출력 사진은 재개 시 생성하지만 원본이나 기존 사진 내용이 바뀌면 중단합니다.

## 7. 확인·재개 및 결과 위치

설치 후 7차 폴더에서 아래 파일을 더블 클릭하세요.

| 실행 파일 | 동작 |
|---|---|
| `Start-CXR7.cmd` | 새 UUID로 처음부터.<br>기존 결과 보존 |
| `Resume-CXR7.cmd` | 현재 7차 실행만 재개 |
| `Monitor-CXR7.cmd` | 약 2초 간격 진행·GPU 조회.<br>Ctrl +C는 모니터만 닫음 |
| `Check-CXR7.cmd` | 사전 검사만. 6차 중지·7차 학습 안 함 |

단일 CMD에 `check`, `monitor`, `resume` 인수를 줘도 됩니다.

```bat
CXR7_AllInOne_Start.cmd check
CXR7_AllInOne_Start.cmd monitor
CXR7_AllInOne_Start.cmd resume
```

단일 CMD를 인수 없이 다시 더블 클릭하면 **재개가 아닌 새 실행**입니다.
이미 7차가 실행 중이면 중복 실행을 거부합니다. 재개는 코드·설정·분할·환경 바인딩이 같을 때만 허용합니다.
중간 배치 재개는 worker 증강 난수 스트림까지 연속 실행과 비트 단위로 같지는 않습니다.

아래는 `7차\runs\실행UUID` 안에 저장됩니다.

| 파일/폴더 | 내용 |
|---|---|
| `progress.json`, `events.jsonl` | 단계·epoch·batch·loss·평가 진행 |
| `verification`, `retrieval_phase1`, `retrieval_phase2` | last/epoch 체크포인트, 선택 가중치 |
| `evaluation_results.json` | 원본 성능, AUC CI, NIH 논문 수치 대비 차이 |
| `privacy_results.json`, `privacy_results.csv` | 원본·블러·모자이크 측정 및 완료 상태 |
| `대표사진` | 고정 원본별 42 PNG와 출처·해 시 |
| `training.stdout.log`, `evaluation.stdout.log`, `privacy.stdout.log` | 단계별 실행 로그 |
| `training_config.json`, `preflight.json`, `artifacts.json` | 설정·사전 검사·선택 모델 증거 |

진행 JSON 시각은 UTC, 모니터 상단 시각은 Windows 로컬 시각입니다.
합성 GPU 점검은 `runs\smoke-...`에 별도로 저장하며 연구 결과로 세지 않습니다.
원본 임베딩만 `privacy_cache`에 캐시하고 전체 변환 영상 데이터셋은 만들지 않습니다.
새 결과·프로그램 캐시·임시 파일은 7차 아래에 둡니다.

## 8. 검증 범위와 오류

실제 수행한 검증과 미수행 항목은 `검증_범위_원본.md`에 있습니다.
CPU 합성 테스트 통과는 논문 성능 재현이나 Windows GPU 전체 실행 성공을 뜻하지 않습니다.

- 원본 파일 누락: 오류의 NIH/COVID 경로와 파일명을 확인합니다.
- GPU 메모리 부족: 다른 GPU 작업을 직접 확인합니다. 관계없는 프로세스는 자동 종료하지 않습니다.
- 관리자 정체 확인 실패: 로그 확인 후 기존 6차 실행 창에서 직접 종료해야할 수 있습니다.
- 의존성 오류: 기존 환경을 자동 변경하지 않습니다. `requirements-runtime.txt`는 검증 환경 참고용입니다.
- 코드 변경으로 재개 거부: 다른 결과가 섞이지 않도록 차단한 것입니다. 기존 결과를 보존하고 새 실행을 사용하세요.
