## LEVEL 1 - Beginner · 배경과 용어부터 읽기

| 구분 | 이 차수에서 하는 일 | 처음 읽을 때 확인할 뜻 |
| --- | --- | --- |
| 목적 | 저자 원본 NIH·COVID 목록과 공개 공식 구현을 기준으로 ImageNet 초기값에서 새로 학습하는 Windows 포팅입니다. | 배우는 작업인지 평가인지 먼저 구분합니다. |
| 입력 | NIH112,120장·COVID781장과 저자 공식 목록을 사용하며 이전 정 제112,086/777 집합이나 5차 CXR 가중치를 이어받지 않습니다.<br>COVID는 외부 시험용입니다. | 사진·목록·모델·설정의 역할은 다릅니다. |
| 처리 | 검증 학습 →검색 출력 부 30에폭 →검색 전체 50에폭 뒤 원본 평가와 변환 평가를 합니다.<br>원본·블러 0·모자이크 0·모자이크 1은 측정한 원본 결과를 재사용하고 나머지 17 조건은 추론합니다. | 화면과 계산 프로그램을 혼동하지 않습니다. |
| 설정·조건 | 검증 256px·배치 32·Adam1e-4·최대 100 에폭·patience5·최저 검증 손실 선택; 검색 1024px·128차원·SGD momentum0.9·weight decay1e-5·OneCycle 최대 0.158489·블록 8·CBM128·입력 작업자16/4입니다. | 설정 숫자는 성능 숫자가 아닙니다. |
| 출력 | `7차/runs/<UUID>`에 진행·이벤트·체크포인트·원본 성능 JSON·변환 CSV/JSON·대표 사진을 저장합니다. 21 조건 ×2 데이터셋 ×2 과제 =84과 제 조건이며 CSV는 42 행입니다. | 파일이 있어야 측정 값을 읽을 수 있습니다. |
| 과거·현재 관측 | 공식 코드와 설정·손실·샘플링을 대조하고 학습을 진행 중입니다.<br>검증 모델의 손실·처리 배치 관측은 있으나 전체 학습 종료·원본 성능·변환 전체 완료·논문 재현은 미확인입니다. | 이 차수에서 확인한 범위까지만 말합니다. |
| 한계 | 원본 중복과 검증 중 동일 CBM 큐 갱신을 유지합니다.<br>논문 본문의 고정 검증 설명과 달리 공식 randomized 코드는 검증 음성도 에폭마다 다시 만듭니다.<br>Windows·동률·난수·신뢰구간 차이와 CheXpert 미수행이 남습니다. | 후속 차수의 해결을 과거에 소급하지 않습니다. |
| 실행·검사 | 로컬 Start-CXR7.cmd는 새 실행, Resume-CXR7.cmd는 현재 실행 재개, Check-CXR7.cmd는 사전 검사입니다.<br>All-In-One.ps1의 start/resume과 체크포인트 결합·손실/기울기·분할·재개 검사를 구분합니다.<br>공개 소스는 제공하지만 의료 목록·전체 실행 관리 패키지·가중치는 포함하지 않으므로 공개 사본만으로 전체 실험을 바로 실행할 수 없습니다. | 공개 설명만으로 의료 실험을 실행할 수 있는지 확인합니다. |

**읽는 예:**7차는 이전에 정리한 사진 목록과 모델을 그대로 이어 쓰는 대신 저자가 공개한 원래 목록을 사용해 새로 배우는 실험입니다.

초기값은 일반 사진으로 배운 ImageNet 모델이며, 의료 사진에서 이미 답을 배운 최종 CXR 모델이 아닙니다.

NIH로 학습·내부 시험을 하고 COVID는 외부 시험으로 남깁니다.

아래 용어 표의 설정은 점수를 높이기 위한 사후 조정값이 아니라 미리 정한 학습 규칙입니다. 검증 모델은 학습 중 따로 보는 자료의 손실이 가장 낮은 상태를 선택하고, 검색 모델은 정한 각 과정의 마지막 상태를 사용합니다. 손실은 틀림의 크기를 나타내는 학습 신호이며 시험 정확도와 같은 숫자가 아닙니다.

**원본에 가깝다는 뜻의 한계:**같은 사진의 중복을 일부러 지우지 않고 공식 코드가 검증 중 기억 공간을 바꾸는 동작도 유지했습니다.

이전 누수 방어 차수보다 무조건 안전해진 것이 아닙니다.

논문 글은 고정 검증을 설명하지만 채택한 공식 코드 분기는 검증의 다른 환자 쌍도 매번 다시 만듭니다.

설정·입력·코드 중 무엇을 맞췄는지 구분해야 합니다.

학습 뒤 21 종류 사진 조건을 두 데이터셋과 두 과제로 시험하므로 84개 과제·조건입니다. CSV42 행은 한 행에 검증·검색 결과 둘을 담기 때문에 더 적습니다. 원본과 픽셀이 같은 변환은 이미측정한 원본 결과를 재사용했다고 적으며 사진 42장이 생성된 것만으로 평가 84개가 끝났다고 하지 않습니다.

### LEVEL 1 · 설정 용어를 하나씩 풀어 읽기

| 용어·설정 | 쉬운 뜻 |
| --- | --- |
| 검증·검색 | 검증은 두 사진이 같은 환자인지 묻고, 검색은 한 사진과 같은 환자의 다른 사진을 후보에서 찾습니다. |
| 에폭·배치 | 에폭은 학습 목록을 한 차례 도는 단위이고 배치는 한 번에 처리하는 사진 묶음입니다.<br>배치 32와 에폭 100은 서로 다른 단위입니다. |
| Adam·학습률 0.0001 | 학습 오차를 보고 모델 숫자를 고치는 규칙입니다.<br>Adam은 과거 변화도 참고하며 학습률은 한 번에 고치는 크기의 기준입니다. |
| SGD·momentum0.9 | 검색 모델 숫자를 고치는 다른 규칙입니다. momentum은 앞서 움직이던 방향을 일부 이어가 흔들림을 줄이는 설정입니다. |
| weight decay 0.00001 | 모델 숫자가 지나치게 커지지 않도록 학습에 붙이는 규칙입니다.<br>그 자체가 시험 성능이나 익명성 보장은 아닙니다. |
| OneCycle·최대 학습률 0.158489 | 학습 과정에서 고치는 크기를 정해진 일정으로 올렸다 낮추는 방법입니다.<br>시험 결과를 보고 임의 조정하는 것이 아닙니다. |
| 128차원·출력 부 | 사진을 비교하기 위한 128개 숫자의 특징으로 바꾸는 마지막 부분입니다.<br>먼저 출력 부를 30에폭, 이어 전체를 50에폭 학습합니다. |
| 블록 8 | 저자 방식에서 학습 사진을 8개 단위 블록으로 구성하는 규칙입니다.<br>환자별 사진 수와 남는 사진 처리도 함께 적용하며 배치 32를 8로 줄인 뜻이 아닙니다. |
| CBM128·검증 큐 | 최근 사진 특징 128 칸을 기억해 새 특징과 함께 비교하는 장치입니다. 7차는 검증용 사진을 볼 때도 같은 기억 공간을 갱신하므로 검증과 학습의 영향이 완전히 분리됐다고 말할 수 없습니다. |
| patience5·검증 손실 | 따로 보는 자료의 오차가 5번 연속 좋아지지 않으면 검증 모델 학습을 멈춥니다.<br>가장 낮은 검증 오차 상태를 고르며 시험 정답률을 보고 고르지 않습니다. |
| RNP·randomized | 같은 환자 사진 쌍은 유지하고 다른 환자 사진 쌍은 에폭마다 다시 묶습니다.<br>채택한 공식 코드에서는 검증용 음성 쌍도 바뀝니다. |
| AMP·overflow | 숫자를 작은 정밀도로 계산해 메모리를 절약하는 방식입니다.<br>숫자가 유효 범위를 벗어나면 그 배치의 모델 수정은 생략할 수 있어 처리 배치 수와 실제 적용 횟수가 다릅니다. |
| bootstrap·신뢰구간 | 시험 사진 쌍을 겹침을 허용해 10,000번 다시 뽑아 AUC 변동 폭을 살펴봅니다.<br>같은 환자의 연관성을 묶어 다시 뽑는 방식은 아니므로 오차 범위의 한계가 있습니다. |
| AUC·P @1·mAP @R·R-Precision | AUC는 같은/다른 환자 점수의 구별 정도, P @1은 맨 앞 후보 성공률입니다.<br>나머지 두 값은 여러 정답 후보의 순위·앞쪽 포함 정도를 평가하며 각 분모를 함께 읽어야합니다. |
| 가중치·체크포인트·UUID | 가중치는 배운 모델 숫자, 체크포인트는 모델·학습 상태 저장, UUID는 실행들을 섞지 않는 고유 표지입니다. |
| PrivacyScore @1 | 100×(1 −검색 P @1), 즉 고정 공격의 1 순위 실패율입니다.<br>사진이 완전히 익명화됐다는 보증이나 질병 진단 점수가 아닙니다. |

**결과 보고:** 저장된 측정값과 논문 기준을 구분합니다. 손실은 시험 정확도가 아니며 PrivacyScore @1은 고정 공격의 1 순위 실패율입니다. 이 값만으로 익명성·임상 효용을 보장하지 않습니다. 의료 영상·개인별 목록·모델 가중치·운영 원문은 공개하지 않습니다.

7차는 **저자 목록·학습 규칙·모델 선택·고정 모델 변환 평가**를 하나의 출처 계약으로 묶습니다.

검증의 RNP는 같은 환자 양성 쌍을 유지하고 다른 환자 음성 쌍을 다시 구성하는 방식이며 채택한 공식 분기는 학습뿐 아니라 검증 음성도 바꿉니다.

검색은 128차원 표현을 대조 손실로 학습하고 CBM 큐로 최근 특징을 함께 비교합니다.

검증 때 같은 큐가 바뀌는 공식 동작을 보존하므로 이 설계를 완전한 누수 방지로 해석할 수 없습니다.

모델 선택을 마친 뒤에는 시험 결과를 보고 강도별 재학습이나 임계값 조정을 하지 않습니다.

여기서 OneCycle은 학습률의 시간표, CBM은 최근 특징을 저장하는 큐, 블록 8은 배치 순서를 구성하는 규칙입니다.

서로 다른 기능이므로 한 수치를 바꾸면 손실 입력과 최적화 경로가 함께 달라질 수 있습니다. bootstrap은 시험 쌍 재표집으로 AUC의 변동 범위를 추정하며 환자 집단 재표집이 아니라는 점을 지표와 함께 읽습니다.

**결과 보고:** 저장된 측정값과 논문 기준을 구분합니다. 손실은 시험 정확도가 아니며 PrivacyScore @1은 고정 공격의 1 순위 실패율입니다. 이 값만으로 익명성·임상 효용을 보장하지 않습니다. 의료 영상·개인별 목록·모델 가중치·운영 원문은 공개하지 않습니다.

## LEVEL 5 - Expert · 전체 상세와 근거

## 7차 — 저자 원본 목록 기반 새 학습

원 저자의 NIH·COVID 목록과 학습 구성을 기준으로 새 ImageNet 초기값에서 시작하는 Windows 포팅입니다. 이전 5차 모델을 이어받거나 공개 최종 CXR 가중치만 평가하는 경로가 아닙니다.

검증은 256px·배치 32·Adam0.0001·최대 100 에폭·patience5·최저 검증 손실 모델 선택입니다. 검색은 1024px·128차원·30/50에폭·SGD momentum0.9·weight decay1e-5·OneCycle maxLR0.158489·block8·CBM128을 사용합니다.

로컬 7차 All-In-One.ps1의 start는 새 실행, resume은 현재 실행의 바인딩된 체크포인트 재개입니다. 화면 모니터는 조회 전용입니다. runs/<UUID>에 진행 JSON·이벤트·가중치·원본 평가·변환 평가를 저장합니다. 이 공개 설명에는 의료 목록·가중치·운영 로그·대표 사진을 포함하지 않습니다.

원본 중복을 보존하고 공식 코드의 validation CBM 큐 갱신도 유지합니다. 새 누수 방어 실험이라고 부를 수 없습니다. Windows/RTX4090/PyTorch2·난수 호출·활성 값 재계산·거리 동률·bootstrap 구현 차이가 남고 CheXpert와 논문의 모든 분석은 수행하지 않습니다.

변환은 질의에만 적용하고 원본 갤러리를 고정합니다.

원본·블러 0·모자이크 0·모자이크 1은 픽셀 항등 조건으로 측정한 원본 결과를 재사용했다고 표시하며, 나머지 17 조건은 실제 추론합니다.

데이터셋 두 개의 42 행에 검증·검색 두 과제가 있어 84과 제 조건입니다.

대표 사진 42장은 처리 예시이며 평가 완료를 뜻하지 않습니다.

논문 본문은 균형 잡힌 고정 validation/testing 집합을 설명하지만, 공식 RNP randomized 구현은 validation 음성 쌍도 매 epoch 다시 만듭니다. 7차는 후자의 공식 구현 분기를 따르므로 본문과 코드가 모두 완전히 동일하다고 주장하지 않습니다.

공식 고정 커밋의 관련 파일과 로컬 참조 사본의 바이트 대조를 별도 검토했습니다.

## 공개 사본의 실행 범위

이 폴더는 의료 목록·가중치·설치 CMD와 운영 식별자가 내장된 `src/cxr7_process_guard.py` 및 해당 검사를 포함하지 않습니다. 완전한 실행 패키지가 아니므로 공개 사본만으로 학습을 시작할 수 있다고 해석하지 않습니다. 실제 학습의 원본 모듈과 실행 기록은 로컬 7차에 그대로 보존합니다.
