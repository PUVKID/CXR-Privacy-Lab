# 3차 변경 기록

## 변경 목적

감사에서 확인한 데이터 검증·검색 정규화·실행 보존 문제를 고치고 공개 CXR 최종 가중치 평가에서 새 모델 학습 후 평가로 실행 순서를 변경합니다.

## 현재 확정한 변경

- 실행 관리자는 CUDA 확인 → 데이터 준비와 검증 → 새 모델 학습 → 해당 실행의 가중치로 평가 순서를 강제합니다.
- 실행 UUID마다 새 출력 폴더를 만들고 공개 CXR 가중치나 이전 실행의 학습 체크포인트로 자동 재개하지 않습니다.
- 과거 실행의 결과를 현재 결과 표에 섞지 않으며 학습 상태·에폭·단계·손실을 별도로 표시합니다.
- 기존 Host·Origin 검사, 임의 명령·경로 입력 거부, 실행 ID 중단, 모션과 다크·라이트 전환을 유지합니다.
- 지표 설명은 고정 공격에서의 재식별 실패율로 한정합니다.

## 연구 엔진과 학습 포팅

- Verification·Retrieval의 공식 목록 차이를 별도 검증하고, 영상 전수 디코드와 정확 픽셀 중복·환자 분리 검사를 추가했습니다.
- 검색 L2 정규화와 고유 영상 키 동률 규칙을 적용하고 질의 분모·영벡터·동률을 기록합니다.
- 캐시 v4는 모델·영상·전처리·환경과 payload SHA·dtype·shape를 확인합니다. 불일치 파일은 격리 보존합니다.
- 결과를 실행별로 보존하고 재개 시 조건별 영수증·파일 해시를 확인합니다.
- 고정 원격 소스·메타데이터·다운로드 해시, 완료 partial416 처리와 중단 추출 prefix 보존·복원을 구현했습니다.
- CMD·노트북을 현재 경로와 학습 가중치 명시 선택에 맞췄습니다. 메모리·디스크 검사와 그래프 수식 글리프를 보완했습니다.
- PML0.9.94의 손실·임베딩 gradient·CBM 큐를 직접 대조한 131개 검사를 통과했습니다. 실제 GPU에서 배치32인 검증·검색 출력부·검색 전체의 합성 역전파를 확인했습니다.
- 검색 모델 전체 학습에 활성값 재계산을 적용하며 BatchNorm 상태·난수·기울기 보존을 검사했습니다. AMP 초기 overflow는 상태 복구·배율 backoff 후 같은 배치를 재시도하고 유한 갱신만 적용합니다.

엔진·학습 구현의 실제 전체 파일 비교를 [비교 설명](COMPARISON.md)에 연결합니다. 합성 검사와 실제 NIH 학습·논문 성능 재현을 구분하며 문서의 존재를 학습 실행·완료나 원격 반영 증거로 사용하지 않습니다.
