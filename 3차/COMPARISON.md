# 1차·2차 대비 3차 변경

2차는 읽기 전용 감사였으므로 연구 코드 비교 기준은 보존한 1차입니다. 3차는 새 모델 학습과 다음 평가를 연결하고 감사에서 확인한 문제를 수정합니다. 최초 공개 묶음에는 1·2·3차를 함께 보존하며 앞선 원격 커밋이 있었다고 가정하지 않습니다.

| 범위 | 변경과 이유 |
| --- | --- |
| 학습 | 공개 CXR 최종 가중치 대신 공식 ImageNet 초기값과 새 optimizer로 시작. RNP 검증 모델과 검색 출력부·전체 학습을 구현 |
| 데이터 범위 | Verification112120·Retrieval112118의 실제 공식 목록을 구분하고 2장의 차이를 고정 출처에 결합 |
| 누수 | 환자 분리·쌍 라벨·자기 이미지 제외·전수 디코드·정확 픽셀 중복 검사. 근사 중복 검사는 미실시로 명시 |
| 검색 | 공식 출력 L2 정규화, 영벡터 규칙과 고유 영상 키 기반 동률 순위·동률 보조 통계 |
| 결과 | 실행 UUID별 결과·provenance·조건별 영수증. 재개 시 설정·결과 해시 검증, 과거 파일 보존 |
| 캐시 | 모델·영상 내용·전처리·환경 출처와 payload SHA·dtype·shape를 결합. 불일치는 격리 보존 후 재계산 |
| 다운로드 | 고정 소스·메타데이터 해시, 완료 partial416 복구, 검증된 압축 앞부분과 일치하는 중단 추출 파일만 보존 후 복원 |
| 실행 | 현재 E 프로젝트와 runtime 경로, CMD 단일 진입, 노트북의 학습 가중치 명시 선택, 디스크·실측 GPU 검사 |
| 지표·그림 | 고정 공격의 Rank-1 실패율로 해석 한정, EER·CI·추가 해상도와 원 논문 범위 구분, 그래프 수식 글리프 수정 |
| 화면·관리 | 학습/준비/검증/평가 구분, 실제 에폭·단계·손실, 새 실행의 결과만 표시, 이전 차수 중단·보존 |

공개 가능한 본문 전체 비교는 [1차 대비 공개 코드 차이](comparison/1차_대비_공개코드.diff)에서 확인합니다. 공백·주석을 포함한 UTF-8 텍스트 차이를 저장하고 바이너리는 크기·SHA를 구분합니다. 비교 산출물 자신과 이 비교 설명은 자기 참조를 피하기 위해 해당 패치의 비교 대상에서 제외합니다.

제공 평가 패키지의 수정 원문과 의료 목록을 포함한 전체 비교는 재배포 권한 미확인·의료 자료 경계로 로컬에 보존합니다. 공개판에 원문이 없는 파일을 공개했다고 표현하지 않습니다. 새 학습 코드는 원 GPL·MIT 출처와 라이선스를 함께 보존합니다.

검사 통과는 실제 환자 데이터 학습 종료·논문 성능 재현을 뜻하지 않습니다. 합성 역전파와 실제 영상 학습을 구분합니다.
