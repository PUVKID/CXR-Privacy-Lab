## LEVEL 1 - Beginner · 배경과 용어부터 읽기

[11/13시점 원격 설명(보존) · 같은 LEVEL 1](https://github.com/PUVKID/CXR-Privacy-Lab/blob/2434a1e29533a74b7acc60a6799c8da550c91ac7/3%EC%B0%A8/README.md#reading-level-1) — 당시 6차까지의 설명이며 현재 7·8차 관측과 구분합니다.

| 구분 | 이 차수에서 하는 일 | 처음 읽을 때 확인할 뜻 |
| --- | --- | --- |
| 목적 | 공개 최종 가중치 평가와 별도로, ImageNet 초기값에서 CXR 모델을 새로 학습하는 경로를 만들었습니다. | 배우는 작업인지 평가인지 먼저 구분합니다. |
| 입력 | 확보한 원영상, 환자·분할 목록, 학습 설정과 ImageNet 초기값을 사용합니다.<br>이전 CXR 최종 모델의 성능을 새 학습 결과로 쓰지 않습니다. | 사진·목록·모델·설정의 역할은 다릅니다. |
| 처리 | 데이터 준비·검증과 GPU 확인 후 검증 모델→검색 출력부→검색 전체를 학습하고 이 실행이 만든 두 모델로 변환 평가를 진행합니다. | 화면과 계산 프로그램을 혼동하지 않습니다. |
| 설정·조건 | 시드 3·배치 32를 유지하고 검색의 활성 값 재계산을 사용합니다.<br>검증 중 CBM 기억 공간 갱신을 차단하는 누수 방어는 저자 코드와 의도적으로 다릅니다. | 설정 숫자는 성능 숫자가 아닙니다. |
| 출력 |실행마다 `3차/work/runs/<UUID>` 아래 학습 기록·체크포인트·평가 결과를 분리합니다.<br>자동으로 과거 실행을 이어받지 않습니다. | 파일이 있어야 측정값을 읽을 수 있습니다. |
| 과거·현재 관측 | 새 학습 경로와 감사 후 보완을 구현한 차수입니다.<br>합성 역전파·실제 학습 시작·학습 종료·논문 수치 재현은 각각 다른 확인 항목입니다. | 이 차수에서 확인한 범위까지만 말합니다. |
| 한계 | Windows·현대 PyTorch 환경, 활성값 재계산과 검증 메모리 차단 때문에 저자 실행과 완전히 같은 재현은 아닙니다.<br>재배포 권한 미확인 엔진은 공개 보류입니다. | 후속 차수의 해결을 과거에 소급하지 않습니다. |
| 실행·검사 | 로컬 상위 runtime/Scripts/python.exe로 run_experiment.py, Node로 server.mjs를 실행합니다.<br>연구 자료의 이전 이름은 research입니다.<br>검사·독립 검토는 해당 차수 명세로 확인합니다. | 공개 설명만으로 의료 실험을 실행할 수 있는지 확인합니다. |

**읽는 예:** 같은 환자의 다른 사진을 찾도록 직접 배우게하려면 학습용 사진과 시험용 사진을 먼저 나눠야합니다. 3차부터는 이미 완성된 CXR 모델을 시험하는 경로와, 일반 사진을 보고 배운 ImageNet 모델에서 의료 사진 학습을 새로 시작하는 경로를 분리했습니다.

검증 모델은 두 사진의 동일 환자 여부를 배우고 검색 모델은 후보를 잘 정렬하도록 배웁니다.

검색 출력부는 사진 특징을 최종 숫자 표현으로 바꾸는 부분이고 전체 학습은 그 앞의 영상 처리 부분도 조정합니다.

이 세 학습 과정 뒤에 원본·블러·모자이크 평가가 오는 것이므로, 원본 버튼을 고를 때마다 새 모델을 배우는 것이 아닙니다.

**중단을 이해하기:** 데이터 준비에 실패하면 뒤의 학습을 시작하지 않고, 학습에 실패하면 그 실행의 평가로 넘어가지 않습니다. 체크포인트는 다시 시작할 수 있도록 학습 상태를 저장한 파일입니다. GPU의 작은 모의 계산이 통과해도 오랜 실제 학습이나 논문의 높은 점수가 보장되지는 않습니다.

**결과 보고:** 저장된 측정값과 논문 기준을 구분합니다. 손실은 시험 정확도가 아니며 PrivacyScore @1은 고정 공격의 1 순위 실패율입니다. 이 값만으로 익명성·임상 효용을 보장하지 않습니다. 의료 영상·개인별 목록·모델 가중치·운영 원문은 공개하지 않습니다.

## LEVEL 2 - Explorer · 구성과 조건의 관계

[11/13시점 원격 설명(보존) · 같은 LEVEL 2](https://github.com/PUVKID/CXR-Privacy-Lab/blob/2434a1e29533a74b7acc60a6799c8da550c91ac7/3%EC%B0%A8/README.md#reading-level-2) — 당시 6차까지의 설명이며 현재 7·8차 관측과 구분합니다.

| 구성 요소 | 연결되는 자료·조건 | 해석 경계 |
| --- | --- | --- |
| 목적 | 공개 최종 가중치 평가와 별도로, ImageNet 초기값에서 CXR 모델을 새로 학습하는 경로를 만들었습니다. | 경로의 목적을 정하는 계약입니다. |
| 입력 | 확보한 원영상, 환자·분할 목록, 학습 설정과 ImageNet 초기값을 사용합니다.<br>이전 CXR 최종 모델의 성능을 새 학습 결과로 쓰지 않습니다. | 입력 출처가 바뀌면 결과 해석도 바뀝니다. |
| 처리 | 데이터 준비·검증과 GPU 확인 후 검증 모델→검색 출력부→검색 전체를 학습하고 이 실행이 만든 두 모델로 변환 평가를 진행합니다. | 앞 단계 통과가 뒤 단계의 전제입니다. |

| 출력 |실행마다 `3차/work/runs/<UUID>` 아래 학습 기록·체크포인트·평가 결과를 분리합니다.<br>자동으로 과거 실행을 이어받지 않습니다. | 상태·미리보기·지표는 다른 출력입니다. |
| 과거·현재 관측 | 새 학습 경로와 감사 후 보완을 구현한 차수입니다.<br>합성 역전파·실제 학습 시작·학습 종료·논문 수치 재현은 각각 다른 확인 항목입니다. | 관측과 기능 구현은 다른 증거입니다. |
| 한계 | Windows·현대 PyTorch 환경, 활성값 재계산과 검증 메모리 차단 때문에 저자 실행과 완전히 같은 재현은 아닙니다.<br>재배포 권한 미확인 엔진은 공개 보류입니다. | 같지 않은 조건은 비교에 명시합니다. |
| 실행·검사 | 로컬 상위 runtime/Scripts/python.exe로 run_experiment.py, Node로 server.mjs를 실행합니다.<br>연구 자료의 이전 이름은 research입니다.<br>검사·독립 검토는 해당 차수 명세로 확인합니다. | 검사 도구의 역할을 구분합니다. |

새 경로의 핵심은 **검증 통과를 다음 단계의 전제조건으로 두는 것**입니다.

데이터·GPU 확인 뒤 학습 3 과정을 순서대로 실행하고 현재 실행의 두 체크포인트가 있을 때만 평가합니다.

공개 최종 모델을 별도 경로에 두어 평가 재현과 새 학습을 섞지 않습니다.

검색 활성 값을 다시 계산하면 메모리가 줄지만 난수와 BatchNorm 이동 통계를 복원해야 같은 배치를 중복 학습하는 부작용을 막을 수 있습니다.

검증의 CBM 갱신 차단도 분리한 계약이며 원 저자 구현과 차이가 나는 이유입니다.

**결과 보고:** 저장된 측정값과 논문 기준을 구분합니다. 손실은 시험 정확도가 아니며 PrivacyScore @1은 고정 공격의 1 순위 실패율입니다. 이 값만으로 익명성·임상 효용을 보장하지 않습니다. 의료 영상·개인별 목록·모델 가중치·운영 원문은 공개하지 않습니다.

[11/13시점 원격 설명(보존) · 같은 LEVEL 5](https://github.com/PUVKID/CXR-Privacy-Lab/blob/2434a1e29533a74b7acc60a6799c8da550c91ac7/3%EC%B0%A8/README.md#reading-level-5) — 당시 6차까지의 설명이며 현재 7·8차 관측과 구분합니다.

<a id="-3차--학습부터-다시-수행하는-흉부-x-선-재식별-실험"></a>
## 3차 — 학습부터 다시 수행하는 흉부 X 선 재식별 실험

공개 CXR 최종 가중치를 평가하는 경로와 새로운 학습 경로를 분리했습니다. 데이터 준비·검증이 끝나면 검증 모델, 검색 모델 출력부, 검색 모델 전체를 순서대로 학습하고 이 실행에서 생성한 가중치로 원본·블러·모자이크를 평가합니다. ImageNet 초기화는 논문상 설정이며 CXR 최종 가중치 재사용과 구분합니다.

<a id="-실행"></a>
## 실행

프로젝트 상위의 `runtime/Scripts/python.exe`로 `run_experiment.py`를 실행합니다.

대시보드는 Node.js로 `server.mjs`를 실행하고 로컬 포트 8787에서 확인합니다.

데이터는 기존 프로젝트의 `research/`를 사용하고 실행별 학습·체크포인트·기록은 `3차/work/runs/<실행 UUID>/`에 새로 저장합니다.

과거 실행에서 자동 재개하지 않습니다.

학습 전 데이터의 실제 확보·손상·환자 분리 검증과 GPU 연산 확인이 필요합니다. 화면의 준비 중은 학습 중을 뜻하지 않습니다. 모델 학습 실패나 현재 실행이 생성하지 않은 가중치에서는 평가를 시작하지 않습니다. 기존 1차와 감사 보고서 2차는 보존합니다.

학습은 원 논문 시드 3 과 배치 32를 사용합니다.

현재 GPU에서는 검색 네트워크의 활성 값 재계산을 켜고, 재계산 중 BatchNorm 통계와 난수 상태를 보존합니다.

혼합 정밀도 초기 배율의 overflow는 가중치 갱신 없이 상태를 복원하고 배율을 낮춘 뒤 같은 배치를 재시도합니다.

유한 손실·기울기를 확인한 뒤 optimizer와 스케줄러를 한 번 갱신합니다.

이 포팅 조건을 원 논문 실행 환경과 구분해 기록합니다.

원 공식 검색 코드의 validation CBM 메모리 갱신은 이번 구현에서 차단합니다. 검증 영상이 다음 학습 큐에 섞이지 않도록 한 의도된 변경이며, 원 논문 주요 학습 조건에 누수 방어를 보완한 재학습으로 구분합니다. 모든 코드 동작과 환경이 원본과 동일한 재현이라고 표현하지 않습니다.

<a id="-지표-해석"></a>
## 지표 해석

프라이버시 점수 `100 × (1 − CMC@1)`는 고정된 공격 모델과 검색 집합에서의 1 순위 재식별 실패율입니다.

익명성 보장·차등 프라이버시·법적 적합성·진단 효용을 뜻하지 않습니다.

자기 원본은 검색에서 제외하며 같은 환자의 다른 촬영 영상으로 재식별을 평가합니다.

환자별 영상 수와 질의 분모를 함께 기록합니다.

<a id="-검증과-공개-경계"></a>
## 검증과 공개 경계

검사와 독립 검토 결과는 실제 실행 뒤 별도로 기록합니다. 합성 GPU 역전파 성공과 실제 NIH 학습, 학습 종료와 원 논문 수치 재현은 각각 구분합니다. Windows·Python3.12·PyTorch2.7.1 환경은 원 논문 환경과 동일하지 않습니다.

의료 원영상·영상별 목록·환자 식별자·학습 가중치·실행 로그·개인 지침은 공개하지 않습니다. 제공 패키지 자체의 재배포 권한이 확인되지 않은 평가 엔진은 로컬에서 보존하며 공개 대상에서 보류합니다.
