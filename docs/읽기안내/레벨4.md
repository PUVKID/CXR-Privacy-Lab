# 흉부 엑스레이 환자 재식별 실험 · LEVEL 4 - Advanced

## 현재 실행 정책 · 10차 처음부터

| 확인 대상 | 설명 |
| --- | --- |
| 현재 원본 | 7차 학습과 이전 대기열을 중단하고 보관했으며 10차 새 원본 original_000부터 시작합니다. |
| 21조건 초기화 | 원본 1·블러 10·모자이크 10의 21조건을 공통 ImageNet 초기값·시드3에서 각각 새로 학습합니다. |
| 이전 체크포인트 | 7차 완료를 기다리거나 이전 CXR 체크포인트를 넘겨받지 않습니다. |

| 구분 | 현재 동작 | 보존 범위 |
| --- | --- | --- |
| 상단 학습 |10차 새 원본의 진행·손실·실행 관측 |7차 기록을 현재 진행으로 대신 표시하지 않음 |
| 강도별 학습 |20조건 버튼과 새 원본 상세를 별도 조회 | 각 조건의 초기화·학습·같은 조건 평가만 결합 |
| 이전 7차 | 사용자 요청으로 중단한 보관 이력 | 고정 모델 84평가를 새 21모델 결과와 합치지 않음 |

아래 이전 설명의 ‘7차 유지·원본 완료 대기’는 재시작 요청 이전 설계로 보존하며 현재 동작을 뜻하지 않습니다.

새 실행의 준비·학습·완료 여부는 실제 기록으로 확인합니다.

외부 GPU 프로세스 목록은 관측 정보이며 CXR 중복 실행을 차단하고 기존 단계별 메모리 여유 기준은 유지합니다.

CPU 실변환 검사는 import 시간 상한으로 미완료이며 실제 21조건 학습 완료를 주장하지 않습니다.

입력 검증·학습 엔진·실행 관리자·대시보드의 경계를 나눕니다.

현재 상태와 과거 관측을 분리하고 가중치·설정·분할의 결합을 보존합니다.

비동기 읽기 실패를 정상 학습이나0% 성능으로 바꾸지 않습니다.

## 10차 강도별 독립 학습

이 절은 상단의 재시작 요청 이전 설계를 보존한 설명입니다.

현재 실행 정책은 맨 위의 「10차 처음부터」를 따르며, 아래의 7차 유지·원본 완료 대기는 당시 조건으로 읽습니다.

<a id="level-4--구성식별자-계약"></a>

### 구성·식별자 계약

| 확인 대상 | 설명 |
| --- | --- |
| 분리된 계약·사본 | 10차는 기존 소스와 운영 중인 7차를 수정하지 않고 별도 계약·학습 사본·순차 실행기·읽기 화면으로 구성합니다. |
| 조건 식별·재개 | 조건 식별자는 등록된 20개만 허용하며, 조건별 실행 경계와 지문이 맞아야 체크포인트를 재개합니다. |
| 다른 모델 승계 금지 | 원본 또는 다른 조건에서 학습한 모델 상태를 다음 조건의 초기값으로 쓰지 않습니다. |

<a id="level-49차-학습-진행-화면"></a>

## 9차 학습 진행 화면

9차는 기존 읽기 경계와 상태 판정 위에 **진행 계산·이력 전달·시각화 경계**를 추가합니다.

학습 소스·분할·손실·optimizer·scheduler는 이 화면 변경의 대상이 아닙니다.

| 구현 경계 | 검토할 계약 | 변경 영향 |
| --- | --- | --- |
| 진행 계산 | 에폭의 배치 비율과 단계 최대 에폭 비율을 구분 | 전체 시간 추정과 별개 |
| 완료 상태 | 현재 기록·저장 완료 근거·오래된 상태를 구분 | 실제 완료를 단순 최대 에폭 도달로 대체하지 않음 |
| 이력 전달 | 유한한 읽기 범위·정상 기록·단계·검증 구분 | 무제한 파일 전달과 누락을 0으로 메우는 처리를 금지 |
| 손실 표시 | 관측 구간·축·마지막 시각과 원값 유지 | 부분 이력을 전체 학습으로 오표시하지 않음 |
| 화면 동작 | 테마·모션·포커스·작은 폭과 선택 상태 | 조회 동작이 학습 제어로 번지지 않음 |

분모가 없는 기록은 unknown으로 유지해야 합니다.

단계 전환·재개·실패행의 0·중복 또는 불완전 기록은 현재 상태와 마지막 정상 관측을 구분하는 기존 어댑터 계약과 함께 검토합니다.

진행 막대의 값이 유한하다는 검사만으로 과학적 해석이 맞다고 판단하지 않습니다.

동일 실행의 표시 창과 숨김 학습 실행기는 별개 생명 주기를 가질 수 있습니다.

서버 재시작·브라우저 종료가 학습 종료 API가 되어서는 안 되며, 기존 프로세스 정체 확인·읽기 경로 제한은 유지합니다.

구체적 읽기 상한·계산 함수·회귀 결과는 9차 상세와 8 →9 전체 파일 비교에서 대조합니다.

<a id="level-4--책임-경계와-변경-비용"></a>

## 책임 경계와 변경 비용

현재 7차의 과학 계산을 8차 조회 변경과 분리합니다.

이전 차수의 엔진 재배포 보류와 현재 공개 문서·대시보드 소스 범위도 구별합니다.

아래 경계 중 하나가 바뀌면 해당 소비자·회귀와 출처 결합을 다시 확인해야 하며, UI 정상만으로 계산 계약을 승인하지 않습니다.

| 경계 | 현재 계약 | 의도된 선택·절충 | 검증할 실패 경로 |
| --- | --- | --- | --- |
| 원 목록과 파생 목록 | 7차는 NIH112,120/COVID781 저자 목록 | 4차부터 NIH112,086장 정제·5차부터 COVID777장 정제와 구분; 6차는 5차 연결, 3차는 중복 차단으로 준비 실패 | 분할·수량·SHA·환자 gate를 다른 과제 목록으로 대체하지 않음 |
| 검증 학습 | RNP·Adam·best-validation 선택 | 공식 randomized validation 음성 재생성;본문 고정 검증과 차이 | 시험으로 임계값/모델을 선택하지 않음 |
| 검색 학습 | PML0.9.94·CBM128·블록 8·30/50epoch | 공식 validation CBM enqueue 유지; 방어 차수와 반대 | 손실/기울기·queue wrap·샘플링·epoch 선택 대조 |
| 메모리·정밀도 | 활성 값 재계산·BN/RNG 보존·native AMP | overflow는 적용 생략; 이전차수동일배치재시도와 다름 | 처리배치 카운터를 적용 횟수로 오독하지 않음 |
| 평가 | 고정 모델·원본 gallery·질의 변형 | NumPy 제곱 L2·명시적자기대각제외·결정적 동률 | 원 FAISS 첫이웃제외/동률과의 차이·유효 질의 분모 |
| 신뢰구간 | 10,000회 pair bootstrap | 원 마지막 인덱스 제외 버그는 복제하지 않음 | 환자 cluster CI라고 보고하지 않음 |
| 8차 파일 어댑터 | UUID·고정 root·realpath·UTF8 엄격 해석 | JSONL256KiB tail로 전체 순회 회피 | 중간 손상·CSV 중복·불일치·NaN·누락을 완료로 채택하지 않음 |
| 프로세스 관측 | 정확 source/output/parent/creation +최근 진행 | CIM10초/GPU15초캐시; 불가시 미확인 | venvredirector와 실제 Python 중복 계산·오래된 JSON 실행 판정 방지 |
| 조작·표시 | 읽기 전용·원값·소수 첫째 자리 반올림 | 선택 DOM 보존·테마·모션 분리 | Host·CSP·경로 탐색·비GET 거부·포커스·원값 펼침 유지 |

결과 격리는 같은 UUID 아래에서도 과제·데이터셋·조건키를 함께 요구합니다.

CSV42 행과 84 과제 완료는 다른 축이며, 마지막 summary 하나나 report의 completed 플래그만으로 전체를 완료 처리하지 않습니다.

기준 평가가 먼저 끝나면 현재 artifacts의 모델 SHA와 일치한 원본 과제만 표시하고 변환 전체 완료로 확장하지 않습니다.

사진 42장도 지표의 완료 증거가 아닙니다.

오류의 placeholder0, 마지막 정상 이벤트, 저장 checkpoint는 별개 상태입니다.

AMP 때문에 global_step은 처리 배치일 수 있으므로 optimizer 적용 수를 추론하지 않습니다.

재개 전 코드·설정·목록·환경 binding을 유지하고 중간 배치의 worker 증강 난수 스트림이 비트 동일하지 않은 한계를 남깁니다.

Windows 원자 교체·파일 공유·권한·백신 원인은 실제 관측 없이 단정하지 않습니다.

정상 이력 truncation과 malformed 기록을 다른 사용자 안내로 분리하더라도 원래 JSONL 검증 정책은 유지합니다.

3차는 CBM 검증 혼입을 차단하고 정확 픽셀 중복을 엄격히 검사했으며 NIH 중복으로 준비가 실패했습니다.

4차는 NIH 허용 112,086장 파생 목록을 도입했지만 COVID 충돌로 준비가 중단됐습니다.

5차부터 COVID 허용 777장 정제를 추가했고, 6차 화면은 5차 실험에 연결됩니다.

7차는 저자 원본 정합성을 위해 원본 목록의 중복과 공식 검증 큐 갱신을 유지한 포팅입니다.

어느 쪽도 다른 쪽의 결과를 재현했다고 자동 주장하지 않습니다.

코드·CPU/GPU 소형 회귀·현재 학습 전진·전체 원본 평가·84 조건 완료·논문 수치 차이와 공식 코드/논문 차이를 단계별 증거로 분리합니다.

고정 공격의 PrivacyScore @1은 운영 지표이며 공식 익명성·임상 효용·법적 적합성 보장이 아닙니다.
