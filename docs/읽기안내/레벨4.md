## LEVEL 4 · 10차 강도별 독립 학습

**10차는 기존 소스와 운영 중인7차를 수정하지 않고 별도 계약·학습 사본·순차 실행기·읽기 화면으로 구성합니다.** 조건 식별자는 등록된20개만 허용하며, 조건별 실행 경계와 지문이 맞아야 체크포인트를 재개합니다. 원본 또는 다른 조건에서 학습한 모델 상태를 다음 조건의 초기값으로 쓰지 않습니다.

같은 조건의 검색 출력부→전체 네트워크 전환은 정상적인 내부 학습 연속성입니다. 조건이 바뀌면 모델과 학습 상태는 새로 생성합니다. ImageNet 초기값과 seed를 공통으로 쓰는 것은 비교 조건을 맞추기 위한 선택이며, 서로 다른 장치나 버전에서 비트 단위 동일성을 보장한다는 뜻이 아닙니다.

실행기 게이트는 원본 전체 정상 완료와 실제 프로세스 종료를 결합합니다. 원본 학습의 progress completed는 후속 평가 완료를 대신하지 않습니다. 큐의 대기·오류·실행 중 상태를 분리하고, 큐가 대기 중일 때 GPU에서 강도 학습이 진행되는 것으로 표시하지 않습니다. 오류를 무시하고 완료로 넘어가지 않습니다.

화면은 허용된 조건과 해당 실행 경계의 기록만 조회합니다. 조건을 바꿀 때 이전 값은 비우고 늦은 응답이 선택을 덮어쓰지 않도록 합니다. 최근 이력 범위와 원값을 유지하며, 불완전하거나 손상된 기록에서 곡선을 발명하지 않습니다. 실제 소스·검사·직전 비교는 아래10차 자료를 통해 확인하며, 전체 실험 완료와 검사의 성공을 구분합니다.

## LEVEL 4 · 9차 학습 진행 화면

9차는 기존 읽기 경계와 상태 판정 위에 **진행 계산·이력 전달·시각화 경계**를 추가합니다. 학습 소스·분할·손실·optimizer·scheduler는 이 화면 변경의 대상이 아닙니다.

| 구현 경계 | 검토할 계약 | 변경 영향 |
| --- | --- | --- |
| 진행 계산 | 에폭의 배치 비율과 단계 최대 에폭 비율을 구분 | 전체 시간 추정과 별개 |
| 완료 상태 | 현재 기록·저장 완료 근거·오래된 상태를 구분 | 실제 완료를 단순 최대 에폭 도달로 대체하지 않음 |
| 이력 전달 | 유한한 읽기 범위·정상 기록·단계·검증 구분 | 무제한 파일 전달과 누락을0으로 메우는 처리를 금지 |
| 손실 표시 | 관측 구간·축·마지막 시각과 원값 유지 | 부분 이력을 전체 학습으로 오표시하지 않음 |
| 화면 동작 | 테마·모션·포커스·작은 폭과 선택 상태 | 조회 동작이 학습 제어로 번지지 않음 |

분모가 없는 기록은 unknown으로 유지해야 합니다. 단계 전환·재개·실패행의0·중복 또는 불완전 기록은 현재 상태와 마지막 정상 관측을 구분하는 기존 어댑터 계약과 함께 검토합니다. 진행 막대의 값이 유한하다는 검사만으로 과학적 해석이 맞다고 판단하지 않습니다.

동일 실행의 표시 창과 숨김 학습 실행기는 별개 생명주기를 가질 수 있습니다. 서버 재시작·브라우저 종료가 학습 종료 API가 되어서는 안 되며, 기존 프로세스 정체 확인·읽기 경로 제한은 유지합니다. 구체적 읽기 상한·계산 함수·회귀 결과는9차 상세와8→9 전체 파일 비교에서 대조합니다.

## LEVEL 4 · 책임 경계와 변경 비용

**현재7차의 과학 계산을8차 조회 변경과 분리**합니다. 이전 차수의 엔진 재배포 보류와 현재 공개 문서·대시보드 소스 범위도 구별합니다. 아래 경계 중 하나가 바뀌면 해당 소비자·회귀와 출처 결합을 다시 확인해야 하며, UI 정상만으로 계산 계약을 승인하지 않습니다.

| 경계 | 현재 계약 | 의도된 선택·절충 | 검증할 실패 경로 |
| --- | --- | --- | --- |
| 원 목록과 파생 목록 | 7차는NIH112,120/COVID781 저자 목록 | 4차부터 NIH112,086장 정제·5차부터 COVID777장 정제와 구분; 6차는5차 연결, 3차는 중복 차단으로 준비 실패 | 분할·수량·SHA·환자 gate를 다른 과제 목록으로 대체하지 않음 |
| 검증 학습 | RNP·Adam·best-validation 선택 | 공식 randomized validation 음성 재생성;본문 고정 검증과 차이 | 시험으로 임계값/모델을 선택하지 않음 |
| 검색 학습 | PML0.9.94·CBM128·블록8·30/50epoch | 공식 validation CBM enqueue 유지;방어 차수와 반대 | 손실/기울기·queue wrap·샘플링·epoch 선택 대조 |
| 메모리·정밀도 | 활성값 재계산·BN/RNG 보존·native AMP | overflow는적용생략;이전차수동일배치재시도와 다름 | 처리배치카운터를적용횟수로오독하지 않음 |
| 평가 | 고정모델·원본gallery·질의변형 | NumPy 제곱L2·명시적자기대각제외·결정적동률 | 원FAISS첫이웃제외/동률과의 차이·유효질의 분모 |
| 신뢰구간 | 10,000회 pair bootstrap | 원 마지막 인덱스 제외 버그는 복제하지 않음 | 환자 cluster CI라고 보고하지 않음 |
| 8차 파일 어댑터 | UUID·고정root·realpath·UTF8엄격해석 | JSONL256KiB tail로전체순회 회피 | 중간손상·CSV중복·불일치·NaN·누락을완료로채택하지 않음 |
| 프로세스 관측 | 정확source/output/parent/creation+최근진행 | CIM10초/GPU15초캐시;불가시미확인 | venvredirector와실제Python중복계산·오래된JSON실행판정 방지 |
| 조작·표시 | 읽기전용·원값·1자리십진반올림 | 선택DOM보존·테마·모션분리 | Host·CSP·경로탐색·비GET거부·포커스·원값펼침 유지 |

결과 격리는 같은 UUID 아래에서도 과제·데이터셋·조건 키를 함께 요구합니다. CSV42행과84과제 완료는 다른 축이며, 마지막 summary 하나나 report의 completed 플래그만으로 전체를 완료 처리하지 않습니다. 기준 평가가 먼저 끝나면 현재 artifacts의 모델 SHA와 일치한 원본 과제만 표시하고 변환 전체 완료로 확장하지 않습니다. 사진42장도 지표의 완료 증거가 아닙니다.

오류의 placeholder0, 마지막 정상 이벤트, 저장 checkpoint는 별개 상태입니다. AMP 때문에 global_step은 처리 배치일 수 있으므로 optimizer 적용 수를 추론하지 않습니다. 재개 전 코드·설정·목록·환경 binding을 유지하고 중간 배치의 worker 증강 난수 스트림이 비트 동일하지 않은 한계를 남깁니다. Windows 원자 교체·파일 공유·권한·백신 원인은 실제 관측 없이 단정하지 않습니다. 정상 이력 truncation과 malformed 기록을 다른 사용자 안내로 분리하더라도 원래 JSONL 검증 정책은 유지합니다.

3차는 CBM 검증 혼입을 차단하고 정확 픽셀 중복을 엄격히 검사했으며 NIH 중복으로 준비가 실패했습니다. 4차는 NIH 허용112,086장 파생 목록을 도입했지만 COVID 충돌로 준비가 중단됐습니다. 5차부터 COVID 허용777장 정제를 추가했고, 6차 화면은5차 실험에 연결됩니다. 7차는 저자 원본 정합성을 위해 원본 목록의 중복과 공식 검증 큐 갱신을 유지한 포팅입니다. 어느 쪽도 다른 쪽의 결과를 재현했다고 자동 주장하지 않습니다. 코드·CPU/GPU 소형 회귀·현재 학습 전진·전체 원본 평가·84조건 완료·논문 수치 차이와 공식 코드/논문 차이를 단계별 증거로 분리합니다. 고정 공격의 PrivacyScore@1은 운영 지표이며 공식 익명성·임상 효용·법적 적합성 보장이 아닙니다.
