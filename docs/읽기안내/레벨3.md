## LEVEL 3 · 실행 전 준비와 목적 선택

현재 작업을 재현하려면 **계산은 로컬7차, 화면은8차**라는 경로 계약부터 확인합니다. 공개판에는 의료 데이터·영상 목록·가중치·운영 원문과 권한 미확인 엔진이 포함되지 않습니다. 문서에서 설명한 로컬 CMD를 공개 사본만으로 전부 실행할 수 있다고 가정하지 않습니다. 원본/패키지가 준비된 환경에서 아래 순서로 확인합니다.

| 순서·목적 | 실제 도구·자료 | 통과 조건 | 실패했을 때 |
| --- | --- | --- | --- |
| 1 환경 확인 | 7차 Check-CXR7.cmd / All-In-One.ps1 -Action check | 환경·공식 목록·필요 영상 존재 확인 | 원인과 원문 보존;누락을 다른 파일로 대체하지 않음 |
| 2 실행 선택 | Start-CXR7.cmd 또는 Resume-CXR7.cmd | 새 UUID 시작인지 현재 실행 재개인지 명시 | 모델·설정·분할·환경 결합 불일치에서 재개 금지 |
| 3 설정 대조 | training_config.json·preflight.json | seed3·배치32·원 목록·작업자16/4·출처 해시 | 실험 도중 설정을 바꿔 오류를 우회하지 않음 |
| 4 학습 확인 | progress.json·events.jsonl·실제 프로세스 | 검증→검색 출력부→검색 전체 단계와 처리 배치 전진 | 과거 training JSON만으로 현재 실행 판정 금지 |
| 5 모델 선택 | 현재 runs/UUID의 선택 가중치·artifacts.json | 검증 best/검색 각 마지막 모델·SHA 일치 | 다른 실행이나 공개 최종 CXR 모델 혼입 금지 |
| 6 기준 평가 | evaluation_results.json | NIH/COVID×검증/검색 실제 지표·분모 | 미측정은 미측정;시험 보고 재튜닝하지 않음 |
| 7 변환 평가 | privacy_results.csv/JSON | 조건별 두 과제 완료·재사용 출처 | 42행 전체가84완료인지 별도 확인 |
| 8 화면 확인 | 8차 node server.mjs·127.0.0.1:8787 | 화면8차/실험7차/읽기 전용·현재UUID | 예전6차 화면의5차 제어와 혼동하지 않음 |

검증 모델은256px·Adam1e-4·100에폭 상한·patience5로 확인합니다. 검색은1024px·128차원·SGD momentum0.9·weight decay1e-5·OneCycle 최대0.158489·출력부30/전체50에폭·CBM128·블록8을 대조합니다. 같은 환자 쌍과 다른 환자 쌍의 생성 방식, 검증 음성 재생성, 검증 중 CBM 갱신을 설정표의 숫자만큼 중요하게 기록합니다.7차는 NIH 원본112,120장·COVID 원본781장을 씁니다. 3차는 중복 차단으로 준비가 실패했고, NIH112,086장 정제는4차부터, COVID777장 정제는5차부터 적용됐습니다. 6차는5차 실험의 조회·제어 연결이며 이 파생 분모를7차에 복사하지 않습니다.

## LEVEL 3 · 결과를 확인하고 보고하기

| 기록 | 확인할 값·출처 | 보고할 때 주의 |
| --- | --- | --- |
| 학습 진행 | epoch·step·global_step·loss·learning_rate·시각 | global_step은 단계 내 처리 배치이며 AMP의 실제 적용 수와 다를 수 있음 |
| 저장·재개 | 체크포인트 메타데이터·설정 결합 | 마지막 이벤트 뒤 미저장 배치가 있어 재처리할 수 있음 |
| 원본 성능 | AUC·Accuracy·P@1·mAP@R·R-Precision·분모 | 논문 기준 AUC0.9940/Accuracy0.9555/P@1 0.9963 등과 관측값 분리 |
| 변환 조건 | 블러·모자이크 각각0,1,2,4,8,16,32,64,128,256 | 질의만 변형·갤러리 원본·자기 원본 제외 |
| 항등 조건 | original/blur0/mosaic0/mosaic1 | 측정한 원본 결과 재사용을 새 추론처럼 쓰지 않음 |
| 구간·점수 | 쌍 bootstrap10,000회·PrivacyScore@1 | 환자 집단 CI나 익명성 보장으로 확대하지 않음 |

화면에서는 데이터셋·과제→단계→강도를 선택하고 원값을 펼칩니다.3초 갱신 후 선택·포커스·펼침이 유지되는지, 양쪽 테마·모션 재생/정지·작은 화면에서 글자가 잘리지 않는지 확인합니다. 최근 로그는 현재 실행의 가장 최근 stdout/stderr 쌍인지 봅니다. 정상256KiB 앞부분 생략은 보조 안내이고 손상·다른 실행·읽기 실패는 오류입니다. 읽기 전용 화면의 선택과 모션 제어는 계산을 시작하거나 끝내지 않습니다.

백분율은 소수 첫째 자리 반올림과 전체 원비율을 함께 기록합니다. 반올림100.0과 정확히1을 구분하고 AUC·손실·학습률 원값을 유지합니다. Node·관리자·모델 CPU/GPU 회귀와 실제 전체 학습·성능 재현을 나눠 보고합니다. 전체 학습·84조건·논문 재현이 미확인인 상태에서 검사 통과를 최종 성공으로 바꾸지 않습니다. 오류·부분 결과·역사적 차수는 보존하며 의료 원본과 비공개 로그는 업로드하지 않습니다.
