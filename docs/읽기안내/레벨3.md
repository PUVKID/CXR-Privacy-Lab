## 프로젝트 소개

**데이터 준비·전수 검사·새 학습·조건별 평가·결과 조회를 이어 확인하는 실행 자료입니다.** 실제 원영상과 로컬 평가 엔진·가중치는 공개 범위에서 제외됩니다. 준비 완료·첫 가중치 갱신·학습 종료를 각기 기록으로 확인해야 합니다.

<a id="guide-problem"></a>

## 문제와 주요 기능

검증 쌍과 검색 질의·갤러리 목록을 따로 확인합니다. 같은 환자의 다른 촬영본이 없는 질의는 검색 지표 분모에서 빠지되 갤러리에는 남습니다. 영상 수와 환자 수, 쌍 수를 섞지 않습니다.

<a id="guide-flow"></a>

## 입력·처리·출력

NIH는 112,120장 중 중복 정책으로 34장을 제외해 112,086장 파생 집합을 만듭니다. 검증 분할 75,690/10,811/25,585장, 학습 양성·음성 각 395,926쌍, 검색 학습 61,735장의 실제 조건을 확인합니다.

<a id="guide-practice"></a>

## 실험과 사용 흐름

현재 원영상 전체 SHA와 정제 명세를 검증하는 스냅샷을 사용하고 실패 시 학습·평가를 시작하지 않습니다. 실행 UUID별 기록을 확인하세요. 과거 실행에서 자동 재개하거나 다른 가중치로 평가했다고 가정하지 않습니다.

<a id="guide-results"></a>

## 관측 결과와 해석

환자별 영상 수와 유효 질의 분모, 검증 쌍의 수를 지표 옆에서 확인합니다. 반올림100.0%와 실제 원비율1을 구분하고 결과 CSV·JSON을 표시 목적으로 수정하지 않습니다. 미측정·대기·정의 불가를 남깁니다.

<a id="guide-architecture"></a>

## 구현과 핵심 파일

차수별 실행 경로와 학습 포팅 조건 문서를 읽습니다. 현재 실행에서 생성한 가중치가 아니면 평가를 시작하지 않습니다. 공개 소스 검사와 재배포 권한이 보류된 로컬 평가 엔진의 범위를 구분합니다.

<a id="guide-paper"></a>

## 실제 논문과 원고

원 논문 DOI10.1038/s41598-022-19045-3과 고정 공식 코드 링크를 근거로 읽습니다. 새 연구 원고가 존재한다고 만들지 않습니다. 현재 공개 설명과 원 논문 수치 재현의 상태를 따로 기록합니다.

<a id="facts-section-1"></a>

### LEVEL 3 · 현재 화면


6차 화면은 기존 5차 실험을 연결해 학습 3과정과 평가 3단계·21강도조건의 상세를 구분합니다. 각 강도별 재학습을 수행하는 구조가 아니며 같은 새 모델로 평가합니다. 반올림 100.0%와 실제 원비율 1을 구분하고 원값을 펼쳐 확인합니다.





<a id="facts-section-2"></a>

### LEVEL 3 · 현재 실험


NIH 원본 112,120장 전수 검사에서 정확한 픽셀 중복 25그룹을 확인했습니다. 환자 기록이 다른 동일 영상은 모두 제외하고, 같은 환자의 동일 영상은 한 장만 남기는 파생 실험 목록을 만듭니다. 원본·공식 분할·3차의 차단 기록은 보존합니다. 4차는 이 누수 방어와 한글 경로·모션 버튼 수정을 반영합니다.

이후 COVID 외부검증 자료에서도 서로 다른 환자ID의 동일 픽셀 2그룹을 발견해 준비를 차단했습니다. 5차는 원본 781장 중 환자 충돌 4장을 제외한 777장·1,534쌍으로 외부 평가 집합을 일관되게 파생합니다. 양성 772쌍·음성 762쌍이라는 실제 분모를 유지하며 임의 균형 보충은 하지 않습니다.

이번 실험은 논문 주요 조건을 기반으로 중복과 검증 메모리 혼입을 차단한 재학습입니다. 원 논문 환경·모든 분석·공식 데이터 구성을 그대로 복제했다고 주장하지 않습니다. 학습 시작·종료·논문 수치 재현 여부는 실제 실행 결과를 따로 확인합니다.

### LEVEL 3 · 화면과 실행


흰색·회청색 화면에서 준비·학습·평가를 구분하고 실제 GPU·학습 진행·결과를 확인합니다. 백분율은 소수 첫째 자리까지 반올림해 표시하며 저장 원비율과 전체 정밀도 값을 펼쳐 확인합니다. 다크·라이트와 모션 제어를 제공합니다. 변환 미리보기는 평가 결과가 아닙니다.

Node.js로 `6차/server.mjs`를 실행하면 로컬 포트 8787에서 대시보드를 확인할 수 있습니다.

새 학습 코드는 `5차/실험 코드/training/`에 있습니다. 실행 관리자는 로컬 Python 환경과 평가 엔진·데이터를 필요로 합니다. 제공 평가 패키지의 재배포 권한이 미확인이라 전체 평가 엔진은 포함하지 않았습니다. 이 공개 사본만으로 전체 실험을 실행할 수 있다는 뜻은 아닙니다.

### LEVEL 3 · 지표와 공개 경계


프라이버시 점수 `100 × (1 − CMC@1)`는 고정된 공격 모델·검색 집합에서의 1순위 재식별 실패율입니다. 익명성 보장이나 종합 개인정보 보호 수준을 뜻하지 않습니다. 자기 원본과 동일 픽셀 중복을 이용한 우회를 차단하며, 변경된 질의·검색 집합 분모를 기록합니다.
