## LEVEL 2 · 10차 강도별 독립 학습

**변환 조건 → 새 초기화 → 검증·검색 학습 → 해당 조건 평가**가10차의 흐름입니다. 기존7차의 원본 학습과 고정 모델21조건 평가는 보존합니다. 새 흐름은 변환된 영상에 맞춰 공격 모델도 다시 학습하는 별도 확장 실험입니다.

블러와 모자이크는 각0·1·2·4·8·16·32·64·128·256의10조건입니다. 숫자의 단위는 원영상 픽셀 조건이며, 모델의 입력 크기와 같은 개념이 아닙니다. 변환 뒤 모델별 입력 전처리를 적용합니다. NIH 학습 자료로 모델을 만들며 COVID-19는 외부 평가 자료입니다. 두 데이터셋을 각각 학습한다고 세지 않습니다.

조건 사이에서는 모델·옵티마이저·스케줄러·검색 메모리와 학습 난수 상태를 넘기지 않습니다. 비교에 쓰는 초기 가중치와 seed 기준은 같습니다. 한 검색 모델 안에서 출력부를 학습한 뒤 전체 네트워크를 이어 학습하는 것은 같은 조건의 내부 과정입니다. 다른 조건으로 넘어갈 때의 독립 초기화와 구별합니다.

대기열은 원본 관리자의 실제 종료와 정상 산출물을 함께 확인합니다. 학습 완료 기록 하나나 파일 존재만으로 원본 평가까지 끝났다고 판단하지 않습니다. 조건별 저장 폴더와 실행 식별자가 분리되어 화면에서 한 조건을 고르면 그 조건의 기록만 읽습니다. 기록이 없거나 맞지 않으면 수치를 보여 주지 않습니다.

## LEVEL 2 · 9차 학습 진행 화면

9차는7차 계산 결과를 새로 만드는 학습기가 아니라, **기존 기록을 진행률·단계·추세로 연결하는 읽기 전용 화면**입니다. 에폭, 학습 단계, 전체 평가 조건은 분모가 다른 세 축입니다.

| 연결 | 처리 | 화면에서의 뜻 |
| --- | --- | --- |
| 현재 진행 기록 → 에폭 | 현재 배치 / 해당 에폭 전체 배치 | 한 자료 순회의 진행 |
| 에폭 기록 → 학습 단계 | 완료 에폭과 현재 배치 비율 / 단계 최대 에폭 | 검증100·출력부30·전체50 각각의 예정량 기준 |
| 저장 완료 근거 → 단계 흐름 | 현재 기록과 완료 상태를 구분 | 다음 단계로 넘어간 근거를 표시 |
| 유한한 크기의 이력 → 손실 추이 | 실제 정상 학습·검증 관측만 분리 | 누락·범위·마지막 시각을 함께 해석 |
| 프로세스·최근 기록 → 현재 상태 | 파일 존재만으로 생존을 추정하지 않음 | 현재 실행과 과거 정상 관측을 분리 |

세 단계 비율을 단순 평균해 전체 실험 시간 완료율로 부르지 않습니다. 검증 모델은 조기 종료할 수 있고 각 단계의 한 배치 비용도 다릅니다. 손실 그림은 관측한 오차의 변화이며 최종 검증 AUC나 검색 P@1과 다른 출력입니다. 조회할 기록이 부족하면 계산할 수 없다는 상태를 유지합니다.

표시 창·화면 서버·학습 실행기가 분리돼 있으면 표시만 닫는 조작은 학습 종료 명령이 아닙니다. 다만 실제 실행기 종료·운영체제 종료·저장 실패까지 막는 보장은 아닙니다. 8차의 연결·입력 검증과 강도별 원값 조회는 보존하며9차는 학습 설정이나 변환별 재학습 구조를 추가하지 않습니다.

아래는8차까지의 설명입니다. 당시 화면8차의 조건·절차·관측을 그대로 보존하며 현재9차의 완주나 성능으로 바꾸지 않습니다.

## LEVEL 2 · 두 과제와 세 종류의 단계

검증과 검색은 같은 사진을 다루지만 다른 정답을 계산합니다. 검증은 두 영상의 같은 환자 여부를, 검색은 질의 영상과 후보 집합의 순위를 구합니다. **학습의3과정과 평가의3단계는 다른 축**입니다. 검증 모델·검색 출력부·검색 전체를 학습한 뒤 동일 모델을 원본·블러·모자이크에서 비교합니다. 변환 강도마다 새로 배우면 공격 모델도 달라져 같은 모델에 대한 비교가 아니게 됩니다.

| 구성 | 앞에서 받는 것 | 하는 일 | 다음으로 넘기는 것 |
| --- | --- | --- | --- |
| 목록·이미지 점검 | 저자 원본 목록과 실제 파일 | 목록 해시·수량·환자 분리·필요 파일 존재 확인 | 검증된 학습/시험 입력 계약 |
| 검증 학습 | 256px 사진 쌍·ImageNet 초기값 | Adam·손실 최소화·최저 검증손실 모델 선택 | 동일 환자 판별 모델 |
| 검색 출력부/전체 학습 | 1024px 사진·128차원 표현 | 30/50에폭·SGD/OneCycle·블록8/CBM128 | 각 과정 마지막 가중치 |
| 원본 시험 | 현재 학습의 선택 모델과 시험 목록 | NIH 내부·COVID 외부 성능 및 신뢰구간 | evaluation_results.json |
| 변환 시험 | 고정 모델·원본 갤러리 | 질의 변형·항등 조건 재사용·나머지 실제 추론 | privacy_results.json/CSV |
| 8차 어댑터 | 현재UUID의 저장 기록 | 엄격 읽기·조건별 검증·실제 프로세스 대조 | 미측정과 완료가 구분된 화면 |

7차의 검증 RNP는 같은 환자 양성 쌍을 남기고 다른 환자 음성 쌍을 매에폭 다시 구성합니다. 선택한 공식 randomized 분기는 검증 음성도 다시 만듭니다. 논문 본문의 균형 잡힌 고정 검증 설명과 이 코드 분기는 완전히 같지 않습니다. 검색은 최근 특징128칸을 보관하는 CBM과8개 단위 블록 순서를 사용하고, 공식 구현대로 검증 중에도 같은 CBM 큐를 갱신합니다. 이는3~6차에서 차단한 동작을 다시 보존한 것이므로 “모든 차수를 합친 누수 방지”라고 부를 수 없습니다.

## LEVEL 2 · 조건을 바꾸면 무엇이 달라지는가

| 조건 | 현재7차 연결 | 바꿀 때의 영향 |
| --- | --- | --- |
| 모델 초기값 | 공식 ImageNet ResNet50 | 공개 CXR 최종 모델을 쓰면 새 학습의 출발점이 달라짐 |
| 자료 정책 | NIH112,120/COVID781 원본 목록 | 4차부터의 NIH 정제112,086장·5차부터의 COVID 정제777장과 분모·입력 구성이 다름 |
| 검증 학습·선택 | 배치32·최대100·patience5·최저 검증손실 | 시험 성능을 보고 모델·임계값을 고르지 않음 |
| 검색 학습·선택 | 배치32·출력부30/전체50·각 마지막 epoch | 검증 모델의 best 선택 규칙을 검색에 그대로 적용하면 안 됨 |
| 항등 변환 | original/blur0/mosaic0/mosaic1 | 픽셀이 같으므로 기준 결과 재사용 출처를 남김 |
| 관측 단위 | 42개 데이터 행·84개 과제조건 | 행 수를 두 과제 완료 수와 혼동하면 진행률이 잘못됨 |

OneCycle은 학습률의 시간표, momentum은 이전 이동 방향의 반영, weight decay는 가중치 크기에 대한 규칙입니다. 활성값 재계산은 메모리를 줄이는 대신 중간값을 다시 계산하며 BN 통계·난수 처리의 대조가 필요합니다. 혼합정밀도 AMP는 overflow에서 모델 적용을 생략할 수 있어 global_step이라는 처리 배치 카운터와 optimizer 적용 수를 같다고 볼 수 없습니다. 신뢰구간 bootstrap은10,000회 쌍 재표집이며 환자 집단 단위 구간이 아니라는 해석 경계가 있습니다.

## LEVEL 2 · 관측·오류·검사의 연결

8차는 포인터의 임의 path 대신 현재 UUID의 고정 경계를 읽습니다. 기록이 최근인 조건과 소스·출력UUID·부모·생성 시각이 맞는 프로세스 조건을 함께 만족할 때만 학습 중을 표시합니다. 실제 재개 프로세스가 살아 있고 과거 오류 JSON이 아직 남았으면 둘을 함께 보여 줍니다. 현재 상태, 마지막 정상 이벤트, 마지막 저장 체크포인트는 서로 다른 자료입니다. 재개는 마지막 관측이 아닌 저장 지점부터 일부 배치를 다시 처리할 수 있습니다.

코드·명령·모델·데이터를 검증하는 테스트와 화면 선택·테마·모션을 확인하는 조작 검사는 다른 증거입니다. 원본 성능과 변환 성능은 파일이 저장돼야 읽을 수 있고 손실을 정확도로 변환하지 않습니다. PrivacyScore@1은100×(1−검색P@1)인 고정 공격 실패율입니다. 숫자 표시와 과거 실패를 보존하며 익명성·진단 효용·원 논문 전체 재현은 별도 주장입니다. 공개 사본은 의료 자료와 모델을 제외하므로 로컬 원본 환경과 공개 설명의 실행 가능 범위도 다릅니다.
