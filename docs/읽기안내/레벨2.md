## 프로젝트 소개

**원본·블러·모자이크 세 단계에서 환자 재식별을 평가합니다.** 공개 최종 가중치 평가와 새 학습 경로를 구분합니다. 파일 저장 1~6차와 실험의 세 단계는 다른 구분이며 현재 화면 6차는 기존 5차 실행을 연결합니다.

<a id="guide-problem"></a>

## 문제와 주요 기능

두 사진의 같은 환자 여부를 판정하는 Verification과 순위로 찾는 Retrieval은 분모와 지표가 다릅니다. 프라이버시 점수는 고정 공격의 1순위 검색 실패율입니다. 점수가 높다고 모든 공격을 막았다는 뜻은 아닙니다.

<a id="guide-flow"></a>

## 입력·처리·출력

데이터 검증→검증 모델 학습→검색 출력부 학습→검색 전체 학습→21조건 평가 순서입니다. 블러 0과 모자이크 1은 각각 무변형 대조조건입니다. 변형은 모델 입력 크기를 바꾸기 전에 적용합니다.

<a id="guide-practice"></a>

## 실험과 사용 흐름

한글 폴더의 화면·실험 코드·검사·문서와 공통 연구 자료·실행 환경을 구분합니다. 대시보드와 데이터 준비만 실행하는 경로, 전체 새 학습 경로가 따로 있습니다. 포트8787 화면과 실제 실행 로그를 함께 봅니다.

<a id="guide-results"></a>

## 관측 결과와 해석

프라이버시 점수 100×(1−CMC@1)는 1순위 재식별 실패율입니다. 정확도·F1·AUC와 검색 순위 지표는 별도로 읽습니다. 백분율은 소수 첫째 자리 반올림이며 원값·전체 자릿수를 펼쳐 확인합니다.

<a id="guide-architecture"></a>

## 구현과 핵심 파일

server.mjs와 run_experiment.py가 화면·실행 경로를 나눕니다. 로컬 주소 바인딩, Host·Origin·경로 경계를 검사합니다. 초기화·데이터·체크포인트와 사용자 화면은 서로 다른 역할입니다.

<a id="guide-paper"></a>

## 실제 논문과 원고

Packhäuser 등의 원 논문과 공식 코드를 기준으로 감사를 수행했습니다. 최종 가중치 평가였던2차와 새학습3차 이후를 구분합니다. 중복 정제는 원 논문과 달라진 조건입니다.

<a id="guide-limits"></a>

## 조건·실패·미검증 한계

블러 반지름과 모자이크 타일 크기는 변형 전 원영상 좌표계입니다. 모델의256픽셀 좌표계 값이 아닙니다. 정제·환경 차이와 미완료 실행 상태를 결과 가까이 두고 읽습니다.

위의 수준별 풀이에 대응하는 실제 세부 사실입니다. 입력·조건·수치·표·그림·문서 판본과 작은 변경까지 같은 페이지에서 확인하도록 기존 첫 화면의 내용을 함께 수록했습니다. 각 절은 해당 수준의 앞선 설명과 연결해 읽으며, 원래 실행 코드·전체 비교·원고는 원문 주소로 이어집니다.

### LEVEL 2 · 현재 화면


6차 화면은 기존 5차 실험을 연결해 학습 3과정과 평가 3단계·21강도조건의 상세를 구분합니다. 각 강도별 재학습을 수행하는 구조가 아니며 같은 새 모델로 평가합니다. 반올림 100.0%와 실제 원비율 1을 구분하고 원값을 펼쳐 확인합니다.





<a id="facts-section-2"></a>

### LEVEL 2 · 현재 실험


NIH 원본 112,120장 전수 검사에서 정확한 픽셀 중복 25그룹을 확인했습니다. 환자 기록이 다른 동일 영상은 모두 제외하고, 같은 환자의 동일 영상은 한 장만 남기는 파생 실험 목록을 만듭니다. 원본·공식 분할·3차의 차단 기록은 보존합니다. 4차는 이 누수 방어와 한글 경로·모션 버튼 수정을 반영합니다.

이후 COVID 외부검증 자료에서도 서로 다른 환자ID의 동일 픽셀 2그룹을 발견해 준비를 차단했습니다. 5차는 원본 781장 중 환자 충돌 4장을 제외한 777장·1,534쌍으로 외부 평가 집합을 일관되게 파생합니다. 양성 772쌍·음성 762쌍이라는 실제 분모를 유지하며 임의 균형 보충은 하지 않습니다.

이번 실험은 논문 주요 조건을 기반으로 중복과 검증 메모리 혼입을 차단한 재학습입니다. 원 논문 환경·모든 분석·공식 데이터 구성을 그대로 복제했다고 주장하지 않습니다. 학습 시작·종료·논문 수치 재현 여부는 실제 실행 결과를 따로 확인합니다.

### LEVEL 2 · 화면과 실행


흰색·회청색 화면에서 준비·학습·평가를 구분하고 실제 GPU·학습 진행·결과를 확인합니다. 백분율은 소수 첫째 자리까지 반올림해 표시하며 저장 원비율과 전체 정밀도 값을 펼쳐 확인합니다. 다크·라이트와 모션 제어를 제공합니다. 변환 미리보기는 평가 결과가 아닙니다.

Node.js로 `6차/server.mjs`를 실행하면 로컬 포트 8787에서 대시보드를 확인할 수 있습니다.

새 학습 코드는 `5차/실험 코드/training/`에 있습니다. 실행 관리자는 로컬 Python 환경과 평가 엔진·데이터를 필요로 합니다. 제공 평가 패키지의 재배포 권한이 미확인이라 전체 평가 엔진은 포함하지 않았습니다. 이 공개 사본만으로 전체 실험을 실행할 수 있다는 뜻은 아닙니다.

### LEVEL 2 · 지표와 공개 경계


프라이버시 점수 `100 × (1 − CMC@1)`는 고정된 공격 모델·검색 집합에서의 1순위 재식별 실패율입니다. 익명성 보장이나 종합 개인정보 보호 수준을 뜻하지 않습니다. 자기 원본과 동일 픽셀 중복을 이용한 우회를 차단하며, 변경된 질의·검색 집합 분모를 기록합니다.

의료 원영상·영상별 목록·환자 식별자·가중치·실행 로그·개인 지침과 기억은 공개하지 않습니다. 원 저자 코드의 GPL, PML의 MIT 출처와 글꼴 OFL을 보존하며 전체 저장소에 새 포괄 라이선스를 부여하지 않습니다.
