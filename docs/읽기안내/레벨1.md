새 실행의 준비·학습·완료 여부는 실제 기록으로 확인합니다.

외부 GPU 프로세스 목록은 관측 정보이며 CXR 중복 실행을 차단하고 기존 단계별 메모리 여유 기준은 유지합니다.

CPU 실변환 검사는 import 시간 상한으로 미완료이며 실제 21조건 학습 완료를 주장하지 않습니다.

사진 두 장이 같은 사람인지 묻는 것은 병을 판별하는 작업과 다릅니다.

검색은 기준 사진과 같은 사람의 다른 사진을 여러 후보에서 찾습니다.

**에폭**은 학습 목록을 한 번 도는 단위이고 배치는 한 번에 처리하는 묶음입니다.

## 9차 학습 진행 화면

현재 계산은 7차, 새 진행 화면은 9차입니다.

에폭은 학습 자료를 한 바퀴 도는 단위이고, 배치는 한 번에 처리하는 묶음입니다.

같은 7차 학습을 보면서 현재 바퀴가 얼마나 진행됐는지와 세 학습 과정 중 어디에 있는지를 구분합니다.

| 보는 곳 | 읽는 방법 | 주의할 점 |
| --- | --- | --- |
| 에폭 막대 | 현재 배치를 이번 에폭의 전체 배치와 비교 | 100%는 이번 한 바퀴가 끝났다는 뜻 |
| 학습 단계 막대 | 지금까지의 에폭·배치를 그 단계의 최대 예정 에폭과 비교 | 전체 실험 시간이나 성능의 완성도가 아님 |
| 세 단계 흐름 | 검증 모델 → 검색 출력부 → 검색 전체 | 저장된 완료 증거와 현재 기록을 함께 확인 |
| 손실 그래프 | 실제로 저장된 학습·검증 오차의 최근 관측을 확인 | 낮아졌다고 시험 정확도나 익명성이 보장되지는 않음 |
| 빈 값·원값 | 기록이 없으면 미측정 안내, 있는 값은 원래 숫자로 확인 | 없는 오차를 0으로 채우지 않음 |

먼저 화면의 실험 차수와 학습 상태를 확인하고, 큰 막대 아래의 에폭·배치 숫자를 읽습니다.

그 다음 손실 그림의 범위와 마지막 기록 시각을 봅니다.

앞 부분을 생략한 최근 기록이라면 전체 학습 곡선으로 보고하지 않습니다.

조기 종료가 가능한 검증 모델은 최대 100에폭을 다 채우지 않고 끝날 수 있으므로 막대가 100%가 아니어도 실제 완료 기록이 있는지 따로 확인합니다.

기존 표시용 PowerShell 창이나 브라우저를 닫는 일과 **숨김 학습 실행기를 종료하는 일은 다릅니다**.

별도 실행 중인 학습의 생존과 기록 증가를 확인해야 하며, 모든 PowerShell·Python을 일괄 종료하거나 재부팅해도 계속된다는 뜻은 아닙니다.

화면의 모션 정지는 그림의 움직임만 멈춥니다.

의료 사진·가중치·개인별 목록·운영 로그는 공개하지 않습니다.

## 8차까지의 안내 원문

아래는 8차까지의 설명입니다.

<a id="level-1--먼저-어떤-작업인지-구분하기"></a>

## 먼저 어떤 작업인지 구분하기

이 연구는 엑스레이에서 병을 진단하는 시스템이 아닙니다.

**사진에 환자를 다시 알아볼 만한 특징이 남는지** 시험합니다.

검증은 사진 두 장이 같은 환자인지 묻고, 검색은 기준 사진과 같은 환자의 다른 사진을 여러 후보에서 찾는 일입니다.

사진을 흐리게 하거나 모자이크 처리해도 그 사람이 찾아지는지 비교하되, 공격이 실패했다는 사실만으로 완전한 익명화나 진단용 사진의 쓸모를 증명하지 않습니다.

| 현재 대상 | 넣는 것 | 무엇을 하는가 | 남는 것 |
| --- | --- | --- | --- |
| 7차 검증 학습·시험 | 저자 목록과 사진 쌍 | 같은 환자 여부를 배우고 따로 시험 | 모델·손실·검증 AUC/정확도 |
| 7차 검색 학습·시험 | 사진과 환자별 후보 목록 | 사진을 숫자 특징으로 바꾸고 후보 순위 계산 | 검색 모델·P @1·mAP @R·R-Precision |
| 7차 변환 비교 | 같은 모델과 다른 강도의 질의 사진 | 질의만 변형하고 원본 후보 고정 | 42 행 안에 84개 과제·조건 상태 |
| 8차 현황 화면 | 7차의 저장 기록 | 읽기·선택·원값 표시만 수행 | 현재 관측과 실제 프로세스 확인 상태 |

현재 계산은 7차, 조회 화면은 8차입니다.

과거 1차는 이미 학습된 공개 최종 CXR 모델을 시험하는 첫 화면이었고 2차는 그 계산 조건을 살핀 감사였습니다.

3차는 검증 중 기억 공간 혼입을 막고 중복을 발견하면 준비를 중단한 차수로, NIH 중복 때문에 준비가 실패했습니다.

4차부터 NIH 중복 34장을 제외한 112,086장의 파생 목록을 만들었지만 COVID 충돌로 준비가 중단됐습니다.

5차부터 COVID도 4장을 제외한 777장으로 정제했고, 6차 화면은 이 5차 실험에 연결됩니다.

7차는 저자 원본 목록과 공식 동작을 따르기 위해 그 중복과 일부 혼입 가능 동작을 보존했습니다.

차수 숫자가 높다고 모든 과거 안전 조건을 그대로 더한 것은 아닙니다.

검증의 확률이 0.5보다 클 때 같은 환자라고 판정합니다.

이 기준을 시험 결과에 맞춰 다시 고르지 않습니다.

원본·블러 0·모자이크 0·모자이크 1은 사진 픽셀이 같으므로 측정한 원본 결과를 재사용했다고 표시합니다.

나머지 17 조건은 변환한 사진으로 실제 추론합니다.

데이터셋 두 개와 과제 두 개를 따로 세어 84가 되며, 한 CSV 행에 두 과제 결과가 들어가 42 행이 됩니다.

## 화면을 열고 결과를 읽는 순서

| 하고 싶은 일 | 찾을 도구·기록 | 확인할 것 |
| --- | --- | --- |
| 현황 보기 | 8차의 Node 대시보드 | 화면 8차·실험 7차·읽기 전용 표시 |
| 처음부터 배우기 | 로컬 7차의 start | 새 실행이며 이전 체크포인트 재개와 다름 |
| 중간부터 이어 가기 | 로컬 7차의 resume | 같은 실행·설정·저장 체크포인트인지 확인 |
| 진행 읽기 | 현재 상태·정상 이력·실제 프로세스 | 오래된 화면 글만 보고 학습 중이라 하지 않기 |
| 성능 읽기 | 실제 평가 JSON·CSV와 원값 펼침 | 미측정·모델 학습 손실·논문 참고 값 구별 |

대시보드에서 데이터셋과 과제, 단계와 강도를 고르는 것은 **조회**입니다.

시작·종료 명령을 보내지 않습니다.

모션 정지도 화면 움직임만 멈춥니다.

정상 이력이 길면 최근 256 KiB만 읽고 앞부분 생략을 안내합니다.

손상·읽기 실패와는 다른 상태입니다.

오류 칸의 0은 과거 작업이 없었다는 뜻이 아니며 마지막 처리 기록과 저장 체크포인트를 별도로 봐야합니다.

백분율은 현재 소수 첫째 자리 반올림이며 원래 숫자를 펼쳐 확인합니다.

반올림으로 100.0%가 된 값과 원비율이 정확히 1 인 값은 다릅니다.

AUC·손실·학습률은 저장 원값을 유지하고 없는 값을 0으로 채우지 않습니다.

원 논문의 AUC0.9940등은 비교를 위한 참고 값이며 이번 학습이 달성한 점수가 아닙니다.

<a id="level-1--어디까지-확인했는가"></a>

## 어디까지 확인했는가

코드 검사와 작은 합성 계산은 프로그램의 일부 동작을 확인합니다.

실제 장시간 학습·전체 평가·원 논문 수치 재현까지 끝났다는 증거는 아닙니다.

현재 7차 전체 성능은 미확인입니다.

원본 중복, 공식 검증 큐 갱신, Windows·난수·동률·신뢰구간 차이를 남기고 CheXpert와 논문의 모든 추가 분석을 수행한 것으로 쓰지 않습니다.

의료 사진·영상별 목록·모델·운영 원문은 공개하지 않아 이 공개 설명만으로 전체 실험을 바로 실행할 수 없습니다.
