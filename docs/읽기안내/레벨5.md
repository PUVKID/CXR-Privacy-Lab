## LEVEL 5 · 전문 검토 시 먼저 확인할 계약

| 검토 축 | 현재7차/8차 근거 | 앞선 차수와의 구분 | 남은 판정 |
| --- | --- | --- | --- |
| 모델·입력 | 공식ImageNet초기값·원NIH112,120/COVID781 | 1차 최종모델 평가와 별개; 3차 중복 차단·준비 실패, 4차부터 NIH112,086장 정제, 5차부터 COVID777장 정제, 6차는5차 연결과 구분 | 역사적바이너리·난수흐름 동일성은 미확인 |
| 학습 선택 | 검증best/검색phase최종·RNP공식분기 | 본문고정검증설명과randomized validation차이 | 시험선택금지·전체학습종료 별도확인 |
| CBM·AMP | PML0.9.94 validation큐갱신/native AMP skip | 3~6차큐차단·동일배치재시도와 다름 | 처리batch·optimizer적용·저장checkpoint 분리 |
| 평가·구간 | 고정모델·L2·자기대각제외·tie·pair bootstrap | FAISS/원bootstrap버그 복제 안함 | 원논문모든cohort/ablation 수행 아님 |
| 대시보드 | 고정UUID/read-only·현재프로세스+신선도 | 6차의5차제어연결을제거 | 관측캐시한계·전체성능미확인 유지 |

현재7차 계산·8차 표시와 전문 원문을 대조할 때 global_step은 **단계 내 처리 배치 기록**으로 읽습니다. 비유한 기울기에서 AMP가 optimizer 적용을 생략할 수 있으므로 마지막 이벤트를 마지막 optimizer 적용으로 부르지 않습니다. 전문 원문에 나타난 운영 관측과 본문·공식 코드·환경의 차이를 함께 확인하며, 다음은 기존 전문 설명과 전체 차수 연결을 보존한 내용입니다.

## 목적과 입출력

| 입력 | 처리 | 출력 |
| --- | --- | --- |
| 흉부 X선 두 장 | 같은 사람 여부 검증 | 점수·AUC·정확도 |
| 기준 사진과 후보 사진들 | 같은 환자의 다른 영상 검색 | P@1·mAP@R·R-Precision |
| 학습·평가 기록 파일 | 8차 조회 화면에서 읽기 | 현재 단계·강도·측정값 |

원 저자의 NIH·COVID 목록과 학습 구성을 기준으로 새 ImageNet 초기값에서 시작하는 Windows 포팅입니다. 이전5차 모델을 이어받거나 공개 최종 CXR 가중치만 평가하는 경로가 아닙니다.

재현 단위는 논문 본문의 프로토콜, 고정한 저자 커밋의 실제 분기, 현재 포팅의 실행 환경으로 분리합니다. verification pair 분모와 retrieval의 적격 질의·전체 gallery 분모를 대조합니다. duplicate를 보존한 저자 목록과 중복 제거 파생 목록을 동등한 시험 집합으로 취급하지 않습니다. exact-image 대각 제외와 동률 정렬이 original FAISS의 첫 이웃 제거 가정과 달라질 수 있음을 기록합니다.

## 구성과 조건

| 부분 | 현재7차 기준 | 확인할 점 |
| --- | --- | --- |
| 검증 학습 | 256px·배치32·Adam0.0001·최대100에폭·patience5 | 최저 검증손실 가중치 선택 |
| 검색 학습 | 1024px·128차원·출력부30/전체50에폭 | 단계별 최종 가중치·SGD/OneCycle |
| 평가 | 원본1+블러10+모자이크10 | NIH·COVID, 검증·검색을 각각 구분 |
| 변환 강도 | 두 변환 모두0,1,2,4,8,16,32,64,128,256 | 질의만 변형, 원본 갤러리 고정 |
| 결과 묶음 | 42데이터행·84과제조건 | 항등 변환의 원본 결과 재사용 명시 |

검증은256px·배치32·Adam0.0001·최대100에폭·patience5·최저 검증손실 모델 선택입니다. 검색은1024px·128차원·30/50에폭·SGD momentum0.9·weight decay1e-5·OneCycle maxLR0.158489·block8·CBM128을 사용합니다.

모델 토폴로지·RNP train/validation 생성·strict threshold>0.5·best validation-loss 선택, retrieval phase1 freeze/BNtrain·phase2 final-epoch 초기화·SGD/OneCycle·PML0.9.94 CBM128/block8을 공식 구현과 대조합니다. 논문 본문의 고정 balanced validation 설명과 공식 randomized 분기의 매epoch val negative 재추출은 서술상 차이가 있으므로 동일성의 근거를 분기별로 한정합니다. AMP overflow skip, activation checkpoint RNG/BN 복원, CBM validation enqueue를 포함한 포팅 범위를 공개합니다.

## 사용과 오류 확인

| 목적 | 실행 또는 자료 | 확인 사항 |
| --- | --- | --- |
| 현재 화면 | Node.js로8차/server.mjs 실행 | 127.0.0.1:8787의7차 연결 표시 |
| 기존 학습 재개 | 로컬7차 All-In-One.ps1 -Action resume | 동일 실행·설정·분할·체크포인트 결합 |
| 새 학습 | 로컬7차 start | 새로운 실행이며 기존 resume과 다름 |
| 상태 확인 | progress.json·events.jsonl·체크포인트 | 현재 상태와 마지막 정상 기록을 구분 |
| 평가 확인 | evaluation_results.json·privacy_results.csv | 실제 측정이 없으면 미측정 |

Node.js로8차/server.mjs를 실행하고127.0.0.1:8787에 접속합니다. 현재7차의 검증된 UUID 아래 기록만 읽고 화면에서 학습 시작·종료 명령을 보내지 않습니다. 원본·강도 선택, 원값 확인, 테마·모션 제어는 조회입니다.

실행은 source/config/split/environment binding과 UUID별 checkpoint provenance에 결합합니다. 8차 서버는7차 런 경계를 읽는 관측 계층으로 학습을 제어하지 않습니다. 질의 처리만 변경하고 원본 gallery와 baseline weights를 고정한 확장 평가에서 항등 조건의 baseline reuse를 별도 표시합니다. 두 데이터셋42행의 각 verification/retrieval 결과를84taskcondition으로 집계하며, 조건 수와 학습 횟수·독립 환자 수를 혼동하지 않습니다.

재개 감사는 실패 원문·원자 교체 임시파일·마지막 이벤트·checkpoint hash·프로세스 신원을 보존한 뒤 진행합니다. terminal placeholder0과 마지막 처리 배치 관측을 분리하고 checkpoint 이후 재실행 구간과 worker augmentation RNG의 비트 연속성 한계를 밝힙니다. 공식 지원 resume을 성공했다고 보고하려면 프로세스 존재뿐 아니라 새 global_step 전진이 필요합니다. 파일 공유 충돌·AV·권한 등은 실제 증거 없이 원인으로 확정하지 않습니다.

## 결과 읽기와 한계

| 값 | 읽는 방법 | 한계 |
| --- | --- | --- |
| 손실 | 해당 학습·검증 단계의 저장 원값 | 시험 정확도와 다름 |
| 백분율 | 소수 첫째 자리 반올림·원비율 펼침 | 반올림100.0%와 실제1 구분 |
| PrivacyScore@1 | 100×(1−P@1) | 고정 공격의 실패율, 익명성 보장 아님 |
| 논문 기준 | 비교를 위한 외부 참고값 | 이번 실험의 관측 성능이 아님 |

관측 결과와 논문 기준을 출처별로 분리하며 원비율·소수 첫째 자리 반올림·정확히1의 의미를 보존합니다. PrivacyScore@1의 보수 변환은 고정 공격에 대한 operational metric이며 공식 프라이버시 보장이나 임상 utility를 대신하지 않습니다. 원 논문 모든 cohort/ablation 및 역사적 실행 바이너리 동등성을 재현한 것은 아닙니다. 공개 원문·전체 비교·라이선스를 보존하고 PHI·medical images·per-image manifests·weights·operational logs는 공개에서 제외합니다.
