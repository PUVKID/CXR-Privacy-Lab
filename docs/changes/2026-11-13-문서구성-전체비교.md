+
+환자 재식별 모델을 새로 학습하고 원본·블러·모자이크의 재식별 성능을 비교하는 로컬 연구 도구입니다. 공개 CXR 최종 가중치를 사용하는 평가와 ImageNet 초기화에서 시작하는 새 학습을 구분합니다.

+## 현재 실험
