# 5차와 6차의 전체 비교

5차의 데이터 정제와 새 학습 실행은 보존하고,6차는 해당 실험을 보여 주는 화면 탐색을 보완합니다.

| 범위 | 5차 | 6차 |
| --- | --- | --- |
| 단계·강도 | 요약과 결과 표 | 원본 1·블러 10·모자이크 10조건 선택과 상세 |
| 학습·평가 | 학습 요약과 평가 흐름 | 학습 3과정과 평가 3단계, 공유 모델·질의 변환 설명 |
| 현재 실행 | 5차 화면·실험 | 6차 화면이 기존 5차 실행을 명시적으로 연결 |
| 백분율 | 소수 둘째 자리 버림 | 소수 첫째 자리 반올림·원값·100.0% 구분 |
| 검증 해석 | 항목별 판정 기준 | 코드 수정·검사 근거와 성능 미확인 상태 구분 |
| 유지 조건 | NIH·COVID 파생 집합,모델·손실·학습 조건 | 생산 실험 코드 보존 |

공개 대상의 주석·공백까지 포함한 [전체 변경](비교%20자료/5차_대비_전체_변경.diff)과 [파일별 크기·해시](비교%20자료/파일_비교.json)를 확인합니다. 비교 문서 자체와 생성 비교 자료의 자기 참조는 내용 비교에서 제외하며 전체 공개 묶음에는 포함합니다. 권한 미확인 평가 엔진은 로컬 검토에는 포함하고 공개는 보류합니다.
