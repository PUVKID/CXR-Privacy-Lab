# 6차 변경 기록

평가 단계와 강도마다 조건을 확인할 수 없던 화면에 단계·강도 선택과 상세 정보를 추가합니다. 학습3과정과 평가3단계를 구분하고, 같은 새 모델을21조건에 평가하는 현재 코드의 실제 구조를 설명합니다.

- 원본1·블러10·모자이크10조건을 선택하고 현재 실행의 같은 조건 결과를 확인합니다. 미측정·대기·진행·완료는 실제 근거와 구분합니다.
- 화면6차와 연결 실험5차를 분리하고 기존 실행을 이어 보여 줍니다. 모델·손실·데이터·학습 설정은 변경하지 않습니다.
- 백분율을 소수 첫째 자리 반올림으로 표시하고 원값을 펼쳐 확인합니다. 반올림100.0%와 실제 원비율1을 구분합니다. 5차의 이전 표시 정책과 기록은 보존합니다.
- 원 감사 보고서의 코드 수정 근거와 실험·성능 미확인 항목을 구분하는 설명을 보완합니다.

한 줄·주석·공백까지 실제 차이는 [전체 비교](이전_차수_비교.md)에 연결합니다. 의료 원영상·가중치·영상별 목록·비공개 운영 기록은 공개하지 않습니다.

## 11월 13일 재개 확인

기존 실행은 검증 모델의 에폭1 도중 최소3,326회 가중치 갱신 후 CUDA 오류로 중단됐습니다. 최종 모델·검색 학습·21조건 평가 결과는 아직 없습니다. 실패 상태 파일의 초기화된0을 전체 학습0회로 표시하지 않도록 오류 상태와 마지막 정상 관측 기록·시각을 별도로 보여 줍니다. 학습 로그와 수치는 바꾸지 않습니다.

현재 주소의21개 조건을 실제 클릭해 상세 제목과 선택 상태를 확인했습니다. 계산 회귀는75초 정식 제한에서 시간 초과한 실패 이력을 보존합니다. 별도 계측 실행의88개 통과는 정식 검사 통과나 학습 성공을 대신하지 않습니다.
