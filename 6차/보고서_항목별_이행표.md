# 2차 감사 보고서의 문제와 후속 수정

기준은 보존한 `2차/정밀_검증_보고서.md`의9개 문제입니다. 해당 코드 결함의 수정과 회귀검사 이력은 확인했지만, 이것이 논문 성능 재현이나 모든 실험 완료를 뜻하지는 않습니다. 중복 정제와 검증 메모리 혼입 방어를 추가한 재학습이며 공식 데이터·환경을 그대로 사용한 완전 재현과 구분합니다.

이 표는 5차 계산·실행관리 코드와 독립 검증 영수증을 읽어 작성했습니다. 6차의 화면 변경은 진행 중인5차 계산 설정을 바꾸지 않습니다. 특정 실행의 현재 상태는 이 공개 문서에 고정하지 않으며 실제 학습 시작·완료·성능은 실행별 근거를 확인해야 합니다.

## 코드 검사와 성능 검증의 경계

5차의 최종 독립 명세 검사는 대시보드·보안, 계산, 실행관리 세 항목 모두 종료 코드0을 기록했습니다. 계산 검사33.453초는 정식75초 제한 안의 실행 기록이며 전체120초 기준을 늘리지 않았습니다. 이전75.312초 시간 초과와 검증실패 누적3회는 보존합니다. 합성 임시 파일을 시스템 임시 폴더로 옮긴 수리도 검사 대상781개와 assertion을 줄이지 않았습니다.

다음 내용은 코드 검사 통과만으로 결론을 낼 수 없습니다.

- 새 검증 모델과 검색 모델의 실제 학습 완료 및 최종 체크포인트 생성
- NIH 원본과20개 변형 조건, COVID 외부검증의 실제 지표·곡선
- 논문 보고값과의 차이, 새로운 공격자 재학습·복원 공격에 대한 방어
- 진단 유용성, 임상적 안전성, 환자 단위 불확실성 또는 완전 익명성

원본·블러·모자이크는 현재 같은 최종 검증·검색 모델의 평가 조건입니다. 강도별 재학습이 완료됐다는 설명은 맞지 않습니다. 학습 과정의 `verification`·`retrieval_phase1`·`retrieval_phase2`와 평가1·2·3단계의 차이는 [단계별 실험 구조](문서/단계별_실험_구조.md)에 정리했습니다.

## 논문 근거와 확장 연구의 범위

[2022년 원논문](https://www.nature.com/articles/s41598-022-19045-3)과 [공식 전체 원문](https://www.ebi.ac.uk/europepmc/webservices/rest/PMC9434540/fullTextXML), [고정 저자 코드](https://github.com/kaipackhaeuser/CXR-Patient-ReID/tree/880168f564afa07936a8d8fb3b868b140ab937d9)를 기준으로 과제·모델·분할·평가를 대조했습니다. 원논문의 해상도·이물질·외부검증과 첨부 프로젝트의 블러10강도·모자이크10강도를 분리합니다. 2차 보고서의 “10강도 일치”는 첨부 코드와 일치한다는 뜻이며 원논문의 조건이라는 주장이 아닙니다.

CheXpert와 원논문의 모든 훈련 조건 탐색·임상 속성별 분석은 현재 범위에 포함하지 않습니다. NIH/COVID 중복 정제 때문에 원논문과 동일한 전체 데이터 분모도 아닙니다. 프라이버시 보수 점수는 CMC-R1을 사용하는 [Tian 외의 연구](https://openaccess.thecvf.com/content/ICCV2025/papers/Tian_Semantic_versus_Identity_A_Divide-and-Conquer_Approach_towards_Adjustable_Medical_Image_ICCV_2025_paper.pdf)를 지표 근거로 삼은 이번 확장 연구의 정의이며, Tian의 동일 공식·동일 실험 재현으로 인용하지 않습니다.
