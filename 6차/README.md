# 6차 — 단계와 강도를 골라 보는 재식별 실험

1단계 원본, 2단계 블러, 3단계 모자이크를 선택하고 각 강도의 조건·진행·실제 결과를 확인하는 대시보드입니다. **화면은 6차, 연결한 실험은 기존 5차 실행**입니다. 화면 개편만으로 기존 실행을 다시 시작하지 않습니다.

2026-11-13 확인 시 연결 실험은 CUDA 오류로 중단된 상태입니다.

<a id="-학습과-평가"></a>

## 학습과 평가

검증 모델 학습 → 검색 모델 출력부 학습 → 검색 모델 전체 학습을 마친 뒤, 같은 실행에서 만든 두 모델로 21조건을 평가합니다. 강도마다 모델을 다시 학습하는 구조는 아닙니다. 강도별 재학습은 별도 실험 설계입니다.

| 평가 단계 | 선택 조건 | 변환 |
| --- | --- | --- |
| 1단계 원본 | 원본 0 | 변환 없이 검증·검색 |
| 2단계 블러 | 0,2,4,8,16,32,64,128,256,512 | 원영상 픽셀 기준 Gaussian 반경 |
| 3단계 모자이크 | 1,4,8,16,32,64,128,256,512,1024 | 목표 타일 크기(px) |

변형은 질의에만 적용하고 검색 갤러리는 원본으로 고정합니다. 자기 원본은 검색에서 제외합니다. 블러 0과 모자이크 1도 각 단계의 별도 조건입니다. 원본 모델의 논문 재현과 블러·모자이크 확장 비교를 구분합니다. [단계별 실험 구조](문서/단계별_실험_구조.md)에서 실제 코드와 지표를 확인합니다.

<a id="️-화면-사용"></a>

## 화면 사용

단계 선택 → 강도 선택 → 상세 정보 순서로 확인합니다. 결과가 없는 조건도 선택할 수 있고 미측정으로 표시합니다. 현재 실행의 같은 단계·강도 결과만 연결하며 선택은 3초 갱신 뒤에도 유지합니다. 학습 3과정과 평가 3단계는 별도로 보여 줍니다.

백분율은 **소수 첫째 자리 반올림** 표시입니다. 저장 원비율과 전체 자릿수는 펼쳐 확인하고 반올림 100.0%와 실제 원비율 1을 구분합니다. AUC·손실·학습률 원값도 유지하며 결과 CSV·JSON을 표시 목적으로 변경하지 않습니다.

흰색·회청색, 나눔고딕 Bold700, 양쪽 테마·모션 제어를 유지합니다.

<a id="️-실행과-보존"></a>

## 실행과 보존

`대시보드_시작.cmd` 또는 Node.js로 `6차/server.mjs`를 실행하고 `http://127.0.0.1:8787/`에 접속합니다. 화면 6차는 고정한 5차 실행 관리자의 현재 상태·학습·결과를 연결합니다. 시작·중단도 같은 실행 관리자를 사용해 중복 실행을 막습니다. 원본과 1~5차는 보존합니다. 실험 코드와 학습 설정은 5차의 보존 사본이며 이번 변경으로 강도별 재학습을 추가한 것은 아닙니다.

<a id="-검증과-해석"></a>

## 검증과 해석

[보고서 항목별 이행표](보고서_항목별_이행표.md)에서 코드 수정·검사와 실제 학습·성능 재현의 확인 상태를 구분합니다. NIH34장·COVID4장 제외, 검증 메모리 혼입 방어와 Windows 포팅으로 원 논문의 모든 조건을 그대로 복제한 전체 재현은 아닙니다. 프라이버시 점수는 고정 공격의 Rank-1 실패율을 0~100으로 환산한 조작적 지표이며 익명성·진단 효용을 보장하지 않습니다.

의료 원영상·영상별 목록·가중치·운영 기록과 재배포 권한 미확인 엔진은 공개하지 않습니다.
