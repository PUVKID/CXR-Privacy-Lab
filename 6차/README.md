**읽는 예:**책의 목차를 새로 만들었다고 책의 실험을 다시 한 것은 아닙니다. 6차는 5차에서 계산한 기록을 더 잘 찾아보게하는 화면입니다. 원본·블러·모자이크 중 하나를 누르고 강도를 고르면 그 조건의 설명과 저장된 점수를 읽습니다.

블러는 영상의 주변 색을 섞어 흐리게 하는 처리이고 모자이크는 작은 색 묶음으로 바꾸는 처리입니다. 숫자는 원본 사진의 픽셀 크기 기준입니다. 질의는 찾고 싶은 사진, 갤러리는 비교할 후보 묶음입니다. 이 실험은 질의만 바꾸며 같은 모델과 원본 후보를 유지합니다.

**상태 읽기:**결과가 없는 강도도 눌러 볼 수 있으나 점수는 미측정입니다. 선택이 3초 갱신 뒤에도 남는 기능은 계산 완료와 별개입니다. 당시 연결 실험이 CUDA 오류로 멈췄다는 기록도 유지합니다. GPU 계산 도구인 CUDA의 오류를 화면 개편 성공으로 지우지 않습니다.

**결과 보고:** 저장된 측정값과 논문 기준을 구분합니다. 손실은 시험 정확도가 아니며 PrivacyScore @1은 고정 공격의 1 순위 실패율입니다. 이 값만으로 익명성·임상 효용을 보장하지 않습니다. 의료 영상·개인별 목록·모델 가중치·운영 원문은 공개하지 않습니다.

[11/13시점 원격 설명(보존) · 같은 LEVEL 4](https://github.com/PUVKID/CXR-Privacy-Lab/blob/2434a1e29533a74b7acc60a6799c8da550c91ac7/6%EC%B0%A8/README.md#reading-level-4) — 당시 6차까지의 설명이며 현재 7·8차 관측과 구분합니다.

| 구현 경계 | 보존하는 계약과 사실 | 변경 영향 |
| --- | --- | --- |
| 목적 | 화면은 6차이고 계산은 기존 5차 실행인 상태에서 평가 단계와 강도를 선택하는 탐색 화면을 만들었습니다. | 상태·제어·수치 계산의 책임을 분리합니다. |
| 입력 | 5차의 고정 실행 UUID 아래 상태·학습 기록·단계별 summary.csv와 로컬 변환 예시만 연결합니다.<br>새 학습 결과를 만든 화면 차수가 아닙니다. | 출처 결합과 입력 검증의 경계입니다. |
| 처리 | 원본·블러·모자이크의 큰 단계 버튼에서 강도 칩으로 이동하고 그 조건의 단일 결과 행을 찾습니다.<br>중복 결과는 임의 선택 대신 확인 필요로 표시합니다. | 실패 전파와 결과 격리를 검토합니다. |
| 설정·조건 | 원본 0; 블러 0,2,4,8,16,32,64,128,256,512; 모자이크 1,4,8,16,32,64,128,256,512,1024의 21 조건입니다.<br>학습 3 과정과 평가 3 단계를 구분합니다. | 재현 조건·설계 차이의 일부입니다. |
| 출력 | 3초 갱신 뒤에도 선택·포커스·원값 펼침을 유지합니다.<br>백분율 첫째 자리 반올림, 원비율 1 과 반올림 100.0% 구분, 테마·모션 제어를 제공합니다. | 출력 계약을 바꾸면 소비자 검사도 필요합니다. |
| 과거·현재 관측 | 2026-11-13 확인 때 연결된 5차 실행은 CUDA 오류로 중단됐습니다.<br>오류의 진행 0 과 과거 정상 기록을 구분하도록 보완했고 화면 개편으로 성능 달성을 주장하지 않습니다. | 증거의 범위를 유지합니다. |
| 한계 | 6차 조건의512/1024 강도를 현재 7차의 0~256 조건에 섞지 않습니다.<br>NIH·COVID 정제와 검증 메모리 방어가 있는 5차의 한계를 그대로 가집니다. | 남은 위험과 의도된 변경을 구별합니다. |
| 실행·검사 | 대시보드 _시작.cmd 또는 node server.mjs로 엽니다.<br>이 차수의 시작·중단은 5차 관리자에 연결됩니다.<br>Node·실제 21 조건 클릭·테마·키보드·모션 검사와 모델 검사는 별도입니다. | 구조·실제 동작·모델 성능 검증을 구별합니다. |

**선택·갱신 경계:**정의된 단계/강도만 hash 선택으로 받아들이고 같은 실행의 단일 summary 행만 상세에 연결합니다.

중 복 행은 최신 추정 선택을 금지합니다.

주기 갱신은 칩 DOM을 보존해 키보드 포커스가 사라지지 않게하고 테마·모션 상태와 평가 상태를 독립적으로 둡니다.

API executionRoot는 5차, 정적 root는 6차여서 제어·로그·결과 모두 같은 실행에 결합해야 합니다.

마지막 summary 한 행을 전체 21 조건 완료로 확대하지 않으며 source·분모·원값을 각 조건에 붙입니다.

**결과 보고:** 저장된 측정값과 논문 기준을 구분합니다. 손실은 시험 정확도가 아니며 PrivacyScore @1은 고정 공격의 1 순위 실패율입니다. 이 값만으로 익명성·임상 효용을 보장하지 않습니다. 의료 영상·개인별 목록·모델 가중치·운영 원문은 공개하지 않습니다.

## LEVEL 5 - Expert · 전체 상세와 근거

[11/13시점 원격 설명(보존) · 같은 LEVEL 5](https://github.com/PUVKID/CXR-Privacy-Lab/blob/2434a1e29533a74b7acc60a6799c8da550c91ac7/6%EC%B0%A8/README.md#reading-level-5) — 당시 6차까지의 설명이며 현재 7·8차 관측과 구분합니다.

## 🩻 6차 — 단계와 강도를 골라 보는 재식별 실험

1 단계 원본, 2 단계 블러, 3 단계 모자이크를 선택하고 각 강도의 조건·진행·실제 결과를 확인하는 대시보드입니다. **화면은 6차, 연결한 실험은 기존 5차 실행**입니다. 화면 개편만으로 기존 실행을 다시 시작하지 않습니다. 2026-11-13 확인 시 연결 실험은 CUDA 오류로 중단된 상태입니다.

## 🧪 학습과 평가

검증 모델 학습 → 검색 모델 출력 부 학습 → 검색 모델 전체 학습을 마친 뒤, 같은 실행에서 만든 두 모델로 21 조건을 평가합니다. 강도마다 모델을 다시 학습하는 구조는 아닙니다. 강도별 재학습은 별도 실험 설계입니다.

| 평가 단계 | 선택 조건 | 변환 |
| --- | --- | --- |
| 1 단계 원본 | 원본 0 | 변환 없이 검증·검색 |
| 2 단계 블러 | 0,2,4,8,16,32,64,128,256,512 | 원영상 픽셀 기준 Gaussian 반경 |
| 3 단계 모자이크 | 1,4,8,16,32,64,128,256,512,1024 | 목표 타일 크기(px) |

변형은 질의에만 적용하고 검색 갤러리는 원본으로 고정합니다. 자기 원본은 검색에서 제외합니다. 블러 0 과 모자이크 1 도 각 단계의 별도 조건입니다. 원본 모델의 논문 재현과 블러·모자이크 확장 비교를 구분합니다. [단계별 실험 구조](문서/단계별_실험_구조.md)에서 실제 코드와 지표를 확인합니다.

## 🖱️ 화면 사용

단계 선택 → 강도 선택 → 상세 정보 순서로 확인합니다. 결과가 없는 조건도 선택할 수 있고 미측정으로 표시합니다. 현재 실행의 같은 단계·강도 결과만 연결하며 선택은 3초 갱신 뒤에도 유지합니다. 학습 3 과정과 평가 3 단계는 별도로 보여 줍니다.

백분율은 **소수 첫째 자리 반올림** 표시입니다. 저장 원비율과 전체 자릿수는 펼쳐 확인하고 반올림 100.0%와 실제 원비율 1을 구분합니다. AUC·손실·학습률 원값도 유지하며 결과 CSV·JSON을 표시 목적으로 변경하지 않습니다. 흰색·회청색, 나눔고딕 Bold700, 양 쪽 테마·모션 제어를 유지합니다.

## ▶️ 실행과 보존

`대시보드_시작.cmd` 또는 Node.js로 `6차/server.mjs`를 실행하고 `http://127.0.0.1:8787/`에 접속합니다.

화면 6차는 고정한 5차 실행 관리자의 현재 상태·학습·결과를 연결합니다.

시작·중단도 같은 실행 관리자를 사용해 중복 실행을 막습니다.

원본과 1~5차는 보존합니다.

실험 코드와 학습 설정은 5차의 보존 사본이며 이번 변경으로 강도별 재학습을 추가한 것은 아닙니다.

## 🔎 검증과 해석

[보고서 항목별 이행표](보고서_항목별_이행표.md)에 서 코드 수정·검사와 실제 학습·성능 재현의 확인 상태를 구분합니다.

NIH34장·COVID4장 제외, 검증 메모리 혼입 방어와 Windows 포팅으로 원 논문의 모든 조건을 그대로 복제한 전체 재현은 아닙니다.

프라이버시 점수는 고정 공격의 Rank-1 실패율을 0~100으로 환산한 조작적 지표이며 익명성·진단 효용을 보장하지 않습니다.

의료 원영상·영상별 목록·가중치·운영 기록과 재배포 권한 미확인 엔진은 공개하지 않습니다.
