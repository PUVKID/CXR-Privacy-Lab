### LEVEL 1 · 목적과 대상

**이 차수의 목적과 실제 구성**

1단계 원본, 2단계 블러, 3단계 모자이크를 선택하고 각 강도의 조건·진행·실제 결과를 확인하는 대시보드입니다. **화면은 6차, 연결한 실험은 기존 5차 실행**입니다. 화면 개편만으로 기존 실행을 다시 시작하지 않습니다.

2026-11-13 확인 시 연결 실험은 CUDA 오류로 중단된 상태입니다.

흉부 엑스레이를 흐리게 하거나 모자이크로 바꿔도 같은 환자의 다른 사진을 찾아낼 수 있는지 살피는 실험입니다. 검증은 두 사진이 같은 사람인지 비교하고, 검색은 여러 사진 중 같은 사람을 찾는 작업입니다. **화면의 변환 미리보기는 평가 결과가 아닙니다.**

### LEVEL 1 · 달라진 내용과 차수 관계

화면6차가 기존5차 실행을 읽도록 개편한 차수입니다. 화면 수정으로 실제 학습을 재시작하지 않습니다.

어떤 사진이 누구의 것인지 다시 찾는 것이 재식별입니다. 흐리게 한 사진을 모델에 넣고 같은 환자의 다른 촬영 사진이 검색되는지 봅니다. 자기 사진을 그대로 정답 후보에 두면 쉬운 비교가 되므로 제외합니다.

### LEVEL 1 · 처리 절차

단계 선택 → 강도 선택 → 상세 정보 순서로 확인합니다. 결과가 없는 조건도 선택할 수 있고 미측정으로 표시합니다. 현재 실행의 같은 단계·강도 결과만 연결하며 선택은 3초 갱신 뒤에도 유지합니다. 학습 3과정과 평가 3단계는 별도로 보여 줍니다.

흰색·회청색, 나눔고딕 Bold700, 양쪽 테마·모션 제어를 유지합니다.

<a id="️-화면-사용"></a>

## 화면 사용

단계 선택 → 강도 선택 → 상세 정보 순서로 확인합니다. 결과가 없는 조건도 선택할 수 있고 미측정으로 표시합니다. 현재 실행의 같은 단계·강도 결과만 연결하며 선택은 3초 갱신 뒤에도 유지합니다. 학습 3과정과 평가 3단계는 별도로 보여 줍니다.

백분율은 **소수 첫째 자리 반올림** 표시입니다. 저장 원비율과 전체 자릿수는 펼쳐 확인하고 반올림 100.0%와 실제 원비율 1을 구분합니다. AUC·손실·학습률 원값도 유지하며 결과 CSV·JSON을 표시 목적으로 변경하지 않습니다.

<a id="️-실행과-보존"></a>

## 실행과 보존

`대시보드_시작.cmd` 또는 Node.js로 `6차/server.mjs`를 실행하고 `http://127.0.0.1:8787/`에 접속합니다. 화면 6차는 고정한 5차 실행 관리자의 현재 상태·학습·결과를 연결합니다. 시작·중단도 같은 실행 관리자를 사용해 중복 실행을 막습니다. 원본과 1~5차는 보존합니다. 실험 코드와 학습 설정은 5차의 보존 사본이며 이번 변경으로 강도별 재학습을 추가한 것은 아닙니다.
