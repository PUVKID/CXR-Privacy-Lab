## LEVEL 1 - Beginner

| 용어 | 쉬운 뜻 | 이번 실험에서 하는 일 |
| --- | --- | --- |
| 새 모델 | 사진 특징을 배울 계산 장치를 처음 상태에서 준비 | 원본과 각 강도마다 별도로 시작 |
| 검증·검색 | 두 사진의 환자가 같은지 비교·여러 후보에서 같은 환자 찾기 | 각 조건에서 두 모델을 만들고 외부 자료로도 시험 |
| 에폭·배치·손실 | 자료 한 바퀴·한 묶음·학습 오차 | 정확도와 다르며 아직 없으면 미측정 |

**원본부터 10차에서 다시 시작**합니다. 일반 사진을 배운 ImageNet을 공통 출발점으로 삼고, 이미 흉부 사진을 배운 7차 모델은 넘겨받지 않습니다. 블러는 주변을 부드럽게 섞고 모자이크는 작은 칸으로 뭉개는 변환입니다. 두 변환은 연구자가 비교하려는 차별점입니다.

블러 2와 블러 4는 다른 모델입니다. 변형이 없는 블러 0도 별도로 학습하므로 같은 결과를 자동 복제하지 않습니다. NIH로 학습하고 COVID-19로 외부 평가합니다. 화면에서 원본 상세나 강도 버튼을 누르면 그 조건의 기록만 봅니다. 새 실행을 시작한 사실과 전체 학습을 마친 사실은 다릅니다.

Adam·SGD는 모델 수치를 고치는 학습 방법이고 OneCycle은 학습률을 바꾸는 계획입니다. CBM은 최근 특징을 기억하는 검색 학습 메모리입니다. 검증 모델은 최대 100에폭·개선 없음 5회 조기 종료, 검색 출력부는 30에폭·전체는 50에폭입니다. 이 설정과 배치 32를 유지하며 단계별 시간을 같다고 계산하지 않습니다.

**21개의 새 학습 조건**과 이전 모델 하나의 21개 변환 평가는 다른 실험입니다. 현재 순차 실행은 새 원본을 첫 번째로 학습하며 7차 완료를 기다리지 않습니다. 이전 7차는 중단한 이력으로 보존합니다. 조건 사이에는 optimizer·스케줄러·CBM·난수 상태까지 넘기지 않습니다.

NIH의 학습·검증·시험 역할과 COVID-19의 외부 평가 역할을 구분합니다. 데이터셋과 블러·모자이크 확장은 이번 비교 범위이고, 학습 방법의 원논문 대비 차이는 따로 확인합니다. 원저자 목록을 쓰므로 기존 중복과 검증 메모리 정책의 한계가 사라졌다고 주장하지 않습니다.

기존 통과 검사는 재사용했고 이번에는 새 연결과 경계에 필요한 최소 검사만 수행했습니다. CPU 실변환 검사는 import 시간 상한으로 미완료입니다. 실행 자식이 시작됐다는 관측을 전체 학습·평가 완료나 성능으로 쓰지 않습니다.

CXR 동일 프로젝트의 중복 학습·평가는 차단하고 기존 단계별 메모리 여유 기준은 유지합니다. 외부 GPU 작업 목록 자체를 일괄 종료·차단 근거로 쓰지 않습니다. 코드 검사와 실제 21개 조건의 완주는 구분합니다.

# 새 원본부터 시작하는 강도별 독립 학습 · 10차

10차에서 원본 모델부터 새로 학습한 뒤 블러·모자이크의 각 강도에서도 별도 모델을 학습합니다. 이전 7차 학습과 대기열은 사용자 요청으로 중단하고 보관했습니다. 기존 CXR 체크포인트를 이어받거나 7차의 완료를 기다리지 않습니다.

| 조건 | 새로 만드는 모델 | 순서와 평가 |
| --- | --- | --- |
| 원본 `original_000` | 검증 모델과 검색 모델 | 첫 번째로 새 학습, 해당 모델의 원본 조건 평가 |
| 블러 10개 | 각 강도의 검증·검색 모델 | 0, 1, 2, 4, 8, 16, 32, 64, 128, 256 픽셀 |
| 모자이크 10개 | 각 강도의 검증·검색 모델 | 같은 10개 강도, 각 조건의 학습과 평가가 끝나야 다음 조건 실행 |

총 21개 학습 조건입니다. 블러 0, 모자이크 0·1은 픽셀 변형이 없는 항등 조건이지만 모델을 재사용하지 않고 각각 새로 학습합니다. 같은 모델의 질의만 변형했던 이전 고정 공격 평가와 구분합니다. NIH는 학습·내부 검증·시험, COVID-19는 외부 평가에 사용합니다. 두 데이터셋과 블러·모자이크 확장은 이번 비교 연구의 범위이며 그 추가 자체를 원논문 방법 재현 실패로 세지 않습니다. 원논문의 방법과 실제 구현 차이는 따로 대조합니다.

## 학습 조건과 데이터 처리

| 과정 | 설정 | 상태 연결 |
| --- | --- | --- |
| 검증 모델 | ImageNet·시드 3, Adam, 학습률 0.0001, 배치 32, 최대 100에폭·개선 없음 5회 조기 종료 | 해당 조건의 선택 가중치 |
| 검색 출력부 | ImageNet 백본 고정, SGD·OneCycle, 배치 32, 30에폭 | 같은 조건의 마지막 출력부 가중치 |
| 검색 전체 | 같은 조건의 출력부 가중치, 새 optimizer·scheduler·CBM, 배치 32, 50에폭 | 같은 조건의 최종 검색 모델 |

조건 사이에는 CXR 가중치·optimizer·scheduler·CBM·RNG 상태를 넘기지 않습니다. 같은 조건 안의 검색 출력부 → 전체 단계 연결은 정상적인 내부 승계입니다. 같은 조건의 명시적 재개는 전체 프로토콜·조건·실행 지문이 일치할 때만 허용합니다. 이번 새 원본은 이전 체크포인트의 재개로 시작하지 않습니다.

원영상에 조건 변환을 적용한 뒤 모델별 크기 변환과 정규화를 수행합니다. 검증쌍 양쪽과 검색 학습·검증 영상에 같은 조건을 적용하며, 평가의 질의와 갤러리도 같은 조건입니다. 원본 파일은 수정하지 않습니다. 구체적인 변환 정의·원저자 분모·최적화 설정과 실행 조건은 [학습 안내](학습안내.md)를 따릅니다.

## 실행과 조회의 경계

| 구성 | 읽거나 만드는 기록 | 확인 기준 |
| --- | --- | --- |
| 순차 실행기 | `work/queue/state.json`, `start_mode=fresh_all_21` | 새 원본을 포함한 21개 조건, CXR 중복 실행 차단 |
| 조건별 학습 | `work/runs/<UUID>/training/` | 허용 조건·정규 UUID·조건 지문·설정 결합 |
| 상단 원본 진행 | `original_000`의 progress·events·단계 기록·로그 | 7차의 진행·손실을 대신 표시하지 않음 |
| 강도 선택 | 블러·모자이크 20개 버튼과 새 원본 상세 버튼 | 해당 조건의 기록만 조회, 늦은 이전 응답 거절 |
| 현재 실행 판단 | 최근 진행과 PID·생성시각·명령·관리자 계보 | 파일이나 큐 상태 하나만으로 학습 중 단정하지 않음 |
| 완료 | 조건별 학습·평가 정상 종료와 모델·두 데이터셋 지표 결합 | 이전 7차의 고정모델 84개 평가 상태와 합치지 않음 |

상단은 새 원본의 현재 에폭·남은 배치와 최대 예정 에폭 기준 단계 진행을 보여 줍니다. 최대 예정량의 비율은 전체 실험 시간 완료율이 아닙니다. 학습·검증 손실은 최근 256 KiB 범위와 실제 축을 구분하며, 단계 전환·되감기·손상 기록을 잇지 않습니다. 백분율 요약은 소수 첫째 자리 반올림이고 저장 원비율·손실·학습률을 펼쳐 확인할 수 있습니다. 미측정은 0이 아닙니다.

대시보드는 읽기 전용입니다. 모션 정지·화면 종료는 학습 중지 요청이 아니며 시작·종료 API를 제공하지 않습니다. 기본 서버는 `node server.mjs`로 로컬 8787에 연결합니다. 시험용 `createDashboard()`는 별도 포트에서 사용할 수 있습니다. 기존 7차 형식의 격리 fixture에 명시적 `executionRoot`를 전달하는 호환 모드와 달리 새 원본 fixture에는 `freshOriginal:true`를 사용합니다. 실제 서버 교체와 학습은 별도 프로세스입니다.

## 관측과 검증 범위
