# 원논문 실험 방법과 10차 코드 대조

**검증 모델과 검색 모델의 기본 학습 방법은 저자 코드에 맞춰 구현되어 있습니다.**  
다만 현대 PyTorch 이식과 평가 처리 차이가 있어, 모든 계산이 원본과 완전히 같다고 표현하지 않습니다. 이 문서는 설정과 소스를 대조한 결과이며 실제 학습 완료나 논문 성능 재현을 보고하는 문서가 아닙니다.

사용자가 지정한 NIH·COVID 두 데이터셋을 사용합니다.  
데이터셋 선택과 블러·모자이크를 추가한 연구 조건 자체는 방법 불일치로 세지 않습니다.  
NIH에서 학습·검증하고 COVID는 외부 평가에만 사용합니다.  
원본 조건도 10차에서 새로 시작하며 다른 조건의 CXR 가중치나 학습 상태를 가져오지 않습니다.

## 구분해서 남기는 차이

**학습 핵심 설정을 바꿔야 할 불일치는 이번 소스 대조에서 발견하지 않았습니다.** 다만 아래 차이는 논문과 완전히 같은 실행이라는 주장에 포함하면 안 됩니다.

- **논문 본문과 공식 구현의 validation 차이:** 현재 검증 모델은 공식 RNP 분기를 따릅니다.  
  고정된 validation 쌍이라는 본문 서술을 문자 그대로 따른 구현과는 다릅니다.  
  이 때문에 validation 손실·조기 종료 시점이 달라질 수 있습니다.
- **현대 실행 차이:** 원본 검증 의존성은 torch 1.7.1, 검색은 torch 1.6.0·Lightning 1.0.5입니다.  
  현재는 현대 PyTorch, 명시적 에폭별 난수, TF32 비활성화와 activation checkpointing을 사용합니다.  
  checkpoint 재계산 때 BN 버퍼를 복구하여 이중 갱신을 막지만, GPU·라이브러리·작업자 난수열까지 원본과 같은 수치 경로라고 보장하지 않습니다.  
  관련 구현은 [engine.py L56–98](src/training/engine.py#L56)입니다.
- **bootstrap 구현 차이:** 저자 `Utils.py L148`의 상한은 마지막 시험쌍을 추출하지 못합니다.  
  현재 [evaluation.py L162](src/cxr_reid/evaluation.py#L162)는 전체 쌍을 복원추출하며 분위수 CI를 계산합니다.  
  논문의 bootstrap 목적을 따르되 이 결함과 구형 분위수 인덱스를 그대로 복제하지 않습니다.  
  따라서 CI 원값의 완전 일치는 기대하지 않습니다.
- **동점·자기 영상 처리 차이:** 구형 FAISS 경로는 최근접 결과의 첫 항목을 제거합니다.  
  현재는 정확한 자기 영상의 대각 항목을 제거하고, 거리가 같은 후보는 고유 파일명 순서로 정합니다.  
  동일 임베딩이 있는 경우 순위와 지표가 달라질 수 있습니다.  
  다른 파일명의 동일 픽셀 영상을 모두 제거하는 정책은 아닙니다.
- **기록·계산 경로 차이:** 에폭 학습손실 표시는 영상 수 가중 평균이며 저자 검증 로그는 배치 평균입니다.  
  validation 모델 선택 기준은 저자와 같은 배치 평균입니다.  
  평가의 배치 분할과 임베딩 캐시·마지막 FC 계산 경로도 원본 실행과 다르지만 동일 모델의 평가식을 사용합니다.

이 대조는 자료·소스 확인입니다.  
같은 검사를 다시 실행하거나 학습을 중단하지 않았으며, 실제 조건별 초기화·첫 optimizer 갱신·학습 완료·성능은 해당 실행의 결과 기록으로 별도 확인해야 합니다.  
추가 CPU 실변환 검사는 앞선 import 시간 상한 때문에 완료되지 않았으므로 이 문서를 그 검사 PASS 근거로 사용하지 않습니다.

현재 실행 조건과 저장 위치는 [학습안내](학습안내.md)에서 확인할 수 있습니다.
