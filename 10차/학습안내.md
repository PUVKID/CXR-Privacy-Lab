# 블러·모자이크 강도별 독립 학습

10차는 **각 강도로 변환한 영상에서 새 모델을 따로 학습**합니다. 보존된7차 원본 학습을 포함하면 원본1조건과 새20조건입니다. 기존7~9차의 한 모델을 고정한21조건 공격 평가는 다른 실험입니다. 이 확장은2022년 원논문에 보고된 블러·모자이크 재학습 실험이 아닙니다.

| 구분 | 학습과 평가 | 해석 |
| --- | --- | --- |
| 기존7차 원본 | 기존 원본 모델의 학습과 후속 원본·고정모델 평가를 유지 | 다시 시작하거나 덮어쓰지 않음 |
| 새10차20조건 | 조건마다 NIH 학습·검증과 새 모델의 같은 조건 평가 | 각 조건의 검증 모델과 검색 모델을 별도로 만듦 |
| COVID19 | 조건별 새 모델의 외부 평가에만 사용 | COVID별 별도 학습이나 모델 선택에 사용하지 않음 |

## 조건과 픽셀 단위

| 변환 | 강도 | 적용 위치 |
| --- | --- | --- |
| 블러 | 0,1,2,4,8,16,32,64,128,256 | 원영상 좌표계의 Pillow GaussianBlur 표준편차(픽셀) |
| 모자이크 | 0,1,2,4,8,16,32,64,128,256 | 원영상 좌표계의 명목 블록 크기(픽셀) |

블러0, 모자이크0·1은 영상에 항등변환을 합니다. **이 세 조건도 다른 모델이나 원본 결과를 재사용하지 않고 독립 학습합니다.** 모자이크는 가로·세로를 각각 `ceil(원본길이/강도)`로 BOX 축소한 뒤 NEAREST로 원래 크기로 복원합니다. 원본 크기가 강도의 배수가 아니면 경계의 실제 분할 크기가 달라질 수 있습니다. 원본 파일은 바꾸지 않습니다.

변환은 검증 학습쌍의 양쪽과 검색 학습·검증의 모든 영상에 적용합니다. 검증 모델의256×256 크기변환, 검색 모델의1024×1024 입력과 정규화보다 먼저 수행합니다. 검색 학습의 기존 ColorJitter는 조건 변환 뒤에 수행하고 검증·평가에는 적용하지 않습니다. 새 모델 평가의 **질의와 갤러리도 둘 다 같은 조건**입니다. 기존 고정 공격의 질의만 변환·갤러리 원본 정책과 구분합니다.

## 새 초기화와 재개

각 조건은 고정된 공식 ImageNet ResNet-50 초기값과 seed3으로 새 자식 프로세스에서 시작합니다. 다른 조건의 CXR 가중치·optimizer·scheduler·CBM·RNG를 이어받지 않습니다. 같은 초기값과 seed를 쓰므로 초기 가중치의 수치가 같은 것은 의도된 비교 조건이며 모델 상태를 공유한다는 뜻은 아닙니다.

| 학습 과정 | 유지하는7차 설정 | 같은 조건 안의 연결 |
| --- | --- | --- |
| 검증 모델 | Adam, 학습률0.0001, 배치32, 최대100에폭·검증손실 개선 없음5회 조기종료, 학습·검증 RNP | 검증에서 선택한 자체 가중치 |
| 검색 출력부 | ImageNet 백본 고정·학습모드 BN 유지, SGD·OneCycle, 배치32,30에폭 | 자체1단계 마지막 가중치 |
| 검색 전체 | 같은 조건의1단계 가중치, 새 optimizer·scheduler·CBM, 배치32,50에폭 | 자체2단계 마지막 가중치 |

검색 학습률0.158489·momentum0.9·weight decay0.00001·CBM128과7차 AMP/샘플링/스케줄러 정책을 유지합니다. 검색 validation과 초기 sanity2배치가 CBM을 갱신하는7차 원본 이식 정책도 유지합니다. 배치32를 줄이지 않으며 BN 버퍼를 복구하는 activation checkpointing을 사용합니다. GPU 여유가 없거나 다른 작업이 있으면 실패 폐쇄합니다.

`condition_fingerprint`는 조건 정의를 식별합니다. 별도의 전체 `protocol_fingerprint`와 checkpoint `binding`은 실제 학습률·에폭·해상도·seed·작업자 설정·소스·변환·평가 코드·공식 목록 SHA·환경·조건·실행 UUID를 함께 묶습니다. 변경된 조건이나 프로토콜로 기존 상태를 재개하지 않습니다. 재개는 자기 조건과 실행 UUID에만 명시적으로 허용합니다. 중간 에폭 재개의 작업자 증강 난수열은 비트 단위 동일성을 보장하지 않습니다.

## 순차 실행과 안전한 대기

실제 실행은 프로젝트의 실행 환경 Python을 사용합니다. `src/cxr10_queue.py --prepare`는 부모가 지정한 기존7차 run UUID·관리자 PID·생성시각을 검증하고 계획을 새로 만듭니다. `--run`은 고유 파일잠금을 얻어 대기와 순차 실행을 시작합니다. 실제 인자는 비공개 운영 기록에 보존하며 공개 문서에 운영 식별자를 싣지 않습니다.

7차의 학습 `progress.complete`나 파일 존재만으로 새 학습을 시작하지 않습니다. 큐는 원본 관리자 프로세스의 정확한 명령·생성시각을 확인한 Windows 핸들을 보유하고 실제 종료 코드를 수집합니다. **원본 관리자 exit0, 원본 두 모델과 NIH/COVID 평가, 고정모델84과제와 지문, GPU 실행 부재**를 함께 확인해야 합니다. 핸들을 얻지 못하거나 종료 영수증이 없으면 완료를 추정하지 않습니다. 원본 프로세스를 종료하거나 설치·이전 차수 중지 명령을 호출하지 않습니다.

각 조건에서 학습 자식 exit0 → 같은 조건의 평가 자식 exit0 → 결과·가중치·설정 지문 검사를 순서대로 통과해야 다음 조건이 시작됩니다. 실패 시 다음 조건을 시작하지 않습니다. 재개가 필요하면 기존 조건의 `--resume-condition`을 명시하며 임의로 새 조건의 상태에 붙이지 않습니다. 대기열은 자기 생존기간에만 시스템 절전 방지 요청을 유지하고 종료 때 해제합니다. 화면을 강제로 켜거나 전역 전원 설정을 바꾸지 않습니다.

| 기록 | 고정 위치와 의미 |
| --- | --- |
| 대기열 상태 | `work/queue/state.json`,20허용조건과 실제 대기·학습·평가·완료·오류 |
| 조건별 학습 | `work/runs/<조건별 UUID>/training/`,다른 조건과 별도 폴더 |
| 실제 진행·손실 | `progress.json`과 물리적 LF로 구분한 `events.jsonl` |
| 초기화·재개 근거 | `training_config.json`과 각 학습 단계의 `initialization.json`·체크포인트 |
| 완료 근거 | `artifacts.json`, `evaluation_results.json`,학습·평가 자식의 실제 종료 영수증 |

대시보드 선택이나 모션 정지는 학습 시작·중지 명령이 아닙니다. 현재 기록과 프로세스 근거가 없으면 학습 중으로 표시하지 않고, 미측정 손실·성능을0으로 만들지 않습니다.

## 원본 분할과 해석의 한계

원저자 분할을 유지합니다. NIH 검증용 영상은 학습75,708·검증10,816·시험25,596장, 검색 학습은61,755행입니다. 시험영상은 학습이나 모델 선택에 사용하지 않습니다.4~6차의 정제 제외목록을 이 실험에 자동 적용하지 않으므로 **원본의 동일 픽셀 중복·다른 환자 표지 중복과 검증 CBM 정책의 한계가 남아 있습니다.** 모든 누수가 해소됐다고 주장하지 않습니다.

검색 평가는 자기 원본 영상의 대각 항목을 제외하고 원래 지표·분모·동점 규칙을 유지합니다. 다른 이름으로 존재하는 동일 픽셀 파일을 이 자기영상 제외만으로 모두 제거하는 것은 아닙니다. 검증 정확도의 임계값은7차와 같은0.5이며 저장 원비율·AUC·손실을 표시를 위해 바꾸지 않습니다. 각 조건의 성능과 전체 학습 완료는 실제 결과·정상 종료 근거가 생긴 뒤에만 판단합니다. 이 코드 검증은 실제20조건 학습 완료나 의료적 효용·익명성을 증명하지 않습니다.
