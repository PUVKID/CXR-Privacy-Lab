# 블러·모자이크 강도별 독립 학습

10차는 **각 강도로 변환한 영상에서 새 모델을 따로 학습**합니다. 사용자 정정에 따라 7차 실행을 종료하고 체크포인트는 보존합니다. 10차는 원본 `original_000`부터 블러10·모자이크10의 총21조건을 모두 처음부터 새로 학습합니다. 기존7~9차의 한 모델을 고정한21조건 공격 평가는 다른 실험입니다. 이 확장은2022년 원논문에 보고된 블러·모자이크 재학습 실험이 아닙니다.

| 구분 | 학습과 평가 | 해석 |
| --- | --- | --- |
| 보존된7차 | 기존 체크포인트와 관측 이력을 보존 | 10차의 초기값·완료 조건으로 사용하지 않음 |
| 새10차 원본 | `original_000`부터 NIH 학습·검증과 원본 조건 평가 | 공식 ImageNet과 seed3에서 새로 시작 |
| 새10차20조건 | 조건마다 NIH 학습·검증과 새 모델의 같은 조건 평가 | 각 조건의 검증 모델과 검색 모델을 별도로 만듦 |
| COVID19 | 조건별 새 모델의 외부 평가에만 사용 | COVID별 별도 학습이나 모델 선택에 사용하지 않음 |

## 조건과 픽셀 단위

| 변환 | 강도 | 적용 위치 |
| --- | --- | --- |
| 블러 | 0,1,2,4,8,16,32,64,128,256 | 원영상 좌표계의 Pillow GaussianBlur 표준편차(픽셀) |
| 모자이크 | 0,1,2,4,8,16,32,64,128,256 | 원영상 좌표계의 명목 블록 크기(픽셀) |

블러 0, 모자이크 0·1은 영상에 항 등 변환을 합니다.

**이 세 조건도 다른 모델이나 원본 결과를 재사용하지 않고 독립 학습합니다.** 모자이크는 가로·세로를 각각 `ceil(원본길이/강도)`로 BOX 축소한 뒤 NEAREST로 원래 크기로 복원합니다.

원본 크기가 강도의 배수가 아니면 경계의 실제 분할 크기가 달라질 수 있습니다.

원본 파일은 바꾸지 않습니다.

변환은 검증 학습 쌍의 양쪽과 검색 학습·검증의 모든 영상에 적용합니다.

검증 모델의 256×256 크기 변환, 검색 모델의 1024×1024 입력과 정규화보다 먼저 수행합니다.

검색 학습의 기존 ColorJitter는 조건 변환 뒤에 수행하고 검증·평가에는 적용하지 않습니다.

새 모델 평가의 **질의와 갤러리도 둘 다 같은 조건**입니다.

기존 고정 공격의 질의만 변환·갤러리 원본 정책과 구분합니다.

## 새 초기화와 재개

각 조건은 고정된 공식 ImageNet ResNet-50초기값과 seed3으로 새 자 식 프로세스에서 시작합니다.

다른 조건의 CXR 가중치·optimizer·scheduler·CBM·RNG를 이어받지 않습니다.

같은 초기값과 seed를 쓰므로 초기 가중치의 수치가 같은 것은 의도된 비교 조건이며 모델 상태를 공유한다는 뜻은 아닙니다.

| 학습 과정 | 유지하는 7차 설정 | 같은 조건 안의 연결 |
| --- | --- | --- |
| 검증 모델 | Adam, 학습률 0.0001, 배치 32, 최대 100에 폭·검증 손실 개선 없음 5회 조기 종료, 학습·검증 RNP | 검증에서 선택한 자체 가중치 |
| 검색 출력 부 | ImageNet 백본 고정·학습 모드 BN 유지, SGD·OneCycle, 배치 32,30에 폭 | 자체 1 단계 마지막 가중치 |
| 검색 전체 | 같은 조건의 1 단계 가중치, 새 optimizer·scheduler·CBM, 배치 32,50에 폭 | 자체 2 단계 마지막 가중치 |

검색 학습률 0.158489·momentum0.9·weight decay0.00001·CBM128과 7차 AMP/샘플링/스케줄러 정책을 유지합니다.

검색 validation과 초기 sanity2 배치가 CBM을 갱신하는 7차 원본 이식 정책도 유지합니다.

배치 32를 줄이지 않으며 BN 버퍼를 복구하는 activation checkpointing을 사용합니다.

GPU 여유가 없거나 다른 작업이 있으면 실패 폐쇄합니다.

`condition_fingerprint`는 조건 정의를 식별합니다.

별도의 전체 `protocol_fingerprint`와 checkpoint `binding`은 실제 학습률·에폭·해상도·seed·작업자 설정·소스·변환·평가 코드·공식 목록 SHA·환경·조건·실행 UUID를 함께 묶습니다.

변경된 조건이나 프로토콜로 기존 상태를 재개하지 않습니다.

검색 학습률0.158489·momentum0.9·weight decay0.00001·CBM128과7차 AMP/샘플링/스케줄러 정책을 유지합니다. 검색 validation과 초기 sanity2배치가 CBM을 갱신하는7차 원본 이식 정책도 유지합니다. 배치32를 줄이지 않으며 BN 버퍼를 복구하는 activation checkpointing을 사용합니다. 같은 CXR 프로젝트의 학습·평가가 이미 있으면 중복 실행을 차단합니다. WDDM의 GUI·다른 프로젝트 GPU 목록은 관측 정보로 남기며 종료하지 않습니다. 기존 VRAM 기준(검증9GiB·검색19GiB)을 유지하고 부족하면 최대6시간 대기한 뒤 실패합니다. 배치 크기나 기준을 낮추지 않습니다.

중간에 폭 재개의 작업자 증강 난수열은 비트 단위 동일성을 보장하지 않습니다.

## 원본부터 새로 순차 실행

`src/cxr10_queue.py --prepare-fresh`가 기존 대기열 전체를 `work/재시작 이전/대기열/`에 바이트 검증하여 보존한 뒤 새 계획과 상태를 만듭니다. 이어서 `--run`으로 원본 `original_000`부터21조건을 차례대로 실행합니다. **7차 학습·평가의 완료를 기다리지 않으며 7차 모델이나 상태를 승계하지 않습니다.** 조건별 실행 UUID와 폴더를 새로 할당합니다. 이미 시작한 조건 기록이 있으면 자동으로 새 계획으로 덮어쓰지 않습니다.

현재 학습·평가 중복은 같은 CXR 프로젝트 경로와 실제 프로세스 명령으로 확인합니다. GPU 목록에 나타나는 일반 GUI·다른 프로젝트 작업은 CXR 중복으로 오인하지 않고 관측만 합니다. 다른 작업을 종료하거나 전역 전원 설정을 바꾸지 않습니다. 실제 CUDA 메모리 확보 여부는 기존 학습 엔진의 엄격한 단계별 기준을 따릅니다.

기존 `--prepare`와 원본 핸들·84평가 대기 분기는 과거 계획 해석을 위해 남아 있으며 이번 새 시작에서는 호출하지 않습니다. 실제 실행 인자·프로세스 식별자는 비공개 운영 기록에 보존합니다.

각 조건에서 학습 자식 exit0 → 같은 조건의 평가 자식 exit0 → 결과·가중치·설정 지문 검사를 순서대로 통과해야 다음 조건이 시작됩니다. 실패 시 다음 조건을 시작하지 않습니다. 재개가 필요하면 기존 조건의 `--resume-condition`을 명시하며 임의로 새 조건의 상태에 붙이지 않습니다. 신원 미확인 자식 PID가 기록된 조건은 자동 재개하지 않습니다. 대기열은 자기 생존기간에만 시스템 절전 방지 요청을 유지하고 종료 때 해제합니다. 화면을 강제로 켜거나 전역 전원 설정을 바꾸지 않습니다.

| 기록 | 고정 위치와 의미 |
| --- | --- |
| 대기열 상태 | `work/queue/state.json`,21허용조건과 실제 대기·학습·평가·완료·오류 |
| 조건별 학습 | `work/runs/<조건별 UUID>/training/`,다른 조건과 별도 폴더 |
| 실제 진행·손실 | `progress.json`과 물리적 LF로 구분한 `events.jsonl` |
| 초기화·재개 근거 | `training_config.json`과 각 학습 단계의 `initialization.json`·체크포인트 |
| 완료 근거 | `artifacts.json`, `evaluation_results.json`,학습·평가 자식의 실제 종료 영수증 |

대시보드 선택이나 모션 정지는 학습 시작·중지 명령이 아닙니다. 현재 기록과 프로세스 근거가 없으면 학습 중으로 표시하지 않고, 미측정 손실·성능을 0으로 만들지 않습니다.

## 원본 분할과 해석의 한계

원저자 분할을 유지합니다.

NIH 검증용 영상은 학습 75,708·검증 10,816·시험 25,596장, 검색 학습은 61,755 행입니다.

시험 영상은 학습이나 모델 선택에 사용하지 않습니다. 4~6차의 정제 제외 목록을 이 실험에 자동 적용하지 않으므로 **원본의 동일 픽셀 중복·다른 환자 표지 중복과 검증 CBM 정책의 한계가 남아 있습니다.** 모든 누수가 해소됐다고 주장하지 않습니다.

검색 평가는 자기 원본 영상의 대각 항목을 제외하고 원래 지표·분모·동점 규칙을 유지합니다.

다른 이름으로 존재하는 동일 픽셀 파일을 이 자기 영상 제외만으로 모두 제거하는 것은 아닙니다.

검증 정확도의 임계 값은 7차와 같은 0.5이며 저장 원 비율·AUC·손실을 표시를 위해 바꾸지 않습니다.

각 조건의 성능과 전체 학습 완료는 실제 결과·정상 종료 근거가 생긴 뒤에만 판단합니다.

검색 평가는 자기 원본 영상의 대각 항목을 제외하고 원래 지표·분모·동점 규칙을 유지합니다. 다른 이름으로 존재하는 동일 픽셀 파일을 이 자기영상 제외만으로 모두 제거하는 것은 아닙니다. 검증 정확도의 임계값은7차와 같은0.5이며 저장 원비율·AUC·손실을 표시를 위해 바꾸지 않습니다. 각 조건의 성능과 전체 학습 완료는 실제 결과·정상 종료 근거가 생긴 뒤에만 판단합니다. 이 코드 검증은 실제21조건 학습 완료나 의료적 효용·익명성을 증명하지 않습니다.
